# 08-MCP 接入

> 范围：`mcp/`（`connection`、`registry`、`registration`、`metadata`、`analytics`、`health`、`rmcp_client`）
> 定位：外部 MCP 服务的连接、发现、注册与观测层

## 连接与注册表

连接管理器持有各服务的客户端实例与注册表，支持懒连接（首次使用）、饥饿连接（注册即连）、保活（注册即连加周期健康检查）三种生命周期；同服务的并发连接经按服务互斥，避免重复建传输。注册表存放服务配置与运行时状态（状态、超时、生命周期模式），后台维护循环住在健康模块。回调支持连接建立与能力变更两类事件，能力变更用于触发元数据刷新。

## 动态注册与元数据

注册器做两类注册：泛型调用工具的常驻定义，以及每个已发现服务工具的具名条目（id 前缀隔离），使服务工具可被直接调用且各自拥有描述与输入 schema。外部输入 schema 转为框架的类型化参数 schema，无法识别的形状退化为空对象 schema，保证调用仍能透传。元数据缓存存放服务能力快照，支持动态上下文提供者按需组装；分析模块按服务与工具聚合调用量与错误；健康模块做周期探测与状态翻转。

## 传输客户端

`rmcp_client` 封装底层传输会话：建连握手、工具列表发现、工具调用、资源读取。审批侧的 MCP 策略（见治理文档）基于同一注册表判定风险，未知工具默认走人工确认。
