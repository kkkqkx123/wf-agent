# Web App 实施方案 - 第四阶段

## 阶段目标

交付查询与审计、事件与系统、设置三个页面域，完成前端特有能力（命令面板、虚拟化、无障碍、移动端），并通过性能与部署验收，使应用达到可交付状态。

## 范围与前提

- 前提：阶段一至三的应用壳、核心闭环、实时通道与剩余后端域已验收。
- 功能边界：权威清单第 3.8–3.9 节与第 6 节（前端特有功能）。
- 不包含：需要新后端的功能（权威清单第 5 节）：登录与 RBAC、通知收件箱、文件编辑、触发器定时启停、技能安装、模板评分评论。旧版阶段四中的 JWT 多用户、角色权限、国际化、前端插件系统、Docker/K8s 清单**不再存在**——后端鉴权为 API key，插件系统属 Rust 侧 `wf-plugin`，与前端无关；部署以 `--static-dir` 同源托管为准。

## 一、查询与审计

### 1.1 即席查询

- 过滤、排序、分页、导出、聚合、分组、去重、求值；结果表格化，大结果集分页拉取 + 虚拟滚动。
- 导出：查询通道支持下载模式则用之，其余由客户端组装下载（前端特有“附件组装下载”）。

### 1.2 审计与分析

- 审计：摘要、报告、时间线、迭代、工具调用、大模型调用、节点执行、进度；报告支持路由级只读分享视图（不设后端分享令牌）。
- 错误与性能：错误分析（含流式，阶段三已接）、高级分析、根因、恢复推荐、相似错误、性能、摘要、瓶颈、迭代对比。
- 大 dump 通道无分页：前端分段请求与虚拟化。
- 全局搜索面：统一搜索框聚合工作流、工具、脚本、消息搜索（通道自带分面与总数）；跨源游标由前端合并。

## 二、事件与系统

- 事件：实时流订阅（阶段三 `events/stream` 已具备，本阶段落页面）、按执行 / 回路 / 工作流过滤的游标分页列表、统计、搜索、时间线（含回合与工具执行）、监听器统计。
- 删除事件为危险操作：必须输入确认或双重点击。
- 依赖：调用方查询、影响分析、审计。
- 运维：健康、信息、存储诊断与健康与统计、系统诊断、事件健康、过期清理、指标快照。
- 不做备份恢复与配置热加载入口（后端未提供）。

## 三、设置

- 服务端通道：偏好读写（`/preferences`）、收藏（`/favorites`）接线；星标与标签以服务端为主、本地为兜底。
- 本地高频项：外观（主题三模、预设、字号档）、执行默认值、通知偏好——先本地持久化，统一走偏好封装，服务端补齐后整体迁移，组件不直读写存储（组件规范数据规则）。
- 快捷键配置页：全局与输入框级快捷键、冲突提示。

## 四、前端特有能力（权威清单第 6 节）

### 4.1 命令面板与执行内查找

- 命令面板：跨工作流、执行、模板、文件统一搜索入口，带历史与数量上限；执行内双搜（内容查找 + 命令）；历史本地存储。

### 4.2 虚拟化与列表性能

- 大列表统一虚拟滚动（执行、事件、变更、审计时间线）；无总数分页的游标模拟收敛为公共封装。
- 长时间线：headings 大纲与滚动小地图（导轨）。

### 4.3 流式渲染完善

- 限速合并、自动跟随尾部、手动接管、回底按钮全页面覆盖；流式占位 shimmer 结束后替换。

### 4.4 无障碍与动效

- 焦点管理、简化动效兜底（命中时改静态）、触控优化；动效只用于状态传达，时长快慢两档（样式规范第 5 节）。
- 状态不得仅用颜色区分，必须配文字或图标。

### 4.5 移动端适配

- 窄屏阈值先折叠右侧检查器再折叠侧栏；移动端侧栏转抽屉、表格转卡片（样式规范第 4 节）。
- 不做 PWA、桌面壳、托盘等借鉴对象专属能力。

### 4.6 只读分享与导出

- 审计报告前端只读路由；时间线截图导出为纯前端渲染能力；输入草稿跨页面恢复。

## 五、性能与交付验收

- 长列表帧率与首屏：骨架先行，核心页无布局跳动；流式页无逐帧全量重渲染。
- 构建与托管：静态产物由 `wf-server --static-dir` 同源托管，SPA 回退正确，`/api/*` 未知路径 404。
- 类型与契约：`schema.d.ts` 无 `any` 泄漏；OpenAPI 快照测试 `cargo test -p wf-server committed_snapshot_matches_document` 通过；快照变更后按管线重生成类型。
- 质量门禁：`check` / `typecheck` / `lint` / `test` 全绿；危险操作、错误态、空态、限流 429 全站抽查通过。

## 七、验收标准

- 权威清单第 2 节十个一级页面全部可达且有真实数据（非占位）；第 6 节前端特有能力均有对应实现。
- 命令面板可跨域检索；设置项刷新后保持；只读分享路由在无操作权限视图下不可触发写操作。
- 大列表滚动流畅；流式页面限速合生效；移动端核心流程（执行查看、审批）可完成。
- 第五节交付验收全部满足。

## 八、后续维护约定

- 后端路由变更 → 刷新 OpenAPI 快照 → 重生成 `schema.d.ts` → 修正调用点；流式契约变更只改 `sse.ts` / `ws.ts` 类型。
- 样式与组件规范修订 → 全局遵守，禁止页面私货；注释不引用文档章节编号。
- 新功能先查权威清单与服务端通道，无通道不立项。
