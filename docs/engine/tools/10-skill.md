# 10-技能系统

> 范围：`skill/`（`parse`、`prompt`、`resources`）、`skill_fs.rs`、`skill.rs` 门面、`predefined/knowledge/skill.rs`
> 定位：技能目录的扫描、解析、缓存与内容加载，渐进披露的第一级

## 加载器

`SkillLoader` 按配置路径扫描技能目录，维护启用/禁用状态与两级缓存（内容缓存与资源缓存，容量上限加过期淘汰）。加载支持变量替换上下文与可用工具校验（技能声明的限定工具缺失时加载失败）。事件枚举上报加载开始/完成/失败、启用/禁用与缓存清理。文件 IO 经 `SkillFileLoader` 抽象隔离，同步设计，默认走宿主文件系统实现，测试可注入故障实现。

## 解析与资源

解析侧为纯函数：去 frontmatter、最小 YAML 解析、名称与描述必填校验、名称字符集约束、变量占位替换。提示词侧生成已启用技能的元数据列表并注入系统提示占位符。资源侧约定技能目录下的四个资源子目录（引用、示例、脚本、附件），按相对路径加载文本或二进制内容。

## 工具定义

`skill` 工具本身只有一条静态定义（技能名参数），注册时仅安装定义、无处理器接线；执行走内置执行器，内容由注入的加载器提供。技能元数据占位符与可发现工具占位符共用同一模板常量来源，保证各注入阶段拼写一致。
