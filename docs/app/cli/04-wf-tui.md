# 04-wf-tui 全屏交互

> 范围：`crates/app/cli/wf-tui`（`wf` 二进制，全屏 `ratatui` 交互）
> 定位：全屏可切屏交互形态的应用外壳，底层渲染能力复用 `app/tui/` 系列 crate

该 crate 是全屏形态的薄门面加应用外壳：库目标重导出共享模块与底层终端能力，自身只保留外壳所需的屏幕、拉取、控制器与状态；二进制解析参数后移交库入口。会话与管理命令的网络语义全部走 `wf-client` 到 `wf-server`，绘制路径保持同步。

## 门面与入口

库门面做两类重导出：共享侧重导出参数、命令、连接、错误、模式、输出与会话驱动；渲染侧重导出时钟、组件、核心状态机、调试、Markdown、渲染与样式、终端等底层 crate 的能力，使既有引用路径在拆分后保持可用。

入口分发顺序为诊断优先、管理命令直接委托共享库、单次运行委托共享库、全屏形态进入交互式。交互式要求标准输出为 TTY，否则以参数错误拒绝。终端探针在此实现：无 TTY 时只做文本说明，TTY 下验证终端守卫的进入与恢复、外置命令窗口与主题探测。

## 全屏外壳

全屏外壳拥有服务客户端，在后台任务中把服务端读取转换为纯展示模型并写入屏幕数据缓存，绘制路径只消费缓存，不触碰网络。外壳职责包括事件循环、屏幕数据缓存、键路由、覆盖层栈、会话页签、尺寸防抖与终端守卫。

- 状态：统一应用状态收拢导航数据、界面通知与客户端焦点三类职责，会话内容本身留在单轮控制器中；通知队列负责瞬时状态行的过期，焦点门控保证后台失焦时的行为可测。
- 屏幕栈：导航栈管理屏幕 kind 与标题，首屏为交互主界面，其余经覆盖层进入；屏幕只做版式，不持有领域类型。
- 尺寸与终端：尺寸防抖收敛频繁的窗口变化事件，终端状态跟踪原始模式与切屏模式的进入恢复。
- 页签持久化：会话页签的落盘与恢复，使多会话布局在重启后延续。

## 后台拉取

每个屏幕 kind 对应一个异步拉取函数，产出展示模型并标记服务端截断，保证列表标题对分页上限诚实。拉取模块按界面域划分：

- 总览类：仪表盘、工作流列表、执行列表、洞察。
- 明细类：执行明细与工作流明细。
- 检查点类：检查点列表与链路与明细格式化、待审批的文件变更（含已提交文件集预渲染）。
- 文件类：文件工作区（执行触达文件与对主干差异的联接）、文件时间线、文件同步（对账点、外部更新提示、同步默认值）、冲突文件（合并不完全的标记区摘录，只读检视，裁决由外壳按键动作下发）。
- 会话类：编辑会话列表（服务端暂存的成组文件编辑，只读展示，开始与回滚由外壳按键动作下发）、交互会话的列表与树。
- 支撑类：目录与设置与代码库与搜索行、侧边栏（代码库状态、执行文件历史、工具可用性，各区独立降级，失败区保留旧行而不清空）、公共时间格式化与抓取 helper。

## 单轮控制器

交互主界面由单轮控制器驱动流式管线，复用与交互渲染相同的归约器、Markdown 流、输入框与审批问答视图。根文件保留会话状态机、生命周期、事件泵与流结算，细分职责下沉到 sibling 模块：

- 输入：提示、审批、问答、滚动四类键盘处理。
- 绘制：回滚视口、底栏、提示行的绘制路径。
- 历史：回放历史加载与向上分页，与历史覆盖层共享分页状态机。
- 性能：动效档位与底栏档位的策略应用。
- 锚点：提示、待办、失败、子智能体、检查点、决策的统一跳转。
- 工具块与子智能体块：工具调用的行会计与子智能体起止的行会计，供跳转与折叠使用。
- 选择与复制、鼠标命中、面板集、徽标、滚动条、视图快照、转向装配。

回放分页、实时流、历史覆盖层三者围绕同一分页器协作，保证回放与实时追加的位置语义一致。

## 键与鼠标体系

键处理按覆盖层分层：普通态、覆盖态、leader 序列、多序列待定构成统一的序列机；输入分类先判定粘贴与组合键，再映射到命令；键位配置可加载用户覆盖。鼠标支持点击命中、拖选、滚轮滚动，复制目标与鼠标捕获按配置 opt-in。剪贴板、信号（挂起与主题重载）、帧调度（限帧请求器）各自独立成模块，避免绘制路径阻塞。

## 外壳覆盖层与辅助屏

- 实时屏：流式执行的跟随视图。
- 回放屏：历史会话的只读回放。
- 分页器：回放分页的状态机，与单轮控制器共享。
- 历史覆盖层：历史记录的浮层检视。
- 命令面板与搜索面板：命令触发与跨资源搜索的浮层入口。
- 会话管理：会话持有者（当前会话内容）、会话列表、会话页签、会话树（层级导航）。
- 分页与列表的文本视图 helper 集中在独立模块，保持服务端返回的 JSON 形态原样打印。

## 用户操作

以下为全屏形态下用户可用的完整操作，按入口分层整理。键位符号中 `C-` 表示 Ctrl，`A-` 表示 Alt。部分键位可经用户键位覆盖改写，下表均为内置默认。

### 进入与退出

- 进入要求标准输出为 TTY，否则以参数错误拒绝。
- 管理列表屏：`Ctrl-Q` 直接退出，`q` 或 `Esc` 后退（首屏后退即退出）。
- 会话屏：`Ctrl-C` 连按两次退出（首次只做警告提示，5 秒窗口内再次按下生效）；流式运行中按 `Esc` 同样进入该双按通道。或经 leader `Ctrl-W q`、命令面板 `/quit` 退出。
- `Ctrl-Z` 挂起进程（恢复后重进终端），`Ctrl-L` 强制重绘。

### 全局导航

下表中 `Ctrl-P`、`Ctrl-K`、`Ctrl-B`、`Ctrl-T` 为全屏全局（会话屏亦生效）；其余为管理列表屏按键（会话屏同形按键归输入框或面板所有，见后文）。

| 按键 | 行为 |
|------|------|
| `0`–`6` | 直达屏幕：0 总览、1 工作流、2 执行、3 洞察、4 会话、5 检查点、6 设置 |
| `7` | 打开跨资源搜索面板 |
| `Ctrl-P` | 打开命令面板（输入框为空的会话草稿不受影响） |
| `Ctrl-K` | 打开跨资源搜索面板 |
| `Ctrl-B` | 打开侧边栏覆盖层（含导航，`j/k` 移动，`Enter` 进入，数字键直达） |
| `Ctrl-T` | 为当前选中会话打开历史回放覆盖层，再按关闭 |
| `?` | 打开帮助浮层 |
| `r` | 刷新当前列表屏 |
| `/` | 对有数据的列表屏弹出客户端子串过滤；`X` 清空过滤 |
| `j/k`、`上下方向键` | 列表选择上下移动；详情屏 `PgUp/PgDn` 翻明细，`Enter` 打开只读全文 |
| `[` / `]`（执行、工作流、目录屏）或 `Tab`（目录屏） | 切换子视图（执行总览/消息/工具/时间线/变量，工作流摘要/节点/运行） |
| `Ctrl-Y` | 复制当前浮层或选中内容（经 OSC 52，受复制策略门控） |

### 会话页签

会话屏支持最多 9 个并发页签，顶行显示页签条（含流式标记与锁定态），落盘后重启延续布局。

| 按键 | 行为 |
|------|------|
| `A-1`–`A-9` | 直达第 N 个页签（无对应页签时提示） |
| `A-t` / `A-T` | 新建页签 |
| `A-w` | 关闭当前页签 |
| `A-]` / `A-[`、`A-右` / `A-左` | 下一 / 上一页签 |
| `A-p` | 锁定当前页签 |
| `A-,` / `A-.` | 页签左移 / 右移 |
| `A-上` | 聚焦父页签（子智能体页签用） |
| `A-下` | 聚焦首个子页签；`A-j` / `A-k` 在子页签间轮转 |
| `A-s` | 打开会话列表 |

### Leader 序列

`Ctrl-W` 为 leader 键，按下后进入待定序列并显示 which-key 提示，2 秒超时自动丢弃。后续单键如下：

| 序列 | 行为 |
|------|------|
| `Ctrl-W q` | 退出 |
| `Ctrl-W h` | 帮助 |
| `Ctrl-W p` | 命令面板 |
| `Ctrl-W n` | 新建会话页签 |
| `Ctrl-W l` | 会话列表 |
| `Ctrl-W m` | 模型面板 |
| `Ctrl-W s` | 技能面板 |
| `Ctrl-W w` | 工作流面板 |
| `Ctrl-W u` | 排队提示面板 |
| `Ctrl-W e` | 以 `$EDITOR` 编辑草稿 |
| `Ctrl-W a` | 认证面板 |
| `Ctrl-W y` | 复制（消息、代码块或全文） |
| `Ctrl-W o` | 复制会话网页链接 |
| `Ctrl-W r` | 最近会话 |
| `Ctrl-W b` | 会话树 |
| `Ctrl-W f` | 分支出新页签（保留历史） |
| `Ctrl-W x` | 最近执行列表 |
| `Ctrl-W t` | 新建页签 |
| `Ctrl-W c` | 关闭当前页签 |
| `Ctrl-W .` / `Ctrl-W ,` | 下一 / 上一页签 |

### 斜杠命令与命令面板

会话输入框以 `/` 开头提交即为斜杠命令，未知命令给出最接近的三个建议。空输入框键入 `/` 直接打开命令面板；命令面板中可继续键入参数，`Enter` 执行。常用命令如下（括号内为别名）：

- 会话：`/new(n)` 新建、`/sessions(list,session)` 浏览切换、`/resume(recent)` 回到最近、`/recap` 一句话回顾、`/executions(exec)` 最近执行。
- 面板：`/model(m)` 模型档案、`/skills(skill)` 技能、`/workflows(workflow)` 工作流、`/queued(queue)` 排队提示管理、`/editor(edit)` 外部编辑器、`/auth(login)` 登录登出。
- 树与分支：`/tree` 会话树、`/fork(branch)` 分支出新页签。
- 复制与链接：`/copy(y)`（`message | code [N] | all | id`）、`/web(open-web)` 网页链接。
- 附件：`/image(images) <路径或地址>... | clear` 暂存图片、`/image-detail [auto|low|high|original|clear]` 细节档位。
- 运行中追加：`/steer [--node <id>] <文本>` 转向输入、`/followup [--node <id>] <文本>` 跟随输入（无活跃循环时暂存本地队列并提示经 `/queued` 重试）、`/append-mode` 查看模式、`/append-mode-steering`、`/append-mode-followup`、`/convert-pending(steer-pending)` 将缓冲转为转向。
- 应用：`/quit(q,exit)` 退出、`/help(?)` 帮助。

命令面板按键：可打印字符过滤、`上下` / `Ctrl-J` / `Ctrl-K` / `PgUp/PgDn` 移动、`Enter` 执行、`Backspace` 删字、`Ctrl-U` 清空、`Esc` 或 `Ctrl-P` 关闭。

### 输入框编辑

- `Enter` 提交，`Shift-Enter` 换行；`左右`、`Home`、`End` 移动光标，行尾右向接受幽灵建议。
- `退格` / `Delete` 删字，`A-退格` 删前一词，`A-d` 删后一词，`Ctrl-K` 删至行尾。
- `上` / `下` 浏览输入历史（多行输入时先在可视行内移动，到顶或底再进历史）。
- `Ctrl-R` 进入反向搜索：`上` / `下` 在命中间移动，无命中时承接历史浏览；`Enter` 接受，`Esc` 取消，`退格` 与字符编辑查询，其余键先接受再执行本义。
- `@` 触发提及面板（本地文件优先，其次服务端实体），`Esc` 关闭；括号粘贴整块一次性插入并压平换行，图片路径自动转为暂存附件。
- `Esc` 语义：运行中复用退出双按通道；有草稿时仅解除双击 Esc 武装；空草稿连按两次按配置分发（会话树、分支或关闭，可在设置屏 `t` 键轮转）。

### 面板（模型、技能、工作流、排队、认证、提及）

- `上下` / `j/k` 移动，`Enter` 选中提交，`Esc` 关闭（草稿保留），可打印字符过滤，`退格` 删过滤字，`Ctrl-U` 清空过滤。
- 排队面板额外：`E` 将选中项取回输入框编辑，`D` / `Delete` 删除；认证面板 `D` / `Delete` 登出选中档案；认证等待输入时直接键入加回车提交，`Esc` 取消。

### 审批与问答

流式中出现工具审批或问答时，底栏切换为专属视图并独占按键：

- 审批：`y` 本次放行、`a` 本会话放行同类工具、`n` 拒绝、`d` 仅拒绝本次（后续再问）、`c` / `Esc` 取消。
- 问答：`1`–`9` 选择对应选项，`Enter` 提交，`Esc` 取消。
- 任一阻塞视图存在时，leader 与面板命令暂停执行并提示先处理完当前事项。

### 回看、锚点与复制

- `PgUp` / `PgDn` 按页滚动；`End` 回到实时尾，`Ctrl-Home` 到最早（回放不完整时重复按键向前取更早页）。
- 工具块：`Ctrl-O` 折叠或展开最近块、`Ctrl-V` 全文检视、`Ctrl-D` 轮转细节档位（低、中、高）、`Ctrl-E` 全部展开或折叠。
- 锚点跳转：`Ctrl-G` 子智能体起止（由新到旧）、`Ctrl-U` 待办更新、`Ctrl-F` 工具失败、`Ctrl-N` 检查点、`Ctrl-X` 人工决策、`Ctrl-I` 列出锚点时间线；`A-N` / `A-P` 在锚点间前后移动（`A-P` 可达用户提示）。`A-L` 轮转嵌套智能体目标。
- 键盘选择（免鼠标）：`Shift` 加方向键 / `Home` / `End` / `PgUp/PgDn` 扩展选择，`Ctrl-A` 全选，`Ctrl-Y` 复制，`Esc` 先清选择再关闭。

### 覆盖层

- 历史回放：`PgUp/PgDn` 滚动（顶部 `PgUp` 取更早页），`Ctrl-Home` 取最早、`End` 到最新；选择与复制规则同上（`Ctrl-A` 全选已加载行、`Ctrl-Y` 复制、`Esc` 先清选择再关闭）。徽标点击回到实时尾。
- 跨资源搜索：键入即过滤，`Enter` 执行搜索，`上下` / `Ctrl-J` / `A-j` / `A-k` / `PgUp/PgDn` 移动，`Esc` 或 `Ctrl-K` 关闭，`A-数字` 直达屏幕。
- 会话列表：`Tab` 在页签窗格与最近窗格间切换。页签窗格：`Enter` 切换、`j/k` 移动、`p` 锁定、`d` 关闭、`x` 清理已关闭页签、数字键直达。最近窗格：`Enter` 继续会话（已打开则切页签，否则新开页签并载入历史）；键入按标识、标题与状态过滤（双引号短语精确匹配）；`Ctrl-D` 两步删除（先武装再确认），`Ctrl-R` 以过滤文本重命名，`Ctrl-N` 仅看已命名，`Esc` 按取消删除、清空过滤、关闭的顺序退场。
- 会话树：`上下` / `PgUp/PgDn` / `Home/End` 移动，键入即搜索，`退格` 删搜索字，`Enter` 按所选节点分支并弹出恢复范围（`1` 仅历史、`2` 仅工作区、`3` 两者），`左右` 折叠，`Ctrl-E` / `Ctrl-G` 全部展开或折叠，`Ctrl-D/T/A/R` 按默认、无工具、全部、已收藏过滤，`Ctrl-O` 轮转过滤，`Ctrl-B` 收藏，`Ctrl-Y` 复制，`Esc` 先清搜索再关闭。
- 通用浮层：确认框 `y` 确认、`n` / `q` / `Esc` 取消；只读检视（文件、差异、明细）`Esc` 或 `q` 关闭，Viewer 为空时复制提示而非静默失败；模型选择框选中即设为默认档案；列表过滤框提交非空文本，清空走 `X` 键。

### 各管理屏的写操作

除通用浏览键外，各屏的变更动作如下，破坏性动作一律先弹确认框：

| 屏幕 | 按键与行为 |
|------|------------|
| 执行 | `f` 轮转状态过滤（全部、运行中、已暂停、已完成、已失败、已取消）；总览按 `Enter` 回放到会话屏，其余子视图按 `Enter` 全文检视；`p` 暂停或恢复选中，`x` 取消选中（需确认） |
| 工作流 | `Enter` 检视（摘要直接渲染行信息）；`d` 删除选中（需确认） |
| 检查点 | `Enter` 明细，`t` 整链；`c` 为选中行实体建检查点；`R` 恢复为新提交（历史不改写）；`d` 删单条，`G` 按实体删全部（均需确认）；`U` 撤销选中实体的最近一次输入 |
| 文件工作区 | `s` 提交送审，`m` 合并到特性分支，`M` 合并到主干，`R` 回滚特性分支，`u` / `Ctrl-R` 撤销或重做，`g` 回收，`i` 重建索引；`t` 看选中文件时间线，`Y` 进同步屏 |
| 文件同步 | `e` 导出主干到工作区（覆盖写，需确认），`p` 导入外部头（幂等、无确认），`b` 变基基准线（先输入选择器再二次确认） |
| 编辑会话 | `Enter` 只读检视；`b` 开始暂存，`X` 回滚选中（需确认） |
| 文件审批 | `y` 批准选中（合入特性引用，需确认），`n` 驳回（移除送审引用，需确认） |
| 冲突 | `Enter` 只读检视（含无合并标记的二进制冲突说明）；`o` 取我方，`t` 取对方 |
| 设置 | `m` 设默认模型档案；`o` 鼠标捕获即时开关；`y` 选中复制模式轮转（关、复制、复制并清空）；`s` 会话滚动条即时开关；`b` 侧边栏即时开关；`c` 复制目标轮转（消息或代码块）；`e` 工具输出开关；`l` 工具细节档位；`t` 双击 Esc 行为轮转（树、分支、关）；`+` / `-` 预览行列预算逐档增减。本地文件类改动落盘并提示重启生效，即时类当场生效 |

设置屏的配置写入本地配置文件并提示是否需重启：鼠标、复制、滚动条、侧边栏类即时生效，其余重启后生效。

### 鼠标

鼠标默认按配置 opt-in（设置屏 `o` 键切换捕获）：

- 滚轮滚动回看（会话屏复用分页语义）或移动其余屏的选择。
- 单击页签条切换页签，单击回放徽标回到实时尾，单击命中行或选项。
- 拖选 transcript 文本生成选择区（`A-拖选` 追加为多选区），右键同格释放复制该行；`Shift` 加任意鼠标操作一律交还终端原生选择。
- 悬停只记录不重绘，滚动、缩放或按键后悬停与多击链清零；文本浮层打开期间指针归属顶层浮层。
