# 后台终端实施进展

> 记录各阶段的落地状态与后续工作。设计本身见 `00-overview.md` 至 `03-design.md`。

## 已完成

| 阶段 | 内容 | 落点 |
|---|---|---|
| 第一阶段 | 任务注册与后台语义统一 | 基础设施层新增后台任务注册表（按会话标识跟踪运行、后台化与结算，结算条目有界保留）；创建即运行的工具登记任务并返回后台指引，后台化工具标记后台态，终止与释放路径同步取消或结算，生命周期转发器兜底自然退出的结算；新增任务列表与后台化两个工具；执行共享层重出注册表类型 |
| 第二阶段 | 完成通知闭环 | 生命周期转发器支持额外槽扇出与进程级全局槽；运行时新增生命周期桥，将命令完成（含后台标记）与会话终止推送到共享事件总线，工具注册时全局安装；后台命令完成后经事件到达订阅端，不再需要人肉轮询 |
| 第三阶段 | 输出溢出与游标分页 | 输出缓冲支持阈值触发的溢出文件（惰性打开、后续分块直写，失败回退纯内存）；尾部读、窗口读与增量读在有溢出文件时从历史 serving，窗口语义保持游标单调；会话快照与窗口回执新增溢出标记与字节数；会话终止与回收删除溢出文件；阈值与目录可配，零阈值关闭 |

验证：后台任务注册表单测、溢出读写单测、工具级后台任务集成测试通过；受影响 crate 的类型检查通过且无新增告警。

## 未做与后续工作

| 事项 | 结论 | 理由 |
|---|---|---|
| 新增 shell 直达路由 | 不做，后台能力经通用工具调用面访问 | 会话存储归属工具注册表的有状态实例，应用门面无法直达；硬接会破坏分层，工具面已有鉴权、审计与 OpenAPI 覆盖 |
| 前端后台任务聚合视图 | 后续工作 | 时间线派生需要结构化的后台状态随流下发，当前流事件的工具结果为扁平文本，聚合视图应等协议补上结构化标记后再做；新工具已自动纳入终端类折叠展示 |
| 工具卡后台徽标与命令行聚合行 | 后续工作 | 同上，依赖结构化标记；后台指引文案已随完整结果下发，代理与全量查看可见，折叠预览的呈现待协议补齐后统一处理 |
| 重启恢复 | 语义已明确，不做复活 | 进程随进程结束；任务详情展示取消原因，避免误以为仍在运行 |

## 配置项

- 溢出目录默认走系统临时目录下的独立子目录，会话级文件随会话删除。
- 溢出阈值默认与内存环同量级；零阈值关闭溢出，回到纯内存行为。
- 会话上限、按任务限额、空闲回收与优雅终止语义均未变更。
