# 前端编辑与可视化后续项：小地图、边标签与遗留任务收敛

> 目标：判断小地图与边标签碰撞处理是否值得继续投入，并把前期模板、配置、可视化改造的剩余事项收拢为一份可执行清单。只描述做什么、为什么、做到什么算完成，不粘贴完整代码实现。

## 1. 现状

- 图渲染基于 Cytoscape，节点固定尺寸、贝塞尔曲线边，支持分层、分列、力导、网格四种布局。工具条提供缩放、适配视图、重排、导出图片、搜索加类型过滤、高亮覆盖层、单击选中、双击扩展邻居。
- 大图设节点上限，按类型轮询采样以保留各类代表，边仅保留双端点存活者；超限时展示类型分布并提供按类型折叠与一键展开入口。
- 边标签当前为数量阈值隐藏：边数超过阈值（默认六十）时全部隐藏，仅保留与选中节点相连的边标签；节点标签统一截断为短标签。
- 代码库中没有小地图、鸟瞰、导航器实现；框选已启用但暂无消费逻辑，目前仅起导航作用。
- 执行图标签已收敛为单次总览请求；分析标签的分片请求保留用于懒加载。

## 2. 小地图：暂缓

- 必要性不足。图规模有上限，且已有适配视图、类型过滤、按类型折叠、搜索、高亮覆盖层、邻居扩展多种定位手段；在工作流、Agent 决策、执行图的主流量级下，现有导航手段已够用，小地图边际收益低。
- 成本偏高。所用图库无内置小地图，需引入扩展或自研缩略渲染（第二渲染器或快照加视口框同步），带来依赖体积、主题同步、无障碍与移动端适配成本。
- 决策：暂缓。触发条件为真实图规模长期贴近上限且用户明确反馈定位困难，届时再立项，用真实数据驱动。
- 低成本替代（可选）：缩放至选中节点、适配至高亮集合；把框选的消费逻辑补齐（多选结果列表），或明确框选保持为纯导航。

## 3. 边标签碰撞：基线保留，无依赖小改进列为可选，专业排版暂缓

- 现状缺口。阈值隐藏是全开或全关两档：超阈值后条件边、错误路由、分支边等语义标签一并消失；无按重要性排序、无随缩放显隐、无文字旋转与避让配置。
- 无依赖小改进（已完成）：按边重要性排序显示前若干条，条件、错误路由、分支、高亮相关优先；边文字沿边方向自动旋转并加底色保证可读；低缩放隐藏标签、放大后显示；按预设区分阈值，执行图更严格。
- 专业排版引擎（暂缓）：引入分层排版引擎与真正的标签避让，仅当现有分层与力导布局在真实数据上被证实不可读时再评估；成本是新依赖体积、异步布局、坐标映射与主题适配。
- 决策：阈值基线已升级为重要性排序加缩放感知；专业排版引擎暂缓。

## 4. 遗留任务清单

- 集中校验（待办）：类型检查、构建、lint、单元测试一次跑通，覆盖后端新增路由编译与前端类型检查。本次未执行，受资源紧张约束，需一次集中验证。
- 接口契约刷新（待办）：后端新增模板导入导出与执行图总览路由后，刷新一次 OpenAPI 生成文件。前端新通道走请求逃逸层，短期不阻塞，但合入前必须刷新。
- 预览工程同步（已完成）：正式应用变更后执行既有同步脚本更新预览工程，样例目录与模拟客户端为预览独有，不被覆盖。
- 洞察执行语义（已确认）：保留默认作用域执行加本地草稿说明，不按原方案禁用，记为已接受偏差。
- 框选消费（已完成）：框选单个节点直接选中，多节点提示数量并引导单击查看，不再是无消费的纯导航。
- 缩放至选中与适配高亮（已完成）：资源管理器工具条新增两个无依赖导航按钮，无选中或无高亮时禁用。
- 边标签重要性排序与缩放感知（已完成）：见第 3 节。
- 小地图（暂缓）：见第 2 节，不设验收，仅记录触发条件。
- 专业排版引擎（暂缓）：见第 3 节，不设验收，仅记录触发条件。

## 5. 验收与风险

- 可选任务按项验收：边标签前若干条显示符合重要性排序、缩放显隐生效、缩放至选中与框选消费可用。
- 暂缓项不设验收与排期，仅记录触发条件：真实图规模分布、用户定位困难反馈、布局可读性证据。
- 风险：新图依赖增加包体积与维护成本。应对为优先无依赖方案，暂缓项必须有证据再立项。
- 非目标：拖拽建模、多选编辑、可编辑画布，延续原方案结论。
