# Web App 功能清单

> **权威清单已迁移**：后端驱动的功能明细以后端实际路由为边界，权威版本为 `docs/plan/web/frontend-feature-list.md`；借鉴来源见 `docs/plan/web/web-frontend-borrow-analysis.md`；服务端缺口（已落地）见 `docs/plan/web/server-gaps.md`。
> 本文档保留**应用视角**的导航结构、全局能力与实施阶段映射，供 `docs/apps/web-app/` 内的架构与阶段文档引用；不再重复罗列后端驱动功能明细，避免双源漂移。

## 1. 范围原则

- 后端驱动功能只看服务端已提供的读取或写入通道；本目录不为缺失后端的功能做前端预设。
- 聊天式隐喻只用于 Agent 回路域；工作流执行域使用执行与节点隐喻，不混用。
- 旧版清单中的 Node 后端、`@modular-agent/*` SDK、双包拆分假设均已失效；如在其他文档残留，以 `docs/plan/web/frontend-feature-list.md` 与本文为准。

## 2. 页面与导航（一级）

一级导航对应后端域划分，执行工作台为默认落地页。明细与后端依据见权威清单第 2 节。

| 一级页面 | 后端域 |
|---|---|
| 执行工作台 | 执行查询、状态、分析、审计 |
| 工作流 | 工作流定义、版本、图、草稿 |
| Agent 回路 | 回路、消息变量、图、错误分析 |
| 检查点与文件 | 检查点、文件分区与审批 |
| 触发器与钩子 | 触发器 |
| 模型与工具 | 大模型、工具、脚本、技能 |
| 模板库 | 模板 |
| 查询与审计 | 观察（查询、审计、分析） |
| 事件与系统 | 系统（事件、依赖、存储、指标） |
| 设置 | 偏好、收藏（`/preferences`、`/favorites`） |

全局能力：命令面板（跨工作流、执行、模板、文件统一搜索）、执行内查找、最近访问、全局 Toast。前端特有功能（主题、快捷键、虚拟化、草稿保留等）见权威清单第 6 节。

## 3. 实时通道（摘要）

- SSE：全局事件流、工作流流式执行、回路流式运行、大模型流式生成、错误分析流（共 5 个端点）。
- WebSocket：`/api/v1/ws`，按执行 / 回路 / 工作流三维度订阅，负载为元数据。
- 选用规则与帧协议详见 `docs/apps/web-app/architecture.md` 第 6 节与权威清单第 4 节。

## 4. 非目标

- 需要新后端才能成立的功能一律不收录：文件内容编辑、触发器定时启停、技能安装、模板评分评论、通知收件箱、登录与 RBAC（后端鉴权为 API key，无 login/token 通道）。
- 桌面 / PWA / 订阅计费等借鉴对象的专属外环功能不收录。

## 5. 实施阶段映射

与 `implementation-phase-1..4.md` 对应关系（阶段划分以“应用壳 → 核心闭环 → 域扩展 → 完善交付”为主线，不按后端域数量平铺）：

| 阶段 | 范围（对应权威清单条目） | 阶段文档 |
|---|---|---|
| 一 | 应用壳与导航、主题 Token、API 客户端与信封拆包、类型与质量门禁、骨架/空态/错误态、单个只读列表页打通 | `implementation-phase-1.md` |
| 二 | 执行工作台（列表 + 详情 + 控制 + 流式启动）、工作流（列表详情版本图）、Agent 回路（列表详情消息变量图） | `implementation-phase-2.md` |
| 三 | SSE/WS 全面接入、检查点与文件、审批与交互、触发器与钩子、模型与工具与脚本与技能、模板库 | `implementation-phase-3.md` |
| 四 | 查询与审计、事件与系统、设置、命令面板与查找、虚拟化与性能、无障碍与动效、移动端适配、部署验收 | `implementation-phase-4.md` |

阶段内任务清单只写目标与验收，不写完整代码；样式与组件约束分别遵循 `docs/spec/web/style-guide.md` 与 `docs/spec/web/component-guide.md`。

## 6. 总结

Web 应用的能力上限由 `wf-server` 现有路由决定；前端的价值在应用壳、信息架构、组件体系、主题与流式订阅接入。功能明细查权威清单，接口契约查 `docs/api/`，集成方式查 `docs/plan/web-app-integration.md`，本文件只负责把“做什么”映射到“哪一阶段做”。
