# 05-wf-cli-demo 演示集

> 范围：`crates/app/cli/wf-cli-demo`（示例与黄金输出，仅演示用途）
> 定位：不含产品逻辑，按三形态 showcase 各形态的真实实现，供开发期检视与手动运行

该 crate 明确声明为演示用途：库目标只放示例 plumbing，各示例目标各自展示一个场景，全部复用产品 crate 的真实实现，不保留镜像副本。布局按三形态划分，全屏示例走可切屏渲染，行式示例走追加输出，无头示例走格式层与目标层。

## 共享演示 plumbing

库模块按复用粒度划分：行式渲染（含真实渲染原语的再导出与示例文档）、转向路由、提示层与笔录的再导出加演示用种子与汇总、格式与目标 plumbing、黄金输出捕获（按形态落盘到对应输出目录）。每个示例保持聚焦单一场景，公共能力沉在库中。

## 无头示例

覆盖无头形态的三类输出行为：多格式渲染（文本与结构化形态的对照）、事件流驱动（流式帧到终端事件的映射）、诊断输出（诊断通道的行语义）。输出目录保留对应的文本黄金文件，用于对照格式回归。

## 行式示例

覆盖行式会话的五类行为：Markdown 三档呈现对照、流式追加的行边界语义、整轮转向的槽分流（助手增量进标准输出、其余进标准错误）、提示行输入（含历史与建议的交互）、会话级多轮（含笔录种子与恢复）。输出目录保留行式相关的黄金文件（流式行、笔录、工具开关对照、斜杠历史等）。

## 全屏示例

覆盖全屏外壳的十余类场景：动画与动效档位、基准性能、组件陈列、差异录制、固定场景、按键接收、Markdown 展示、管理面展示、上下文用量展示、样式陈列、组件输出、面板选择展示。示例目录附带说明文档，输出目录保留重排与选择器等布局相关的黄金文件（窄宽重排、混合 ANSI、单双列选择）。

## 使用方式

按形态运行对应示例目标即可观察该形态的实现行为；新增场景时优先复用库中的真实原语与 plumbing，只在示例侧保留场景编排，不向该 crate 引入产品逻辑。
