# 04 测试用例清单

## 说明

本清单以无头命令全集为来源，按领域分组整理当前需要验证的功能。每条用例给出验证意图与判定准则，不含具体脚本实现。状态标记含义如下：已接入表示已在验证脚本的默认门禁中执行；待接入表示无外部依赖、可后续接入；手工表示依赖外部大模型、凭证或网络，仅手工运行。

判定通用约定延续线束设计：成功路径期望零退出码且包络可解析，失败路径期望非零退出码且错误信息可识别，含时间戳与随机标识的字段先归一化再比对。
