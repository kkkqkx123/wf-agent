# Jump to 锚点导航设计

现状对比对象为 `ref/opencode`，分析目标为当前项目 TUI 与前端如何补充跳转到特定锚点位置的能力。新的锚点不必局限于用户输入，事件触发也可创建锚点，例如待办列表更新工具调用时与检查点创建时。

## 现状事实

### opencode TUI 的做法

锚点注册表与滚动位置分离。时间线锚点表以消息分片引用与分组标识为键，持有渲染节点的纵坐标与高度，只保留已挂载且高度大于零的节点，几何信息留在渲染层。每行会话行挂载时注册、卸载时注销，分组头另行注册。标签页维度另有一份滚动锚点记忆，记录锚点目标加相对视口的屏内偏移，切换标签后按行查找加窗口补偿恢复，跳转会清掉该记忆。

消息边界计算独立于注册表。按方向在子节点纵坐标数组中找下一或上一条消息，用户消息取顶部，助手消息顶部上移一行以露出头，空文本行被过滤，可选只看用户消息。当前标识命中则前后移一位，未命中则按滚动顶部比较纵坐标。

会话滚动控制器围绕全量挂载加弹性空白实现跳转。对齐某条消息时先关闭黏尾，设置导航态并计算底部弹性高度，待布局后滚动到目标顶部。按方向跳转时先保证全量行已挂载，不足则向前补页再递归。跳到指定消息先由锚点表取纵坐标再换算为内容顶部，助手消息减去头行补偿。回尾时清导航态、清计时与锚点记忆、开黏尾并滚动到底。逐行移动时清导航态并按方向揭示更早或更新的行。首屏跳转有专门的首消息路径，加载全部历史后滚到零并做防重守卫。差异查看器另有一套按文件与 hunks 跳转的逻辑，与会话跳转不共用。

交互入口分胶囊、命令与对话框三类。远离底部时浮现跳到最新胶囊。翻页、行滚、半页、首尾均有键位。时间线对话框倒序列出用户消息，移动即实时预览跳转，选中进入消息对话框。另有跳到上一用户消息、下一或上一条消息、仅用户消息的下一或上一条命令，用户行点击与分支对话框复用同一跳转函数。历史补页期间跳转优先于延迟滚动，但需等待锚点补偿完成后执行。

### opencode 网页的做法

时间线交互状态分溢出与跳转两维，跟随态按会话键记忆。溢出且距底部超过阈值时才显示跳转按钮，阈值取视口高度与固定值中的较大者。游标按顶部加固定偏移判定当前消息，上一或下一跳转按可见用户消息数组移动，到末尾则恢复跟随并清哈希，否则取消跟随并滚动到目标。

深链与虚拟化器配合。锚点命名为消息前缀加标识，哈希滚动先激活消息，再经虚拟化器揭示消息，待布局后按顶部减去吸顶标题补偿滚动到元素，重试数次后用替换方式更新哈希。空哈希回尾，消息哈希取消跟随并滚动，普通标识滚动到元素，未知哈希回尾。揭示工具分片时先展开上下文与工具折叠，再按工具标识或会话标识定位，工具顶部带滚动边距，跟随恢复时释放。

跳转按钮仅在溢出且远离底部时可见，点击恢复跟随并滚到底。滚轮、触摸与上翻、翻页、回到顶部键向上时取消跟随，到达底部容差内重新跟随。会话命令只有上一或下一条消息两项，无首尾键，首尾靠滚动与哈希链接，搜索控制器复用揭示消息接口。

### 当前项目 TUI 的处理方式

会话视口为尾跟随模型。偏移量表示尾部之上隐藏的展示行数，零表示跟随，大于零表示暂停自动滚动并显示浮动徽章。绘制时按总量减视口算最大偏移并钳制，刷新是否置顶标记供分页决策。预置缓存负责增量布局，追加、体编辑、前插、裁剪分别同步，前插返回新增展示行数供视口补偿，序列号用于连续性校验。流式尾行始终在缓存之外，每帧重排。

跳转能力只有三类。跳到最新与最旧为首尾哨兵，最旧用最大值哨兵下次绘制时钳制，重复置顶且回放未完成时请求更早页。子 agent 跳转为唯一的消息目标跳转，按到达顺序倒序循环，以启动序列号定位，目标置顶，找不到或被裁剪则丢弃记账并试下一个，无候选则保持不动。徽章为纯展示，显示隐藏行数与回尾提示，窄屏降级为短文本或隐藏。

键位均为显式匹配。会话屏支持回尾、回首、上下翻页、工具块展开切换、查看器、细节档位、子 agent 跳转与复制。管理屏、历史浮层、文件与差异查看器、搜索面板各有自己的翻页与首尾语义，键位基础设施无统一滚动绑定。工具块只做折叠与查看器，不做跳转。锚点一词在核心库中指帧哈希回归检测，与导航无关。回放加载替换全部行并归零，前插合并后若处于历史中则按新增展示行补偿偏移。

### 当前项目前端的处理方式

聊天列为主会话视图，检查器消息页复用同一滚动器，详情页循环面板为非虚拟化简单列表。通用滚动器为唯一的虚拟化消息列表，按固定条数将消息分行，窗口化受阈值门控，偏移量由已测高度或估计高度累加，二分查找定位行，首尾各留过扫行，顶部与底部用占位撑高，实时尾部渲染在窗口之外从不虚拟化。气泡根节点无标识锚点，仅靠外层键值复用稳定标识。

跟随模型与 TUI 同构。视口、滚动顶部、视高、内容高、跟随态、基线计数与编程滚动宽限期为核心状态，距底部短于松弛值即跟随。重置键切换、外部置顶、跟随态下的活动计数变化均回尾，文本选中非空时主动脱离跟随。导出接口只有恢复、滚到顶部与滚到底部，无按标识或索引滚动。浮动按钮分回到顶部与回到尾部两颗，后者带增量徽章。全局跳转键只有到底与到顶两项，经快捷键目录解析。

点跳模式已在别处验证。实时工具行、时间线大纲、分析面板均用元素标识加滚动到视图实现，大纲与时间线左右并列，分析到图谱反向经微任务聚焦图节点。持久消息气泡缺的是同构的一环：在气泡或渲染项包裹层加消息标识，滚动器加按标识滚动并处理虚拟窗口未挂载时的先定位再滚动。

### 核心缺口

首要是无通用锚点表，子 agent 跳转是孤立特例，待办更新、检查点、失败工具、审批问询等事件无落点。其次是视口寻址无统一换算，序列号到展示行、消息标识到虚拟行、哈希到元素的三条链路各缺一段。最后是交互入口单一，只有首尾与子 agent 循环，无时间线对话框、无上一或下一锚点、无按种类过滤、无深链。

## 锚点来源设计

### 分类原则

锚点分用户输入与事件触发两大类。用户输入锚点由本地行直接创建，事件锚点由流事件或接口数据派生。所有锚点共享同一标识与种类约定，展示层按种类过滤与分组，不为每类各起一套跳转语义。瞬时进度只更新宿主卡片与页脚，不建锚点，避免跳转列表被高频事件淹没。

### 用户输入类

用户提问行为天然锚点。发送成功即在提示行序列号处建锚，种类为用户提问，回放重建时按同规则从提示行前缀识别并重建。审批与问询的回答行同样建锚，种类为人工决策，便于事后回看何时放行或拒绝。搜索命中不建锚，只做临时高亮，避免污染列表。

### 事件触发类

待办更新为必备锚点。工具名为待办更新的工具结束事件到达时建锚，成功与失败均建，标签取调用结果首行或状态摘要。不解析待办正文全文，只保留计数与首项截断供列表展示。失败工具为必备锚点，任何工具结束且成功为假时建锚，标签取工具名加错误首行。检查点创建为必备锚点，引擎事件中检查点已创建到达时建锚，标签取检查点标识截断与描述首行，创建失败不建锚，只记错误行。子 agent 起止沿用现有语义，启动行建锚，结束行关闭区间但不新增跳转目标，标签取名称加任务预览。迭代边界与终态为可选锚点，迭代结束、完成、失败、中断各建一种轻量锚点，默认在列表中折叠，按需展开。后台任务交接为可选锚点，工具结束携带后台标记时建锚，标签取会话标识，点击后进入后台会话查看而非仅滚动。

### 不建锚的事件

文本增量、推理增量、用量更新、子 agent 进度、心跳类引擎事件不建锚。工具开始行是否建锚按细节档位决定，低档位无开始行则不建，避免无行可跳。重复投递的同组同签名事件去重后不重复建锚。

## TUI 可借鉴的设计

### 统一锚点表替代单类跳转

在交互控制器侧新增锚点表，与工具块表与子 agent 块表并列，形态复用子 agent 块表的序列号机制。表项以种类加标识为键，含标签、序列号、创建时间与可选结束序列号，到达顺序另存一份有序数组，循环游标按种类独立记忆。子 agent 现有表逐步迁移为该表的子 agent 种类实现，键仍用子执行标识，启动序列号即跳转目标，对外行为不变。待办、检查点、失败工具、用户提问、人工决策、迭代边界、终态、后台交接各占一种类。裁剪回收时按工具块同例丢弃记账，跳转时找不到目标则试下一个同类，无候选则保持视口并给一行轻提示，不静默回尾。

寻址复用现有视口数学。跳转换算为目标序列号到尾部的距离，目标置顶，绘制侧的钳制、置顶标记、前插补偿逻辑不变。宽度变化导致展示行变化时不重算锚点，只在跳转瞬间按当前宽度换算，避免缓存失效。历史浮层内的跳转作用于浮层行集合，浮层重放页需给子行与事件行分配序列号，否则浮层内无目标可寻。

### 键位与对话框

保留现有回尾、回首、翻页与子 agent 循环键不动，新增通用锚点键走两层。第一层为循环键，按种类循环，例如待办循环、检查点循环、失败循环，键位选空闲的组合键并与工具键并列写入帮助。第二层为时间线对话框，倒序列出锚点，标题为标签，副行为时间，分组按种类折叠，移动即预览跳转，选中即确认停留，对话框关闭不改变视口。对话框数据源即锚点表有序数组，无需全量行挂载，预览时若目标页尚未加载则先请求更早页再递归，与 opencode 的先保证挂载再跳转同构。上一或下一锚点命令复用消息边界思路，按展示行纵坐标而非序列号比较，支持仅看用户提问与仅看失败的过滤变体。

徽章从单一回尾提示升级为锚点感知。远离底部时仍显示隐藏行数与回尾提示，附近有锚点时追加最近锚点方向与种类，例如向上几行有待办更新。徽章保持纯展示，点击不跳转，跳转仍走键与对话框，避免鼠标命中区与窄屏布局的额外负担。鼠标点击跳转并入长期鼠标方案，不在此立项。

### 引擎事件的接入

当前归约器忽略引擎事件，需开一条白名单分支，只识别检查点已创建并透传为可回放的提交，其余引擎事件仍忽略。交互控制器在该分支建检查点锚点，失败类引擎事件只记错误行。无头与迷你输出保持现状，不新增锚点打印，避免污染机器可读输出。

## 前端可借鉴的设计

### 消息锚点与滚动器扩展

气泡根节点加消息标识属性，命名与现有实时工具与时间线标识同形，例如消息前缀加标识。渲染项包裹层同时加数据属性，供虚拟化未挂载时的查询兜底。滚动器新增按标识滚动接口，流程为先在行数组中定位目标行，若在可视窗口外则先滚动到估计偏移，待测量后二次校准，再对元素滚动到视图并减去吸顶标题补偿。跟随态在跳转时取消，回到尾部时恢复，与 opencode 的取消跟随加哈希更新同构。深链支持消息哈希，空哈希回尾，消息哈希揭示并滚动，未知哈希回尾，加载更多直到找到或耗尽。

### 时间线与过滤

聊天列与检查器消息页共用同一滚动器扩展，循环面板等非虚拟化列表直接用元素滚动。新增时间线对话框或大纲，倒序列出用户提问、待办更新、检查点、失败工具四类，标题取文本首行或标签，副行取时间，点击跳转并高亮目标行。快捷键目录新增上一或下一锚点两项，默认绑定修饰键加中括号，与现有会话命令同形，用户可覆盖。回到顶部与回到尾部按钮保留，远离底部且有新锚点时在尾部按钮旁追加种类徽标。

### 待办与检查点的展示归属

待办锚点宿主为工具调用卡，工具结束事件按调用标识归入对应卡片，卡片内展示状态与结果摘要，锚点点击滚动到卡片而非单独行。检查点锚点宿主为检查器时间线，检查点链接口按需加载，点击检查点锚点可跳转到检查器对应节点，复用已有层级与子树接口，不常驻全量检查点流。瞬时备注保留为过渡态，最终以工具卡归属取代轮询投影。

## 共享约定

种类枚举在前后端对齐，名称描述行为而非实现，例如用户提问、待办更新、检查点、失败工具、子 agent、人工决策、迭代边界、终态、后台交接。标识命名分三段：用户提问用提示行序列或消息标识，工具类用工具调用标识，检查点用检查点标识，子 agent 用子执行标识。持久消息以消息标识为准，实时行以序列号为准，前端哈希只认消息标识，TUI 对话框展示标签只取首行截断。文档与注释只描述意图，不引用外部文档编号。

## 落地顺序与验收

先落地通用锚点表与三类必备事件锚点，使待办更新、失败工具、用户提问可跳，子 agent 跳转迁移到新表但键位与行为不变。以一次同步问答加一次失败工具加一次待办更新验证成对建锚、标识一致、裁剪后丢弃、空表按键为空操作。

再落地检查点锚点与引擎白名单，使检查点创建可跳。以创建一次检查点验证引擎事件透传、锚点标签正确、失败不建锚。

最后落地时间线对话框、上一或下一锚点、前端按标识滚动与深链、徽章的锚点提示。以连续按键在同类锚点间前移、无目标时空操作、浮层与虚拟化下行为一致、刷新后按需重建为验收线。

后台交接、迭代边界、终态锚点列为可选后续，不进入本次范围。差异文件与 hunks 跳转、鼠标点击跳转、子增量全文透传、跨会话导航均不做。
