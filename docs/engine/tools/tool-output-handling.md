# 工具输出特殊处理

> 范围：`wf-tools` 内全部面向模型的输出整形（执行器、文件/shell/网络工具、展示折叠），以及引擎侧消费这些整形的历史链路（蒸馏、归档、折叠）
> 定位：回答"模型最终看到的文本从哪来、超限时去哪找下文"——定义与实现以代码为准，本文只做索引与规则归纳

## 总览：按可寻址性分三类

| 类别 | 代表 | 恢复方式 | 统一落盘（`tool_output`） |
|------|------|----------|---------------------------|
| 源可寻址 | 文件读取、目录列举、搜索 | 行号/偏移天然可恢复 | 豁免 |
| 流可寻址 | shell 会话（内存环加溢出文件加绝对游标） | 会话标识加绝对位置 | 豁免 |
| 不可寻址一次性输出 | MCP、网页抓取、一次性命令 | 落盘文件加指针 | 必经 |

准入规则：新工具先判定可寻址类别，再决定走分页还是走落盘，不允许第四套措辞。

## 统一落盘层（`tool_output`）

行加字节双限（2000 行 / 50KiB），达任一上限即截断并保留头部行。全文写入落盘文件（`tool_<12位hex>.txt`），行内标记给出已展示行区间、总行数与文件路径。有执行工作区时落在工作区 `.wf/tmp/tool-output/`（保证文件读取工具可读回），否则进程临时目录。落盘失败降级为纯截断，永不使调用失败。

执行结果的 `truncated` / `output_path` 字段是唯一的机器可读截断信号，两个引擎的消息装配点将其转写进工具结果消息元数据（与既有作用域违规标记同携带方式）。无状态处理器只返回纯值，指针走行内文本与值内字段。

## 执行侧内容归一

- MCP：多内容段拼接为文本；图片只留预览占位；资源段序列化；服务端错误前缀 `Error:`；空内容给 `(No output)` / `(Empty response)` 占位；整形后统一过落盘层。
- CLI：行加字节双限的行内截断，附截断原因（按字节/按行/双超限）；落盘分支已删除，职责由统一落盘层承担。
- 内置执行器：作用域违规错误保持错误类型向上传播，其余处理器错误转为失败结果（供引擎计数与标注）。

## 文件工具输出

- 文件读取：超大文件硬拒绝；窗口内逐行编号；截断时前置 `IMPORTANT` 提示、展示行区间与总量、续读指引（`offset/limit`）；空文件给提示；写保护文件追加后缀。
- 目录列举与搜索：结果数上限截断并返回结构化 `truncated` 布尔；展示文本附摘要行；作用域外与忽略规则过滤的条目计数注记（"省略而非不存在"）；搜索命中单行超长按字符截断并标记。
- 补丁改写：预览 diff 按上下文行数生成；大 diff 折叠为标注（合并行数加保留的 diff 标记数）。

## shell 输出

- 会话快照：环掉头时前置截断标记（含省略字节数）；溢出文件存在时附带溢出标记与字节数。
- 窗口读取：绝对位置游标（`window_start/end`、已写总量、丢弃量、头是否丢失、是否由溢出文件服务）；游标跨截断有效。
- 等待工具：上限内返回会话窗口并附会话恢复指针（会话标识加绝对位置，经会话输出工具续读）；无上限保持历史行为。
- 后台迁移：返回固定指引（等待完成事件，用会话输出或任务工具跟进），不轮询。
- 历史折叠：shell 长输出折叠为头加尾（默认 20/40 行）加省略行数标记。

## 网络输出

- 网页抓取：下载硬上限保留（防内存耗尽）；行内超限走统一落盘，返回值内附截断标记与路径字段。
- 网页搜索：结果数上限；HTML 剥离标签与实体转义后取标题加摘要。

## 展示与调用摘要（`display`）

面向前端的展示载荷与结果全文分离：预览按工具类别取形（命令取尾、改写取 diff 标记、探索取计数、其余取头行），调用摘要由参数 JSON 纯推导（命令首行、路径、模式加路径），超长值截为单行短串，前端永不匹配工具名。

## 机器标记一览

| 标记 | 位置 | 含义 |
|------|------|------|
| `truncated` / `output_path` | 执行结果与消息元数据 | 统一落盘截断信号与全文路径 |
| `output_window_start/end/total`、`output_prefix_dropped`、`output_pointer` | 会话等待响应值 | 会话恢复游标 |
| `window_start/end`、`total_written`、`trimmed_bytes`、`prefix_dropped`、`spilled` | 会话窗口响应值 | 流分页游标 |
| `archive_ref`（`a:` 前缀） | 消息元数据 | 检查点归档指针 |
| `not_found`、`scope_violation` | 错误文本标签与消息元数据 | 缺失与越权的可机器判定信号 |
| 各列表工具的 `truncated` 布尔 | 响应值 | 结果数截断信号 |

## 历史侧消费

- 入库前蒸馏（agent 回路）：按工具类别（测试/搜索/diff/命令）压缩长输出，原文归档进检查点并留归档指针；文件读取豁免并按内容哈希去重；已带落盘指针的消息跳过归档、保留原指针（避免双存）。
- 归档读取工具按指针加行范围取回冷内容。
- 历史折叠改写旧消息形态（shell 头尾、diff 标记、通用截断）；general 代理边界做历史形态归一（幂等）。
- 工作流回路暂无入库蒸馏链，是否补链待历史预算压力实测。

## 指针词汇对照

行内指针有三种，分别对应三类可寻址性，不再新增：落盘指针（行区间加总量加文件路径）、会话指针（会话标识加绝对位置）、文件续读指引（`offset/limit`）。含义相同，措辞按类别固定。
