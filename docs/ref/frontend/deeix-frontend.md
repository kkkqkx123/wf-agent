# deeix 前端实现说明

> 对象：`ref/deeix-frontend`（Next.js 静态导出前端，业务规则在 Go 后端，前端负责工作区 UI、客户端状态与展示流程）。
> 视角：仅关心功能与 UI，不关心 Web / 语言差异。

## 1. 概述

deeix 前端是文档型 Agent 工作台：以对话为中心，外加最近会话、文件库、知识库、技能与提示词、设置、管理后台等完整周边页面。路由采用分组布局（鉴权组与项目组仅为代码分组，不占 URL），静态导出后由后端或 CDN 托管。无 Redux 或 Zustand，以分层 React Context 组织状态；API 为契约优先，由后端 DTO 生成类型，前端做轻量适配。

## 2. 功能清单

### 2.1 路由与页面

| 路由 | 功能 |
|---|---|
| `/` 跳转 `/chat` | 默认进入对话工作区 |
| `/login`、`/auth/callback` | 密码登录、OAuth 与 OIDC 回调、人机验证、开发自动登录 |
| `/chat` | 主对话工作区，见下节 |
| `/recent` | 可过滤会话列表，批量操作，星标与标签，快捷预览 |
| `/files` | 三栏文件库：侧栏列表、内容头与元信息与预览、配额面板；抽取、OCR、RAG 状态轮询 |
| `/knowledges` | 用户知识库；管理后台有平台级对等页面 |
| `/skills-prompt` | 技能、提示词预设、可复用 UI 组件画廊 |
| `/share` | 公开分享会话，按需免登录 |
| `/preview/image-loading` | 图片预览加载试验页 |
| `/setting`（通用、对话、订阅、账号、关于） | 资料、外观、对话默认（字号、发送快捷键）、订阅用量热力图与趋势与账单、会话与双因子与身份 |
| `/admin`（约 15 页） | 版本与更新、公告、计费、对话文件（文件、抽取、OCR、RAG、存储）、内容审核、会话参数策略、分组、平台知识库文件、登录策略、审计日志、模型路由与能力与默认参数与原生工具开关、统计图表、MCP 工具、上游通道、用户 |

### 2.2 对话与会话

流式运行（提交、缓冲、排队分发），生成中可继续追问的多消息队列，停止即入队语义；按父级分支 fork 与上下分支切换；用户与助手消息重试、继续、原地编辑、删除、点赞反馈；分享、JSON 导出、标签、星标、项目归属；隐身临时模式；截图分享。

### 2.3 工具

MCP 选择器（数量上限提示，默认持久化），原生工具按模型能力门禁，模型配置面板按模型动态切换参数控件，知识库 RAG 选择器支持单文件退出，多媒体任务（图片生成与编辑、视频生成与扩展）自动切换输入框模式，模型选择器内联计费价格。

### 2.4 鉴权

全局鉴权守卫与初始安全守卫，会话 Provider，内存持有访问令牌加 HttpOnly 刷新 Cookie，多标签页广播同步。

### 2.5 国际化

中英双语，约 28 个命名空间，Provider 加用户语言同步加语言选择器，错误码映射本地化文案。

## 3. UI 布局

### 3.1 总体嵌套

根布局（全高、溢出隐藏）叠加品牌、国际化、主题、外观偏好 Provider，子页面加版本守卫、旧 Service Worker 清理、全局 Toast；项目工作区经鉴权守卫进入侧栏布局；分享页免鉴权或按令牌复用项目布局但默认收起侧栏；管理与设置各有独立壳（管理为窄中栏加侧栏，设置为侧栏加面板）。

### 3.2 侧栏

可折叠为图标并悬停展开：顶部控制（折叠、搜索）、主导航（新建对话、搜索、最近、文件、知识库、技能入口）、中部滚动会话分组（项目、星标、最近）、底部用户区。隐藏滚动条，骨架占位，移动端改为抽屉并在路由切换时自动关闭。

### 3.3 对话页

顶部标题栏（标题内联重命名、星标、标签、项目菜单、分享、导出、截图），中央消息滚动区（居中最大宽度），底部圆角大输入框。两侧各一条细导轨：消息位置小地图与回答大纲（截图与选中模式下隐藏）。空态为衬线问候语加动效徽章。

### 3.4 文件与知识库页

文件页为侧栏列表加内容头与预览三段式；知识库页为侧栏加详情加弹窗；技能页为分区画廊。

## 5. 样式实现

- **框架**：Tailwind v4 加 shadcn（中性灰、CSS 变量），Radix 与基础 UI 原语，命令面板、抽屉、动效、拖拽库。
- **Token**：浅色与深色两套，含背景、纯色、卡片、浮层、主色、次要、静音、强调、边框、输入、聚焦环、图表五色、侧栏体系、圆角、阴影、字体；细滚动条，边框与聚焦环低透明度，触控优化。
- **主题**：浅色、深色、跟随系统三模乘以 8 套预设（默认、 azure、cobalt、graphite、lagoon、ink、ochre、sepia），预注水脚本避免闪烁，品牌就绪前隐藏正文；按用户偏好切换字号档与对话字体（默认、宋体、黑体、等宽）及字重。
- **Markdown 与渲染**：流式 Markdown（含中日韩、代码、公式、图表），公式库，图表库，JSON 编辑器，文档与表格预览库，截图库，动画库。

## 6. 状态与数据流

无全局 Store，以分层 Context 组织：品牌快照、国际化、主题、鉴权会话、侧栏会话、对话会话（含外部存储的运行实例）、布局导航，各功能内再分输入态、运行时、附件、MCP、UI 组件等局部态。`model` 层为纯函数，`hooks` 层做编排（加载、过滤、乐观列表、文件处理轮询、无限滚动哨兵），`utils` 层做格式化，跨功能事件经自定义事件与广播通道（如会话快照变化、公告、文件库、知识库事件）。

API 为契约优先：后端 DTO 经生成类型进入各域 API 适配；HTTP 客户端统一拼接令牌、携带 Cookie、禁用缓存、解包错误体并抛业务异常，支持 `Retry-After`；鉴权客户端注入内存令牌并经 Cookie 刷新；基地址构建时注入，否则同源，开发回退本地端口。

## 7. 特色交互

- 输入框：多消息队列（生成中可编辑、引导、删除），@ 统一提及（文件、模型、工具、技能、提示词），语音输入，实时 Markdown 预览浮层（滚动同步），图片粘贴自动上传，表格粘贴归一化，拖放浮层，RAG 关闭徽标与全关警告。
- 模型感知：多媒体模式药丸自动识别并提示阻断原因，参数控件随模型切换，价格内联。
- 阅读辅助：实时跟随、回底按钮、右侧位置与大纲导轨、上下文压缩分隔线可展开。
- 轨迹透明：过程、思考、工具手风琴在流式时自动展开、结束后自动收起，RAG 引用与文件徽标，完整工具结果弹窗。
- 分享为图：消息多选模式，数量上限，截图专用 DOM 裁剪，品牌页眉页脚注入，后台线程生成。
- 产物与 AI 组件：侧边可调产物面板（代码加沙箱预览），消息内交互块（图表、表格、测验、计算器）经白名单 HTML 与主题变量渲染。
- 壳打磨：悬停展开图标侧栏，全局搜索带会话预览，可安装 PWA，版本更新提醒，公告弹窗，全局 Toast，空态动画问候，登录人机验证。
