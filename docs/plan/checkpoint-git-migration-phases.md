# 文件检查点 Git 化分阶段修改方案

依据对象库为真相源的最终架构，将现有 SQLite 文件历史逐步替换为独立 Git。只描述做什么与验收标准，不保留旧数据兼容，不讨论旧库迁移。

约束：不新增替代型模块，所有改动在原模块内按职责演进；版本号保持不变；每次编译验证合并为最少次数。

## 阶段零 冻结与口径锁定

目标是让后续阶段有唯一的真相口径，避免边改边争论语义。

确定引用命名空间划分，主线、编辑、送审、特性、人工引用的归属与生命周期。确定提交附注字段，执行者、会话、工具来源的记录位置。确定忽略规则的叠加顺序，独立仓库自身排除、工作区已有忽略、自定义模式三层的优先级。确定冲突落盘形态与合入阻塞条件。确定空目录与送审状态的存放位置。

验收：上述口径在最终架构文档中无歧义，后续阶段不再争论命名与存放位置。本阶段不改任何行为。

## 阶段一 存储底座就绪

目标是让独立裸仓库与精简 SQLite 同时可用，旧路径仍为权威，不产生双写。

在工作区维度引入裸仓库管理职责，负责仓库初始化、引用读写事务、工作树关联指针。提交构造走管道式能力，不经过检出切换。引用更新保证原子性，并发提交在不同引用上互不阻塞。

在原有持久化持有结构中增加 Git 句柄，与现有连接共存。新增送审状态、空目录、来源索引三类小表，均只存元数据。对象库缺失时给出明确的未初始化错误，不做静默回退。

依赖层面在工作区统一清单中引入纯 Rust 的 Git 实现，文件检查点模块直接引用。旧的行级差异依赖仅保留作展示用途，不再作为存储格式。

验收：新仓库可初始化并读写引用；新表可写入并可整体重建；旧的创建查询恢复行为无任何变化。验证合并为一次全特性编译检查。

## 阶段二 写入路径切换

目标是让所有新增文件内容只进 Git，不再产生新的增量与快照行。

工具精确上报改为直接构造目录树并在编辑引用上追加提交，内存字节优先，不做磁盘二次读取。脚本运行改为前后状态对比，一次运行恰好产生一个原子提交。多文件操作不再逐文件拆分提交。会话分组改为提交附注，不再写入会话关联表。

人类编辑改为周期性状态轮询，落在人工引用上，永不自动并入主线。执行者引用回退只移动自身引用，不触碰送审与主线。

本阶段删除增量会话写入路径与文件移动记录写入路径，重命名依靠差异相似度检测。旧的增量与快照读取路径暂时保留，仅用于尚未切换的读取侧。

验收：连续工具调用形成线性提交链；脚本多文件操作为单提交；人类编辑与执行者分支天然隔离；不再新增增量与快照行。验证合并为一次编译检查加写入侧目标测试。

## 阶段三 合入与回退切换

目标是让分支隔离回退成为可能，删除分层流转门控。

编辑到送审改为引用复制，不发生合并。送审到特性、特性到主线改为真正的多父合并，保留完整祖先。送审状态改为显式状态表，不再用历史长度隐式判断。驳回只删除送审引用。

冲突以标准标记落盘并阻塞对应合入，未解决前不产生新的主线提交。冲突列表来自未解决合并提交的枚举，不再重放历史推导。

回退单个分支改为产生新的合并或还原提交，将目标输入排除或抵消，其他已合入分支不受影响。主线指针不再回移到旧父提交。

本阶段删除分层合并调用、跨层流转门控、单链分区指针回退逻辑。旧的检查点分支表写入路径随之停止。

验收：回退任一特性后其他特性内容不变；冲突可落盘解决并继续；驳回不影响已合入历史。验证合并为一次编译检查加合入回退目标测试。

## 阶段四 读取与查询切换

目标是让所有读都走目录树与提交图，来源索引只作加速。

工作区物化改为从目标目录树展开并清理多余文件，受保护忽略目录永不删除，空目录按清单重建，内容相同即跳过。差异视图改为两棵目录树对比。文件时间线改为改名跟随加提交日志。按执行者与按路径查询优先命中来源索引，缺失时回退到提交图扫描。

删除基于快照链重放的文本重构、链头增量反查、合并输入重算冲突区域等逻辑。展示用的行级差异能力保留，但只用于渲染，不参与存储寻址。

验收：物化结果与目标提交一致且幂等；时间线可跨越改名；索引清空后可从提交图完整重建。验证合并为一次编译检查加读取侧目标测试。

## 阶段五 检测简化

目标是删除三路归因，只剩两条确定性规则。

删除后台文件监视服务、内容哈希注册表、优雅窗口、删除标记、未完成租约、失败重排队列。删除脚本哈希遍历收集器，脚本归因改走受限范围的状态对比。路径规范化收敛到一处实现。

保留工具上报为主、状态对比为辅。工具上报内容以调用者为准，其余工作树脏文件以对比为准。轮询失败只影响本次人类编辑的及时性，不产生错误归因。

验收：无后台监视时工具与脚本归因依然正确；人类编辑最终可见且不混入执行者分支；全仓无多余的归因分支。验证合并为一次编译检查。

## 阶段六 清理与收尾

目标是让文件历史旧模型彻底消失，回收走对象库机制。

删除分层状态机、行级增量引擎、文件历史提交仓库、分区存储实现及其测试与基准。删除文件历史提交分支表的旧查询与旧回收路径。执行态大对象表与上层协调器不受影响。对外查询恢复接口保持稳定，内部已全部改写。

依赖层面移除文件检查点对旧存储引擎的引用，仅保留对象库、嵌入式数据库、忽略匹配等必要依赖。文档中的旧模型描述同步删除，不保留双轨说明。

验收：全仓无文件节点增量快照分区的读写引用；旧回收路径无调用；对外接口行为符合最终架构验收；一次全特性编译检查与一次全量目标测试通过。不再安排额外的回归轮次。
