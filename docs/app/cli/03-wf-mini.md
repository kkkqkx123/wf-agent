# 03-wf-mini 轻量行式会话

> 范围：`crates/app/cli/wf-mini`（`wf-mini` 库与 `wf-mini` 二进制）
> 定位：原生终端上的轻量交互智能体会话，行规程加追加式输出，不做全屏重绘

该形态面向日常快速问答：标准输出只追加助手文本，标准错误承载工具生命周期与汇总，标准输入每次读取一行。提示词在标准输入与标准错误均为 TTY 时运行于单行原始模式编辑器并附带幽灵文本建议，否则回落到熟制行读取。库目标收拢全部会话能力供示例复用，二进制只做参数解析与形态分发。

## 入口分发

二进制先判断无头子命令，有则直接委托共享库；否则解析形态：单次运行形态委托共享库，全屏形态在此进入原生会话。标准输入与标准输出的 TTY 状态由共享的模式解析器集中判定，各二进制只做分发。会话构造失败与运行失败统一收敛为标准错误行与退出码。

## 原生会话与提示循环

原生会话是在一条服务连接上运行的多轮循环：笔录为每轮请求提供历史种子，服务端流回执行事件，笔录保留助手答案供下一轮使用。

启动时依次打印会话横幅：交互提示与退出说明、当前显示配置单行摘要、会话锚点与后续恢复方式、恢复到的消息条数（仅恢复非空时）。提示符为固定大于号加空格，写往标准错误，保证标准输出只留助手文本。

提示循环的退出语义只有三种：空缓冲上的 Ctrl-D 或标准输入关闭对应文本结束，斜杠退出命令，提示态双击 Ctrl-C。双击以五秒窗口判定：一次放弃当前行并提示再按一次退出，窗口内再次按下退出；任何成功提交的行都会解除上一次的武装。熟制回退下 Ctrl-C 以信号形式参与选择，原生编辑器下以按键事件进入状态机，行为一致。

每轮结束与每次提示态中断后，会话都会丢弃提示未消费期间到达的整行（审批迟到应答、轮次运行中键入的行），丢弃非零时在标准错误留一条计数痕迹，避免迟到行被误读为下一问。空行直接跳过，不入历史不发轮次。

## 输入管线

进程按标准输入 TTY 状态在启动时选定唯一的输入源，运行中途不切换：管道源由后台线程转发字节块再组装为熟制行；TTY 源以终端事件流为唯一读取者，原始提示消费按键事件，熟制提示与审批从按键事件组装行。两种消费者（熟制行读取与原始提示编辑器）轮流使用当前源，互不并发，编辑器每次借用事件流后归还；借用期间熟制侧只报文本结束而不闩住状态，归还后恢复正常。

- 管道组装：按换行切分，兼容回车换行，以宽松编码容错解码；文件结束时若有未换行尾巴则按一行交出，符合管道无尾随换行的习惯。
- TTY 熟制组装：终端保持熟制模式以便 Ctrl-C 仍走信号；组合控制键与修饰键忽略，只有普通字符、退格与回车参与成行。
- 行读取：双管线之上的统一行接口，服务于审批问答、管道输入与 TTY 熟制回退；提示符写往标准错误。
- 鼠标：未启用鼠标捕获，点击保持终端原生行为；滚轮事件在原始提示下映射为上下历史浏览，在熟制组装下忽略。

## 单行编辑器

编辑器是多行感知但单行展示的原始模式提示行，交互模型对齐常见的幽灵建议习惯：建议后缀以暗色绘制于光标之后且不进入缓冲；缓冲修改触发重取，光标移动清除建议；行尾右向或制表接受整条建议，单词级接受只取一个词；上下方向键浏览前缀过滤的历史并在越界时恢复已键入前缀。

结构上分为三层：纯状态机核心（不依赖终端，可单测）、按键映射（终端键到编辑键空间）、原始循环（事件源、原始模式、括号粘贴、退出时防护性恢复）。非 TTY 会话不进入该模块。进入原始模式前会冲掉驱动层残留的半键入行，退出时经守卫恢复熟制模式与粘贴模式，覆盖恐慌展开路径。

按键语义如下：

| 按键 | 行为 |
|------|------|
| 普通字符 | 光标处插入，清除浏览态并重取建议 |
| 退格、删除 | 删除光标前后字符，清除浏览态并重取建议 |
| 左、右 | 光标单步移动并清除建议；唯独行尾右向接受整条建议 |
| Tab、行尾右向 | 接受整条幽灵建议 |
| Ctrl-右、Alt-f | 单词级接受建议中的下一个词（含跟随空白），剩余部分保留为新建议；非行尾时改为词级右移并清除建议 |
| Ctrl-左、Alt-b | 词级左移并清除建议 |
| 上、下 | 按当前前缀过滤历史上下浏览，空缓冲时遍历全部历史；上至最旧停止，下越过最新恢复已键入前缀 |
| Home、Ctrl-a、End、Ctrl-e | 行首行尾跳转并清除建议 |
| Ctrl-k | 删除光标到行尾并重取建议 |
| Ctrl-u | 删除行首到光标并重取建议 |
| Ctrl-w、Alt-退格 | 向后删一词并重取建议 |
| Alt-d | 向前删一词并重取建议 |
| Alt-. | 插入上一提示或最新历史的尾词 |
| 回车 | 提交当前缓冲，不含可见建议 |
| Ctrl-c | 中断本行，交由会话做双击退出判定 |
| Ctrl-d | 空缓冲时结束会话，非空时删除光标处字符 |
| Ctrl-l | 清屏后重绘当前行 |
| Esc、功能键等未绑定键 | 仅重绘，不改状态；释放事件直接忽略 |
| 括号粘贴 | 整块一次性插入，换行压平为空格，光标落于末尾，只重取一次 |
| 终端宽度变化 | 实时更新列数并重绘 |

重绘按显示宽度多行折行：提示符加缓冲加幽灵文本的总宽决定占用行数，光标按列数定位，隐藏光标后回块首清屏下重写再定位；未知宽度时回落单行路径。幽灵文本的屏显按配置截断加省略号，接受时仍为完整建议。

## 建议与幽灵文本

建议引擎以缓冲前缀为输入，按注册顺序试探多种策略，首个命中且为严格前缀扩展的结果胜出；以空格开头的缓冲永不建议。内建策略按序为：

- 历史最新命中：以后到先得取首个长于缓冲的前缀匹配。
- 紧随上一提示的序列命中：匹配项在历史中的前一项必须等于上一提示，反映真实的提问序列而非偶然前缀。
- 提及补全：在最后一个 `@` 后取词，无空白无多 `@` 时生效；`@` 与 `@file:` 走工程目录的有界文件扫描（文件数与深度上限，跳过版本控制与构建产物目录，大小写不敏感子串匹配），`@skill:` 与 `@workflow:` 取提示快照中的注册名；候选排序去重后取首个长于缓冲的前缀扩展。
- 斜杠命令名补全：以斜杠开头且不含空白时生效，单候选补全全名，多候选补全最长公共前缀，歧义点上无扩展时保持沉默，单个斜杠不建议。

当前会话向编辑器传入的技能与工作流注册名均为空，因此提及补全实际只覆盖文件路径部分。

代理携带取消语义，每次取数开新令牌，迟到结果在令牌过期后丢弃，缓冲的每次修改都使旧取数失效。光标移动只清除建议而不重取，保持与常见终端习惯一致。幽灵文本仅在行尾有意义，绘制截断长度默认三十字符，可经环境与配置文件在十到二百之间调整；熟制模式画不出行内 dim，建议由带前缀的历史检视命令显式打印同策略的补全行。

## 历史

历史是内存加可选文件持久化的提示记录，默认内存保留二百条，可经环境与配置文件在一下限与十万上限之间调整。行为上遵循终端习惯：空行跳过，换行压平为空格，连续重复抑制，写入文件逐行即时追加以防进程被杀丢失，缺失或不可读的文件读作空历史。

路径解析顺序为显式路径覆盖环境变量再覆盖状态目录默认，禁用开关与路径互斥：命令行禁用或环境禁用任一成立即不落盘。加载时只取文件尾部至内存上限，追加时自动创建父目录，全部文件失败静默吞掉不打扰会话。

- 历史检视：无参列出最近二十条并带序号，有参按前缀过滤后列出全部命中（序号为全局序号），无命中时明确提示；有参且命中时附带同策略的建议行。
- 重跑：可选序号，缺省为最后一条；命中则代为提问，未命中则提示当前条数而不发轮次。

## 斜杠命令

提示行以斜杠开头的行先做命令解析，命中则执行会话内操作，未命中或参数形态非法则整体作为普通提问发送（例如带多余参数的退出、非法序号的重跑、缺正文的转向都不会报错，只会被当作正文问出去）。别名与主名等价：退出含 `/exit` 与 `:q`，帮助含 `/?`，追问含 `/follow-up`，待定转换含 `/steer-pending`。

- 会话与帮助：退出无参，缺省行为与 Ctrl-D 一致；帮助无参，一次打印会话、服务端会话、历史、显示、嵌套循环、上下文、按键与多媒体的分组说明；清屏只打印分隔线；新会话清空笔录并生成新的本地锚点，同时清除待确认删除、嵌套附着与选择、暂存图片附件，并推进回顾令牌与重置窗口标题。
- 历史检视与重跑：见历史节。
- 显示：原文、纯文本、着色三档的查看与切换，推理流、用量行、工具流三路标准错误开关的查看与切换，全部显示配置的单行检视。开关值只接受开与关两种语义，非法值提示用法。
- 检查点：无参列出服务端检查点，按标识加实体加状态成行展示，空时明确提示，失败时打印原因。
- 回顾：无参手动拉取一次屏显回顾，绕过自动门槛与显示开关，静默时保持静默。
- 节点转向与追问与追加模式与待定转换：转向与追问均接受可选的前置节点旗标与必填正文，追加模式只接受转向与追问两种取值（缺省为追问），待定转换无正文。有显式节点或已附着工作流执行时走工作流嵌套接口，否则走当前智能体循环接口；单快照单目标时可省略节点，多目标必须显式节点；失败正文会代入历史以便经重跑重试，诊断行注明已保留。
- 循环检视：可选执行标识，传入时先附着到该执行再列出；列出嵌套目标的行含选中标记、节点、状态、转向与追问堆积数、追加模式、存活与循环标识。单目标自动选中，多目标需显式节点，已选中而消失的选择会被清除并提示。
- 服务端会话：列表、恢复、重命名、删除四件套，均限于当前工作目录的作用域。第 n 项序号引用的是最近一次列表的展示顺序。
  - 列表可选命名过滤与自由过滤：命名过滤隐藏无标题会话，自由过滤为空白分隔的与组合（引号段为精确短语归一化匹配，单词为大小写不敏感子串匹配），命中范围覆盖标题、标识与状态且标题优先；默认分页展示前二十条并提示剩余条数。
  - 恢复可选目标：缺省恢复最新会话，数字复用上次列表，精确标识优先直连，短语感知过滤取最佳匹配；恢复时替换整份笔录并跟踪新锚点，同时清除待确认删除与嵌套上下文。
  - 重命名必填标题：面向当前循环或非本地锚点，本地新鲜锚点在首轮前无可改名对象。
  - 删除可选目标：缺省删除当前会话，数字、精确标识与过滤匹配的解析同恢复；两步确认，首次只武装目标并提示重复同一命令确认，重复同一命令才执行；删除当前会话后清空笔录并开启新锚点。
- 会话级结构化上下文：无参展示键数与键名，清空、整体替换、单项设置、单项删除、文件加载五种写法；整体替换接受 JSON 对象，单项设置的值尽可能按 JSON 解析否则回落字符串，误用子命令元数时提示用法而非误判为 JSON；上下文随每轮请求携带，可经顶层参数预置。
- 多媒体暂存：图片与文本附件各自维护一个下一轮载荷暂存区，轮次启动时带上并无论胜负消费，未启动的轮次原样保留。
  - 图片接受本地路径与远端地址，本地内联远端原文透传；空参列出已暂存、清空与按序号单删，批量暂存时做合并预算校验，超限则整批拒收并保持暂存不变；新暂存继承当前图片细节档位。
  - 附件为文本文件，读取与截断标记与无头单次的附件旗标一致；列表、清空与单删的语义同图片。
  - 图片细节档位空参查看，四个档位切换，清空回到提供方默认；每次暂存列表都会附带当前档位与组合预算行。
  - `@file:` 提及在服务端解析为图片，客户端侧的 `@` 补全只负责路径提示。

## 轮次执行与中断

提问先入历史并记录为上一提示，随后进入单轮管线：暂存非空时先报送暂存计数，终端进度允许时开关进度转义，打开新的回顾令牌，运行流式轮次，成功则入库笔录并触发完成横切，最后清掉轮次期间到达的迟到行。轮次请求体由共享转向构造器统一装配，携带智能体与模型覆盖、超时预算、结构化上下文、笔录历史与本问载荷（含图片附件）。

流泵是每轮唯一的事件选择：信号中断、审批侧取消、每秒标题心跳、服务端事件流四路偏序竞争。引擎事件中的循环标识会被记为当前循环，决定后续转向与改名的默认对象；完成事件结算成功并携带迭代数，失败与中断事件结算失败；传输错误与无终端事件的流结束都算作未完成并在诊断通道留痕。收尾时恢复空闲标题并打印一行完成摘要：中断只打印中断，正常打印本地关联标识短码与耗时毫秒。

入库规则偏保守：仅已完成轮次入库，中断与失败轮次由调用方丢弃；成功后会话锚点跟踪最新服务端循环并刷新窗口标题，使退出后仍可用锚点恢复。笔录恒存清洗后的原文，不存渲染形态，使显示选择不污染模型上下文。

## 追加渲染与输出纪律

原生会话不拥有视口，已写入标准输出的字节无法修订，因此渲染策略偏保守：先剥离模型输出中的终端转义，再按档位呈现；原文档位逐字透传清洗后文本，纯文本文档位去标记且不加转义，着色档位按 Markdown 跨度包裹样式并在无颜色能力时降级为纯文本。

纯文本与着色档位只排放已安定区：安定边界之后的部分（当前段落、未闭合围栏、未闭合表格等）暂缓到后续增量不再改写时再排放；原文档位不做二次渲染，按换行切分。超大源在阈值上降级为透传并保证不丢不重发，已排放字节永不撤回，跨行强调与集标题下划线等改写会被保守地容忍一次重复。大源阈值与安定判定与全屏侧的流式上限保持一致。

转向渲染经由可注入的转向槽：助手增量追加到标准输出，其余事件全部进入标准错误，保证业务流与诊断流分离。具体映射如下：助手增量走标准输出并在块边界补换行闭合；迭代起止只做输出换行；工具起止、子智能体起止与进度、后台任务提示、完成迭代数走诊断行；推理增量走标准错误文本流；用量走诊断行并附带缓存命中与费用；失败走红色诊断行但失败事件本身不受开关抑制。工具失败与子智能体失败恒显示，其余诊断流受显示开关门控。后台任务在结束时提示跟进方式，在完成时汇总仍在运行的会话并提示确认方式。

终端转义剥离独立成模块，确保模型输出无法驱动终端：控制序列整体移除，残缺尾序列随增量丢弃，除换行与制表外的控制字符丢弃，多字节字符原样透传。诊断区中的提及与暂存占位符在颜色允许时加亮，仅用于已安定诊断行，不进入可编辑缓冲。

## 审批与显示

每轮生成一个迷你审批器：监听事件流，仅在出现审批公告或重连后读取待处理交互，仅对本轮的审批在标准错误上以确认行提问并回传答案；问答类与外轮交互留给服务端宿主默认裁决。确认行注明工具名、可选风险等级与超时秒数，默认拒绝，超时即拒绝；肯定回答只接受确认词的两种常见写法，其余一律拒绝；审批期间的 Ctrl-C 会置位取消并使整轮按中断结算，避免对下一个敏感工具重复提问；超时的迟到行留在通道中由会话统一清掉。

显示配置的解析顺序为命令行标志、环境变量、配置文件、内建默认，默认保持历史行为（原文透传、三路标准错误全开、审批超时上限、建议截断默认值、无颜色）。颜色分两路独立判定：标准输出颜色看标准输出 TTY，标准错误颜色看标准错误 TTY，两路共享禁用开关与哑终端判定，使管道重定向与颜色禁用各自正确降级。

## 会话恢复与服务端台账

会话构造时先建连再定锚点：显式会话标识优先，最近恢复取最新台账，否则生成新的本地锚点；恢复问题一律回落空笔录而不使启动失败。恢复只保留用户与助手非空文本，丢弃系统与工具消息。读取走服务端会话台账：单会话对话接口取指定会话，最新锚点接口加摘要扫描取最新；列表与恢复均带目录查询以隔离多目录服务，缺工作区时回落全局列表。最近恢复在锚点接口不可用时按开始时间扫描摘要兜底。

## 笔录

笔录是内存中的问答对序列，为每轮提供历史种子；仅已完成轮次入库，中断与失败轮次由调用方丢弃；笔录不做截断与压缩，预算与压缩归引擎所有。空助手回复仍保留问题，恢复时保留全部条目而不设上限。

## 横切：通知、标题、进度、回顾与自动标题

会话承担提示循环之外的横切职责：失焦未知假设下的通知触发、运行中窗口标题心跳、终端进度转义、屏显回顾与自动标题。

- 通知：轮次结束按耗时门槛触发站外提醒，完成、中断与失败分别映射不同语义，迭代数作为附加上下文，焦点状态固定为未知。
- 标题：空闲时写会话锚点标题，运行时每秒翻一帧心跳前缀，冻结的帧即卡死信号；标题经清洗后以转义序列写往标准错误。
- 进度：经环境或配置文件显式开启后，在轮次起止开关进度转义。
- 回顾：自动回顾只面向正常完成且超门槛的轮次（耗时、回复折行数、屏幕高度、配置开关共同判定），经服务端回顾接口取一行屏显回顾并以特殊前缀打印；手动回顾绕过门槛与开关但仍要求模型档案非空；每次新轮次或新会话都推进令牌，迟到应答在令牌过期后丢弃。
- 自动标题：仅在配置为模型生成模式时触发，面向正常完成且非本地锚点的循环，经服务端标题接口生成后改名，空结果保持原样，全程静默尽力而为。
