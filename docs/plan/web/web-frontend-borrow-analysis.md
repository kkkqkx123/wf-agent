# Web 前端可借鉴设计分析（重写版）

> 基于 `docs/ref/frontend` 下三份说明：zcode（Agent IDE 工作台）、deeix（文档型 Agent 工作台）、live-agent（桌面风格与 Web 适配策略）。只借鉴功能与 UI，不照搬技术栈。
>
> 状态说明：旧版称 Web 为空壳已过时。应用壳、主题 Token、基础与领域组件、十个一级路由、REST 客户端、事件流 SSE 均已落地（见 `web-app-ui-implementation-design.md` 重写版）。本文只列剩余可借鉴项。方向已翻转为对话优先，总体方案见 `chat-ide-primary-design.md`，与 TUI 的一致性见 `docs/architecture/app/chat-ide-tui-consistency.md`。

## 1. 剩余可借鉴项

### 1.1 向 wf-tui 借会话语义（最高优先级）

TUI 是本仓库内已验证的对话优先实现，借鉴成本低于外部参考：

- 流式语义：双缓冲、限速合并、流式尾行、尾部跟随可手动接管。
- 队列语义：串行先进先出，生成中可追问，取消走安全点。
- 提及规则：文件、技能、工作流三种解析与高亮，Web 在此基础上加模型与工具两种。
- 审批与提问交互：记住选择、问答卡、命令恢复横幅。
- 执行回放进会话：执行列表选中后切回会话并加载历史。

### 1.2 向 deeix 借对话页打磨

- 页头操作群：内联重命名、星标、标签、分享、导出。
- 输入框：多消息队列、统一提及、拖放浮层、阻断原因提示。
- 轨迹透明：过程与思考与工具手风琴在流式时展开、结束收起，引用徽标，完整结果弹窗。
- 列表页：过滤加星标加标签加批量操作加快捷预览，补足现有只有查询加状态的筛选条。

### 1.3 向 zcode 借工作区编排

- 中心列加多标签边面板：图、迭代、变量、检查点、工具、时间线、分析归属当前会话。
- 草稿与正式任务分离，队列面板管理待发送消息。
- 文件预览与 Diff 与变更面板组合，命令中心统一搜索命令、会话、文件。

### 1.4 向 live-agent 借风格节制

基座已落地，剩余三项：卡片逐项延迟入场、主题切换过渡、设置页左导航加右卡片行。

## 2. 不建议借鉴

- zcode 桌面专属：自绘标题栏、防休眠、未读徽标、静默发行说明。
- deeix 登录与计费外环：密码与 OAuth 登录、多媒体生成、订阅账单。
- TUI 单行输入框形态：属终端约束，Web 做多行组合器。
- 需要新后端才能成立的功能：文件内容编辑、触发器定时启停、技能安装、模板评分、通知收件箱。
