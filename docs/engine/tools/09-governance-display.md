# 09-治理与呈现

> 范围：`approval/`、`protect.rs`、`scope_gate.rs`、`tool_exposure.rs`、`predefined/risk.rs`、`predefined/schema.rs`、`predefined/display.rs`、`predefined/fold/`、`tool_description_generator.rs`、`tool_schema_formatter.rs`
> 定位：工具调用前的审批、分级与调用后的呈现，全部为纯判定逻辑

## 审批协调

审批协调器按工具调用请求逐个判定放行、拒绝或转人工，批量时汇总为自动放行与待决两组。判定顺序为：总开关关闭则全转人工；命名白名单命中则放行；文件权限（敏感与受保护路径的读写、命令字符串中抽取的文件读写）不命中则转人工；写保护命中则拒绝（唯一硬拒绝）；之后按风险等级分支——只读默认放行、写默认转人工、命令按允许/拒绝清单三态判定、网络按允许/拒绝域名表判定、MCP 委托专用策略、系统与交互分别走固定默认。命令审批与引擎命令安全共用同一允许/拒绝清单，避免双源漂移。

## 写保护与路径门

`protect.rs` 维护默认受保护模式表（版本控制、密钥、锁文件、CI、证照等）并支持自定义叠加，判定为纯 glob 匹配。`scope_gate.rs` 是三执行器共用的路径裁决：词汇前缀包含加符号链接逃逸检测，返回界外/界内/逃逸三态并携带物理路径，调用方各自决定 fail-closed 或 lenient 语义。

## 暴露分级与风险

`tool_exposure.rs` 是每轮 schema 装配的唯一依据：隐藏名单最强，其次按次暴露覆盖，再次可发现名单，最后工具元数据的默认直达；可发现非空时自动附加 general 代理。风险分级以各工具定义的等级字段为唯一来源，模块只提供查询（按 id 查等级、按等级列工具）与临时会话的允许/拒绝等级表。

## 呈现与描述

展示层为每个工具结果产出前端载荷（命令尾部、差异标记、计数摘要、文本头部分类），与模型上下文独立。折叠层按工具种类改写模型可见历史（服务文件折叠、合并差异折叠、头尾折叠），节约 token。描述生成器负责可发现工具的元数据列表（名加单行描述加类型化参数表，三档详略），注入占位符；schema 格式化器负责参数结构的 JSON Schema 渲染。`predefined/schema.rs` 是全部预定义工具的单一来源类型，由它同时派生注册表定义与 LLM 描述，保证两者永不同步漂移。
