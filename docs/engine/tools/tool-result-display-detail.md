# 工具调用结果展示详细程度

> 范围：`wf-tools/src/predefined/display.rs`、`wf-types/src/tool/display.rs`、`wf-types/src/tool/background.rs`、`wf-types/src/events/stream_event.rs`（`ToolEnd.display/background`）、`tui-core/src/tool_output.rs`、`wf-tui/src/interactive/tool_blocks.rs`、`wf-tui/src/replay.rs`、`web-app/src/lib/config/tool-output.ts`、`web-app/src/lib/utils/tool-output.ts`、`web-app/src/components/domain/ToolCallCard.svelte`
> 定位：回答“一次工具调用在人眼前展示多少”——引擎产什么摘要、线上协议带什么载荷、各前端按什么档位裁剪。不回答“模型看到多少”，后者见《工具输出特殊处理》与《09-治理与呈现》。

## 总览：双通道与三层

一次工具调用产生两份互相独立的“详细程度”：

- 模型通道：进 LLM 历史的文本，走截断落盘、历史折叠、后台压缩，只求 token 可控与可恢复。
- 展示通道：给人看的摘要，走本文的展示载荷，只求一眼可扫、失败可诊断、检索不刷屏。

展示通道分三层，职责单向流动：

1. 引擎层按工具类别定形，产出小摘要载荷，全文保留在事件旁路。
2. 线上协议把全文与摘要同事件下发，摘要缺席时前端可降级推断。
3. 各前端只做通用裁剪与分组展开，禁止按工具名写特例呈现。

## 引擎侧摘要载荷

引擎为每次调用产出一份前端载荷，含呈现类别、预览文本、是否截断、隐藏行数、调用摘要五项。全文始终保留在同事件的结果字段中，预览只是摘录，点开展示仍可取全文。

呈现类别固定四种，由工具归属决定，不随结果内容变化：

- 命令尾：终端会话族。信号在 recent 行，取结果尾部。
- 差异：文件改写族。优先取结构化结果中的差异字段，大差异只留差异标记行，小差异原文直出。
- 计数：读与检索族（文件读、目录列举、各类搜索、代码检索、网页抓取搜索）。多行结果折叠为一行计数，单行结果保留该行。
- 通用文本：其余一切。取结果头部。

行预算上，命令尾与通用头各取二十五行。该值等于网页端最高档的天花板，保证服务端载荷永远是各前端档位裁剪的上界，前端只向下切，不向上补。单行预览宽度另有字符预算，防止一行超长撑版。

调用摘要纯由参数 JSON 推导，前端永不拼接参数：终端族取命令首行，改写族取文件路径（只留末两段），探索族取模式加路径，其余取首个可读参数。超长值截为单行短串，无参数时为空。路径缩写、首行提取、字符截断三步都在引擎做，前端直接渲染。

后台交接另有一条结构化挂钩：只有真正交出运行会话的四个后台动作且结果中同时带会话标识与后台标记时才产出标记，其余一律为空。标记只含会话标识与后台位，前端据此画后台徽标与任务聚合，不再嗅探结果文案。进模型历史的文本另行压缩为只留会话 linkage 与跟进指引的小对象，大输出不进模型上下文，但流事件中的全文仍供界面渲染。

## 线上协议形态

工具结束事件携带六要素：调用标识、工具名、成功位、全文结果、失败原因、展示载荷、后台标记。后三者均为可选：展示载荷缺席表示老服务端，前端回退到按工具名推断类别；后台标记缺席表示前台工具或老服务端，前端不画后台徽标。成功位决定预览源：失败时错误文本优先，成功时展示预览优先，全文兜底。

## TUI 侧详细程度

TUI 的裁剪收敛在一个运行时阈值结构中，调用处只传工具类别：总开关、通用预览行数与字符预算、命令预览行数、失败预览行数、单块存储摘录字节上限、默认详细级别。默认值通用十行三百二十字符、命令十行尾、失败四行头、单块三十二 KiB。

详细级别与预览长度正交，级别只决定分组与默认展开，不改变预览行数：

- 低档：连续成功的只读探索工具合并为一条活动汇总（如多命令多读多改各计一行），写与命令及一切失败仍逐条可见，不被汇总隐藏。
- 中档（默认）：每调用一行摘要加折叠预览。
- 高档：检索类默认展开，其余仍折叠；落点时明确提示高档会刷屏，中档才是日常默认。

预览变换均为与宽度无关的纯文本函数：通用取头并在末行打省略号，命令取尾并在首行注记省略行数，字符预算按字素切割以保护中文与宽字符，存储摘录按字节上限留尾并在越界时前置省略标记。检索类成功时正文默认隐藏，计数摘要即全部行内故事，全文只在展开器中查看；失败时错误全文优先，错误预览行数有独立预算。摘要行固定由状态符号、工具名、调用摘要、耗时、溢出行数组成，插件模板只能替换括号内的调用部分，无匹配或空模板时回退内置样式。

交互上支持单块展开折叠、全部展开折叠、全文查看器（只读模态）、详细级别循环键、低档活动组冲刷。回放加载器无用户配置可读，固定用默认阈值重演，保证回放行与直播行视觉一致。持久化历史与异构服务端走同一套按名推断回退，与直播的协议载荷路径展示一致。

## 网页端详细程度

网页端把行与字符预算暴露为三档命名预设而非自由数字，避免设置界面难调与极端值藏失败：精简、均衡、详细。均衡与 TUI 默认值对齐，详细取二十五行八百字符即服务端天花板，精简取四行一百六十字。另有展开正文的行上限（网页特有，约束单块 DOM 体量）与失败预览下限（任何档位不低于两行，保证失败可诊断）。检索隐藏规则与错误优先规则与 TUI 一致，跨端行为对齐。

列表分组为纯渲染态推导，不存状态：连续成功的检索合并为读组、连续成功的文件改写合并为改组，其余（命令、失败、未知）各自成行，保证命令尾不被埋进组内。键由成员标识派生，直播追加时折叠组不抖动。卡片头为工具名加计数或溢出行数、子智能体、后台、耗时与状态徽标；展开后分输入、输出两区，差异行按增删 hunk 着色，ANSI 按段着色，超长输出先行内截断再给对话框看全文。

## 轻量终端现状

轻量终端目前无工具块详细程度配置，不消费展示阈值，仅复用摘要模板与快照 Markdown 规则做轮次渲染。工具结果在该端保持行内简写，不做折叠分组与查看器。

## 配置与持久化

TUI 配置文件中的工具输出节全字段可选，缺文件或缺键逐项回退内置默认；详细级别可在运行时按键循环并即时生效。网页偏好持久化详细档位与预览总开关。损坏的偏好值回退均衡档，不破坏渲染。

## 设计不变量

- 呈现知识只存引擎：新工具只需选最接近的四种类别，前端不新增匹配分支。
- 服务端载荷是天花板：前端只向下裁剪，不向上补行。
- 级别管分组展开，预算管预览长度，两者不互串。
- 错误永远有独立下限行数，不被精简档藏掉。
- 检索默认隐藏正文，命令默认留尾，改写默认留差异标记。
- 后台 linkage 靠结构化标记，不靠文案匹配。

## 新工具接入

先判定呈现类别：产命令输出的归命令尾，产改写的归差异，产读与检索的归计数，其余归通用文本。调用摘要若需特殊命名，在引擎的摘要推导中加分支，前端无需改动。超出常规体量的新输出若需进模型通道的落盘或折叠，另按《工具输出特殊处理》的可寻址三类走准入，不在此文加第四套措辞。
