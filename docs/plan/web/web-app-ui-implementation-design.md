# Web App 样式、布局与组件实现方案（重写版）

> 目标：记录 `apps/web-app` 已落地的样式与布局基座，并给出剩余任务清单。本阶段性文档不再复述已完成的实施细节，只保留约束与验收口径。
>
> 上游依据：`frontend-feature-list.md`（功能边界）、`web-frontend-borrow-analysis.md`（借鉴结论重写版）、`chat-ide-primary-design.md`（对话优先翻转方案）、`web-app-streaming-markdown-design.md`（流式方案重写版）。

## 1. 已落地（不再展开）

- 样式基座：Tailwind v4 加 HSL 通道 Token，浅深两套语义色，统一缓动，细滚动条，受限毛玻璃，无障碍降级，预注水防闪烁。
- 应用壳：双栏加检查器（宽屏停靠、窄屏转抽屉），侧栏折叠与宽度记忆，命令面板，Toast，骨架与空态。
- 组件库：基础原语、布局组件、领域组件三层，变体集中管理，未知状态中性兜底。
- 十个一级路由：执行、工作流、回路、检查点、触发器、资源、模板、洞察、事件、设置，外加三组详情路由。
- 数据层：样例 fixtures 已全部替换为 API 客户端加领域服务，无残留；REST 拆包、鉴权注入、事件流 SSE、地址栏状态回写均已接通。
- 工程约束验证通过：类型检查、lint、格式、构建、路由可访问、无硬编码颜色。

## 2. 剩余任务

### 2.1 流式 Markdown 渲染

详见 `web-app-streaming-markdown-design.md` 重写版。含依赖引入、POST SSE 客户端、流存储、渲染组件、推理块与工具节点、与三条执行流的对接。

### 2.2 对话优先翻转

详见 `chat-ide-primary-design.md`。含根重定向改对话、侧栏改会话分组、输入组合器、追问队列、边面板标签化、工作台降级为中心列模式。

### 2.3 错误态组件

各页面现有空态与加载态，缺统一错误态（含重试）。随首个流式页面一并补齐，不单独立项。

### 2.4 长列表虚拟化

`DataTable` 预留列模型，未实现虚拟化。超过 200 行启用，阈值集中配置。大 dump 通道响应有界，前端配合虚拟化。

### 2.5 命令面板统一搜索

当前检索导航加三类实体直跳。待接入后端统一搜索通道后，合并为命令、会话、文件统一搜索加预览加直接执行。

### 2.6 图可视化选型

当前为内联 SVG 占位渲染。待图编辑需求明确后，在自研 SVG、D3、ECharts 之间定型，避免提前锁死。

### 2.7 主题色元标签例外收敛

首绘前脚本中的深浅两枚颜色字面量（`src/app.html`）因元标签不接受 CSS 变量而保留。后续收敛到一处常量并注明例外，不再扩散。

### 2.8 产品外环

分享导出、截图为图、大纲与位置导轨、设置页重组、空态推荐，按翻转方案的最后一步推进。

## 3. 保持有效的约束

- 代码、注释、日志、错误信息一律英文，禁止中文入代码。
- 注释只描述代码意图，禁止出现文档结构标识符。
- 格式化沿用 tabs 缩进加单引号。
- 不手写契约类型，视图模型与契约类型分离。
- 链接必须经路由解析函数，禁止裸字符串回退。
- 颜色只能来自 Token，唯一例外为第 2.7 节。

## 4. 验收口径

- 类型检查、lint、格式、构建四项全绿。
- 路由可访问，无白屏；深浅色切换无闪烁，偏好持久化恢复。
- 组件内无硬编码颜色；未知状态值有中性兜底。
- 流式页面逐帧消费正常，错误与关闭有处理；长列表虚拟化达标；移动端断点可用。
