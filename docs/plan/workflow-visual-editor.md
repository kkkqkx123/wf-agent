# 图工作流可视化编辑器改造方案

配套分析：`docs/analysis/n8n-workflow-visualization.md`、`docs/analysis/wf-agent-analysis.md`。
范围：把 `apps/web-app` 的只读图查看器升级为可编辑的工作流画布，对标 n8n 画布的编辑能力。

## 现状事实

- 视觉编码集中在 `apps/web-app/src/lib/graph/display-model.ts`：三种预设、形状判定、状态色、大图截断、决策图列式坐标。后端只给纯拓扑，该原则已在注释中明确。
- 渲染在 `apps/web-app/src/lib/components/domain/GraphCanvas.svelte`：cytoscape 动态加载，四种通用布局，交互只有点选、双击展开邻居、框选、缩放、导出。无拖拽移动落盘、无手柄连线、无新建节点。
- 外壳在 `apps/web-app/src/lib/components/domain/GraphExplorer.svelte`：过滤、叠加高亮、选中详情、图例、大图折叠。
- 工作流详情页 `apps/web-app/src/routes/workflows/[id]/+page.svelte` 编辑按钮明确禁用，草稿只有拓扑预览。
- 后端已就绪：`wf-workflow` 有完整校验规则集与结构分析，`wf-server` 有草稿保存、校验、晋升接口与图查询接口。缺的是前端编辑态与服务端强校验的联动。

## 设计目标

- 同一画布支持查看与编辑两种模式，默认查看，显式进入编辑。
- 画布库只负责绘制与发出意图，所有状态变更归 store，保证单一数据源。
- 编辑结果经草稿链路保存，保存即触发服务端校验，晋升复用现有晋升接口。
- 不引入第二套图状态，不新建替代模块，所有改造在原模块上按职责拆分。

## 1. 投影层改造

- 在 `display-model.ts` 内按职责拆分，不另起替代文件：
  - 语义投影：输入工作流拓扑、执行态、校验结果，输出每节点的展示状态、问题标记、脏标记，每条边的展示状态。
  - 几何映射：把投影结果转为 cytoscape 元素定义，保留现有形状、虚线、状态色函数作为第二阶段工具。
- 投影为纯函数，无副作用，便于单测。执行、校验、编辑三路数据独立更新，画布只消费最终投影。
- 节点渲染类型由字符串分支改为枚举分发，预留便签、触发器、Agent 卡等扩展点。枚举值描述节点做什么，不做版本比较命名。

## 2. 受控编辑模式

- `GraphCanvas.svelte` 增加编辑模式开关：
  - 查看模式保持现有行为，布局自动运行。
  - 编辑模式关闭自动重排，节点拖拽只发意图事件，不直接改库内状态。
- 新增编辑 store，持有可编辑图、选中、脏标记与撤销重做栈：
  - 监听画布意图（移动、建边、删边、增删节点），写回 store 后重新同步元素。
  - 历史栈按操作合并拖拽过程事件，只压入最终位置。
  - 脏标记按节点粒度计算，用于离场提示与保存按钮使能。
- `GraphExplorer.svelte` 增加编辑工具条插槽：进入编辑、撤销重做、保存草稿、校验、晋升、退出。查看态工具条保持不变。
- 交互分阶段落地：
  - 第一阶段：拖拽移动、框选删除、双击空白建节点、边点击删除。
  - 第二阶段：手柄连线、右键菜单、快捷键、节点内嵌参数入口。
- 手柄连线在 cytoscape 中用节点覆盖层与自定义事件模拟，不引入新的画布引擎。

## 3. 布局升级

- 工作流预设改用分层有向图布局，替代现有通用宽度优先布局。决策预设保留按迭代分列，执行预设复用工作流布局再叠加状态。
- 布局函数放在 `display-model.ts` 同目录的新职责文件，按预设分发：
  - 连通子图拆分后并排，避免不连通分支挤在一起。
  - 工具调用链视为纵向子图，先独立布局再嵌入父图包围盒。
  - 结果按网格对齐，保证连线轴对齐。
- 引入第三方分层布局库时版本锁定在 1，不做版本升级。坐标仍只存前端，后端继续只存纯拓扑。

## 4. 草稿链路打通

- 工作流详情页新增编辑 Tab，复用现有草稿接口：
  - 进入编辑时从当前正式定义创建草稿快照，或复用已有草稿。
  - 保存走草稿保存接口，保存后立即调用草稿校验接口，问题按节点回填到投影层。
  - 校验通过后允许晋升，晋升成功刷新详情与版本列表。
- 模板库工作流模板增加在画布打开入口，模板保存后可直接跳转到工作流详情编辑态，避免模板与画布长期割裂。
- 版本对比保留文本差异，可点击差异项在画布中定位对应节点，为图形化差异留接口。

## 5. 后端配合

- 草稿保存接口已存在，无需新接口。前端保存时提交完整定义，后端覆盖存储。
- 校验接口已存在，前端需把校验问题映射到节点字段级提示，而非仅整单提示。
- 图查询接口保持纯拓扑返回，不接受坐标字段。布局漂移不回写后端。
- 晋升接口保持不变，晋升前必须通过校验，未通过时禁止晋升并给出节点级错误。

## 落地顺序

1. 投影层拆分与渲染类型枚举，画布只消费投影结果。
2. 受控模式与编辑 store，跑通拖拽移动与保存草稿闭环。
3. 分层布局替换宽度优先布局，决策列式布局保持兼容。
4. 草稿校验回填与晋升打通，模板到画布入口。
5. 手柄连线、右键菜单、快捷键作为第二阶段。

## 验收标准

- 查看模式行为不变，现有过滤、叠加、大图截断、导出均可用。
- 编辑模式下拖拽、建边、删节点可保存为草稿，刷新后草稿预览一致。
- 保存后服务端校验问题能定位到节点，晋升成功后版本列表更新。
- 撤销重做覆盖移动、建边、删除三类操作。
- 全量编译检查通过，不引入新的顶层替代模块。
