# 端到端验证

> 范围：`e2e/`，以 `wf-headless` 为客户端驱动的服务端集成测试载体
> 设计说明见 `docs/tests/`

## 前置

同步构建产物到 `e2e/bin`，验证脚本启动前会检查产物是否存在。

## 常用操作

先同步产物，再运行默认门禁；本地执行层不支持的環境可附加跳过标志，服务端进程默认随验证结束而终止，保留运行可附加保持标志。真模型会话不进入门禁，需要时按脚本提示手工执行。

## 目录

- `bin/`：同步来的可执行文件，不入库
- `fixtures/`：版本化输入数据，见其目录说明
- `outputs/`：黄金与实际输出，见其目录说明
- `lib/common.sh`：端口选择、健康等待、调用封装等公共辅助
- `sync-bin.sh`：复制构建产物并确认版本
- `run-e2e.sh`：启动隔离服务端、串行执行用例、收集输出、清理进程
