# Web App 实施方案 - 第三阶段

## 阶段目标

在核心三域之外扩展剩余后端驱动域：完成实时通道（SSE + WS）全覆盖，交付检查点与文件、审批与交互、触发器与钩子、模型与工具与脚本与技能、模板库。

## 范围与前提

- 前提：第二阶段核心闭环与 `sse.ts` 流读取器已验收。
- 功能边界：权威清单第 3.4–3.7 节与第 4 节。
- 不包含：查询与审计、事件与系统、设置、命令面板、性能与移动端（阶段四）；不做无后端通道的功能（见权威清单第 5 节非目标）。

## 一、实时通道全覆盖

### 1.1 SSE 补齐

在既有流读取器上接入剩余端点：

- 全局事件流 `GET /events/stream`：支持 `executionId` / `agentLoopId` / `workflowId` / `since` 过滤；处理首帧 `connected`、30s keepalive 注释帧、客户端上限 503。
- 大模型流式试算 `POST /llm/generate-stream`：含 `event_type=error` 错误帧处理。
- 错误分析流 `GET /executions/{id}/error-analysis/stream`：无错误时为空流，页面给出空态而非加载中。

### 1.2 WebSocket 接入

- 落地 `src/lib/api/ws.ts`：连接管理、`subscribe` / `unsubscribe` / `ping`、30s 心跳、断线重连、鉴权（头或 `api_key` 查询参数，拒绝关闭码 4001 的可读提示）。
- 订阅维度：执行、回路、工作流三主题 + notifications；负载为元数据，详情按需 REST 补拉。
- 多执行并行订阅在此落地；全局主题与通知通道后端缺失，用多订阅合并模拟，不自创协议。
- WS 帧类型独立维护（OpenAPI 刻意不含 WS），与 `schema.d.ts` 分离。

### 1.3 流式通用约束

- 渲染限速合并、长列表虚拟化、自动跟随尾部可手动接管（组件规范消息滚动器）。
- SSE 与 WS 选用：简单日志与时间线用 SSE，多执行并行订阅用 WS。

## 二、检查点与文件

### 2.1 执行检查点

- 创建、链查看、恢复与续跑（含分支与原地模式，按后端参数）、删除、统计；按实体与时间范围查询、元数据读写。
- 对比预览复用文件差异通道，不自建比较模型。

### 2.2 文件工作区

- 分区、按 Actor 与路径的变更列表、重建元数据、差异（双 Actor 与暂存）、时间线、会话创建与回滚、撤销重做、重命名、回收。
- 审批：待审批列表、批准与拒绝，接入全局审批入口（检查器标签 + Toast）。
- 文件内容读写与目录树：后端只读通道（内容、目录树、分页变更）只做展示；**不做文件编辑器**。
- 差异查看组件：单文件与多文件共用同一组件，大差异分页加载（组件规范）。

## 三、审批与交互

- 审批：请求列表与检查、工具执行审批（`/approvals/*`），审批卡包含请求上下文、风险提示、批准/拒绝双操作与结果追溯。
- 交互：按执行与状态的交互列表、响应提交、统计、批量响应；回路维度的交互入口挂在回路详情。
- 交互与审批的未读徽标：暂为前端本地派生（无通知通道），集中封装以便后端补齐后替换。

## 四、触发器与钩子

- 触发记录：列表、统计、按执行 / 触发器 / 工作流过滤、清理。
- 钩子试发：按钩子名发送测试负载并展示结果；幂等键由前端生成；注意钩子鉴权（`x-hook-token` / Bearer）与 API key 通道分离，错误提示区分。
- 不做触发器启用停用与定时启停开关（后端未提供）。

## 五、模型与工具与脚本与技能

- 模型档案：增删改查、默认设置、导入导出、从模板创建、校验；档案模板查询；供应商与模型列表。
- 生成试算：单次、批量、Token 计数、流式（走 SSE 补齐项）；用量与成本按分析指标展示，不自算价格。
- 密钥展示遮罩，前端不回显密钥原文。
- 工具：列表、搜索、详情、执行、参数校验、启用停用、注册表增删与统计；调用卡按注册表类型渲染，未知类型兜底原文展示。
- 脚本：列表、搜索、执行、校验、启用停用。
- 技能：列表、查询、启用禁用、扫描重载、缓存清理、提示词查看；不做安装与版本管理。

## 六、模板库

- 节点与触发器模板：增删改查、导入导出。
- Agent 与 Agent 触发模板：列表、摘要、精选与热门、使用与克隆。
- 工作流与 Agent 注册表：查询、精选热门、使用与克隆。
- 不做评分评论与发布流。

## 八、验收标准

- 5 个 SSE 端点与 WS 均有页面消费；断连、429、503、鉴权拒绝均可读可重试；关闭页面无残留连接。
- 检查点恢复续跑、文件会话回滚、审批双操作端到端可用，危险操作二次确认。
- 工具与差异等重型组件对未知类型 / 大数据不崩溃（兜底渲染、分页、虚拟化）。
- 所有列表遵守游标或封顶约定；无手写响应类型；密钥不回显。
- `check` / `typecheck` / `lint` / `test` 全绿。

## 九、风险与应对

- **WS 与 SSE 双通道状态机**：连接状态收敛到单一 store，页面只订阅投影，不各自管理连接。
- **未读徽标双源**：本地派生集中一处封装，接口形状与未来通知通道对齐。
- **钩子与 API 两套鉴权混淆**：错误归一层区分两者，提示文案明确来源。
