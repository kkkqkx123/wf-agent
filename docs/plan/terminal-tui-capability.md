# 终端 TUI 能力改造方案

目标：独立终端页正确承载 TUI 程序（含 lazygit），使终端配合即可完成全部 git 操作；原完整 git 页不再保留，是否改为 vscode 风格并内联到 IDE，待终端页实际效果验证后再定，本方案不动 git 页。

约束：只改原有模块，不新增替代模块；不新增后端接口；文案复用现有 i18n 键；缺 lazygit 不是降级条件，普通 shell 照常用。

## 结论

渲染层零障碍，后端透明字节管道与 xterm 默认行为已覆盖。改造收敛为五项加一个入口，无需保证之外的兜底。

## 改造项

### 按键绑定

浏览器保留键是唯一硬顶，不可拦截。lazygit 缺省键位与保留键的冲突通过随附的键位重映射预设解决，不改代码。预设覆盖方向为避开关闭标签页、新建标签页、标签页切换、地址栏聚焦与整页刷新刷新相关的组合，其余单键与控制组合保持 lazygit 缺省手感。

应用内冲突已核查：终端页自身无全局监听；Git 页全局监听已豁免终端焦点；应用壳全局热键库缺省跳过输入框（含终端隐藏输入区），无需改动。仅 IDE 页快捷键需补终端豁免，因其保存与关闭绑定在嵌入式终端聚焦时仍会触发并吞掉按键。

### 区域选择

双模式复用同一份复制逻辑：鼠标跟踪关闭时走浏览器原生选中，开启时走 Shift 加拖拽强制选中。粘贴补上括号粘贴模式感知：跟踪应用的 2004 模式开关，开启时包裹粘贴起止标记后发送，否则保持裸文本直发。跟踪只做观察，不接管模式设置本身。

### 中文显示

后端语言环境已为 C.UTF-8，xterm 宽字符处理已对，仅字体栈缺中文字体回退，补系统级中文字体回退即可。

### 鼠标操作

协议层齐备，后端透明透传，lazygit 的点击加滚动需求在覆盖范围内。现有三个前端监听器经核查均不挡路：指针按下只做聚焦且不截断传播，点击拦截仅作用于无修饰键的链接点击，复制粘贴走事件级。触屏不做保证，超出目标范围。

### lazygit 入口

终端页新增快速命令入口，一键在工作区根起 lazygit 会话。目标环境缺 binary 时会话直接退出并走既有断线提示，用户仍在普通 shell 中，无需特殊处理。

## git 页去留

本方案不动 git 页。待终端页验证通过后，再决定删除或改为 vscode 风格内联到 IDE，另立项。

## 落地状态

改造项均已在原有模块内完成：IDE 快捷键补终端焦点豁免；粘贴补 2004 模式感知包裹；字体栈补中文字体回退；终端页新增 lazygit 快捷入口；应用壳全局热键经核查缺省跳过输入框，无需改动。类型检查零错误零警告，相关单测 57 项通过。git 页未动，去留待验证后另立项。

## 验收

IDE 内嵌终端聚焦时快捷键不再吞键；TUI 输入框多行粘贴不再被拆成回车；中文提交信息无豆腐块；一键起 lazygit 可用，缺 binary 时退化提示清晰；类型检查与单测通过。
