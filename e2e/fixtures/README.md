# 输入固件说明

> 范围：`e2e/fixtures`，版本化入库

| 文件 | 用途 | 使用层级 |
|------|------|----------|
| `workflow-minimal.json` | 仅含起止节点的最小流程定义 | 工作流生命周期用例的默认输入 |
| `workflow-script.json` | 含单个脚本节点的本地流程定义 | 本地执行层专用输入，不依赖外部大模型 |
| `workflow-input.json` | 执行输入对象，兼作非法定义文件的否定输入 | 执行触发与校验失败用例 |
| `script-echo.json` | 脚本注册元数据，本地执行层的前置注册输入 | 本地执行层专用输入 |
| `workflow-update.json` | 同标识更新定义，描述变更用于更新语义断言 | 工作流扩展层专用输入 |
| `prompt-smoke.txt` | 手工真模型会话提示词 | 仅手工运行，不进入默认门禁 |

固件遵循最小可用原则：管理链路只用最小流程，避免与脚本注册表耦合；执行层单独使用脚本流程，环境不支持时明确跳过。新增用例需要新输入时，在此目录新增具名文件并在此表登记，不复用已有文件的副作用。
