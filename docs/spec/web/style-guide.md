# Web 前端风格与样式规范

> 适用 `apps/web-app`（SvelteKit 加 Svelte 5 加 Tailwind）。风格取向沿用既有结论：桌面级、克制、深色优先。配色思路借鉴 deeix 的 Token 结构与 zcode 的状态语义覆盖，数值以本规范为准。

## 1. 主题模型

- 支持浅色、深色、跟随系统三模；预设至少保留默认一套，新增预设不得改变语义 token 的映射关系，只允许替换底色与强调色。
- 主题切换通过根属性表达并同步系统配色声明；首屏必须预注水，避免浅色闪烁。
- 品牌就绪前隐藏正文的阻塞行为仅在依赖远端品牌时使用，默认本地主题不得阻塞渲染。

## 2. Token 分层

| 层 | 内容 | 规则 |
|---|---|---|
| 底色 | 背景、侧栏、面板、卡片、浮层、输入 | 浮层必须高于卡片，输入必须区别于背景，禁止同值复用 |
| 文字 | 前景、次要、静音、禁用 | 静音仅用于辅助信息，禁止作为可操作控件的主文案色 |
| 边框与聚焦 | 边框、聚焦环 | 边框使用低透明度，聚焦环必须全主题可见 |
| 强调 | 主色、成功、危险、警告、运行中、排队 | 状态色与终端输出色解耦，图表色独立成组 |
| 域语义 | 执行状态、变更类型、提及类型、轨迹类型 | 新增域语义色必须登记，不得复用通用强调色 |
| 形状与阴影 | 圆角、阴影、间距 | 圆角档位收敛为三档以内，阴影只用于浮层 |

## 3. 排版

- 基准字号固定，正文、说明、小字三档为主；极小字仅允许坐标轴与图例使用。
- 等宽字体用于标识、路径、代码、键值；中西文混排必须保证中文回退字体。
- 对话与审计正文使用独立排版样式，与界面文案分离；标题内联编辑态必须保留可聚焦轮廓。

## 4. 布局与密度

- 三栏 Shell 宽度：侧栏固定窄栏可折叠为图标，中心列居中限宽，右侧检查器可调并记忆尺寸。
- 密度 single：行高与内边距只设常规与紧凑两档，紧凑仅用于表格与时间线。
- 窄屏阈值自动折叠右侧检查器再折叠侧栏；移动端侧栏转抽屉，表格转卡片。

## 5. 动效

- 动效只用于状态传达：思考态渐变、流式进入、脉冲高亮、倒计时填充。
- 时长收敛为快慢两档；尊重简化动效偏好，命中时一律改为静态。
- 滚动条细型圆角；终端与重型预览内隐藏滚动条；滚动遮罩只做首尾渐隐，不得改变可点击区域。

## 6. 状态呈现

| 状态 | 呈现要求 |
|---|---|
| 加载 | 骨架屏，波纹方向一致，禁止布局跳动 |
| 流式 | 占位 shimmer，结束后替换为正式内容 |
| 空 | 插画加一句话加主操作，不得只显示空白 |
| 错误 | 错误码加人话加重试，禁止裸异常文本 |
| 危险操作 | 二次确认，删除事件类操作必须输入确认或双重点击 |

## 7. 禁止事项

- 禁止引入与主题无关的硬编码色值；所有颜色必须走 Token。
- 禁止为单个页面自创圆角、阴影、动效时长。
- 禁止用颜色作为唯一状态区分；状态必须配文字或图标。
- 禁止在注释中引用本规范的章节编号，注释只描述样式意图。
