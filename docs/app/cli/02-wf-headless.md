# 02-wf-headless 无头二进制

> 范围：`crates/app/cli/wf-headless`（`wf-headless` 二进制）与 `crates/app/cli/wf-cli-shared` 中的无头链路
> 定位：共享逻辑的薄入口，不含任何交互界面，面向脚本与自动化

该 crate 只有一个二进制目标：解析顶层参数并移交共享库的无头专用入口，失败时向标准错误打印错误并按共享错误映射的退出码退出。自身不实现会话、渲染或管理命令，全部行为由共享库提供。

## 与共享库的分工

二进制只做参数解析与进程级错误收敛：成功路径完全委托共享库，错误路径统一转换为人类可读的标准错误行与退出码。这种划分使无头形态的行为与其它形态共用同一实现，新增子命令无需在此追加分发。

无头专用入口与通用入口是同一分发逻辑的两种称谓，保证无头判定与实际分发不会随演进分叉。判定上所有子命令均为无头，管理类子命令在此直接执行，单次会话子命令走无头会话管线，诊断子命令走模式展示，全屏探针在此明确拒绝并指引使用全屏二进制。

输出路由集中在共享库：单次会话经输出槽扇出到标准输出与日志文件，执行域经信封与逐行 helper 同时落标准输出与日志文件，其它管理域直写标准输出。颜色开关按终端与重定向自动收敛。

## 运行行为

无头形态是非交互的单次语义：一次调用执行一条命令或一轮会话后即退出，不保留跨调用状态。

### 前台阻塞

单次会话默认前台阻塞到终态事件：流式优先、阻塞调用回退双通道驱动，业务失败与中断分别映射退出码，诊断走标准错误。工作流无修饰执行同步阻塞，等终态观察与日志跟随以事件流为主、轮询为降级阻塞到终态， control-c 映射为中断退出。

### 后台运行

进程级后台交由外部编排，命令行不内置守护与 pid 文件。服务端后台仅工作流具备：单次会话与统一执行外观各提供一个后台开关，经工作流后台接口立即返回执行标识并退出，服务端在独立任务中排空流到终态，调用方后续以标识接回。智能体转向无对应服务端后台接口，不提供后台开关。

常用接回组合为后台下发后用等终态观察确认状态、用日志分页与跟随回放过程、用展示与状态与历史检视补齐细节。

### 文件输出

单次会话的日志文件扇出经输出槽同格式双写。执行域的信封渲染与逐行打印经调用方配置 helper 同时追加日志文件，流式增量无换行逐块同步追加并在终态刷盘，静默格式两端都不写。日志文件写入失败按配置错误退出，不静默丢弃。其它管理域暂直写标准输出，需落盘时使用外部重定向。文本布局与信封名不受落盘影响，管道与脚本消费无需调整。

### 输入与会话选项

提示词来源支持位置参数与管道输入；交互式问答模式下标准输入转为应答通道，因此要求位置参数提供提示词，避免提示词与答案争用同一输入。交互式应答与全盲批准互斥，应答超时仅限交互式且超时即拒绝审批并取消问答。

单次会话支持智能体与模型选择、可重复批准前缀、超时预算、结构化上下文及其文件来源；智能体转向独占图片、远端图片、附件、细节档位与工作区隔离，工作流转向独占工作流标识与三层输入合并，位置提示词不可与工作流标识同用；单次远端覆盖仅作用于本轮；工作区隔离在连接前重定位本次工作目录。

输出延续共享纪律：业务内容走标准输出并支持文本与 JSON 与 JSON 行与静默四档格式，诊断走标准错误。管道与重定向下颜色自动关闭，机器消费无需额外清洗。

## 适用场景

适用于持续集成、定时任务、管道组合与一次性管理操作。需要多轮记忆、行内建议或全屏检视时，应使用行式会话或全屏形态；需要探查终端能力时，应使用全屏二进制的终端探针；需要离场长任务时，应使用工作流后台开关下发后接回。

### 单次会话与诊断

单次会话与诊断形态不属于管理命令，走独立管线而非按域分发。

- 单次会话：位置提示词缺省时，非 TTY 下消费标准输入全文作为提示词；支持智能体与模型选择、可重复批准前缀、超时预算、结构化上下文及其文件来源；智能体转向独占图片、远端图片、附件、细节档位与工作区隔离，工作流转向独占工作流标识与三层输入合并，位置提示词不可与工作流标识同用；交互式应答与全盲批准互斥，应答超时仅限交互式且超时即拒绝审批并取消问答；单次远端覆盖仅作用于本轮；后台开关仅限工作流转向，要求工作流标识且拒绝交互式问答，返回执行标识后退出并用观察与日志接回。
- 模式诊断：打印当前形态、输出格式与两侧 TTY 状态及日志文件。
- 终端探针：验证终端守卫进入与恢复、外置命令窗口与主题探测，支持切换全屏模式集与指定外置命令；无头构建中明确拒绝并指引使用全屏二进制。

### 执行与工作流

统一执行外观先按智能体后按工作流回退解析，工作流域面向定义与版本，分析臂复用共享分析构造器。

- 运行中智能体循环的输入追加、默认追加模式设置、堆积追问转转向；工作流执行下属循环的列出、节点级追加、节点级模式设置、节点级待定转换；已完成循环的按时间清理。
- 工作流定义的列表、展示、图结构与汇总与环路与拓扑与可达与邻居检视、创建、更新、删除、克隆、校验、导出、导入、版本管理、回滚、执行图与路径与慢节点与效率与概率与备选路径分析；版本下属列表、展示、升级、差异、变更日志。

检查点覆盖状态记录、文件分区与智能体循环三类，审批面向文件检查点审批接口；运行时工具调用审批由会话中的交互应答器回答，不走审批命令。

## 实现

- 薄入口：二进制解析顶层参数并移交共享无头专用入口，错误收敛为标准错误行与退出码。
- 形态判定：显式全屏优先，单次会话子命令次之，强制无头与非 TTY 标准输出依次兜底，交互式 TTY 默认全屏。
- 会话管线：请求体装配、流式与阻塞双通道、事件渲染、终态汇总与退出码；后台分支在输入校验后经服务端后台接口立即返回。
- 输出层：格式层与目标层正交，内存槽服务交互形态，文件槽与扇出槽服务无头落盘；执行域信封与逐行输出经调用方配置 helper 双写。
- 连接层：统一连接句柄解析远端与凭据与目录作用域，所有命令经运行中服务提供。
- 观察链路：事件流为主、轮询为降级的等终态与跟随实现，终端事件判定与服务端订阅一致。

## 无头约束

- 全屏开关不可与子命令同用，强制无头开关不可与会话恢复类选项同用。
- 顶层智能体与模型选项仅限交互形态，子命令中的单次会话使用自身的同名选项。
- 会话恢复类选项仅限交互形态，不可出现在子命令中。
- 工作区位置参数仅限交互形态，子命令必须使用显式目录旗标。
- 历史文件路径与禁用互斥，工作流输入类选项要求工作流标识，图片附件与结构化上下文仅限智能体转向。
- 超时必须为正，工作区目录不可为空，工作区隔离名称仅接受纯目录名。
- 后台开关要求工作流标识且拒绝交互式问答，应答超时仍要求交互式。

## 支持的命令清单与具体用法

以下按调用方式整理，参数细节以共享逻辑文档为准，完整旗标以各命令帮助为准。

- 单次前台：位置提示词执行智能体，管道输入在缺省时作为提示词；工作流前台用工作流标识加三层输入合并，位置提示词不可同用；交互式问答要求位置提示词，标准输入转为应答通道。
- 单次后台：工作流后台开关返回执行标识后退出，文本打印标识行，结构化携带标识与后台标记；要求工作流标识且拒绝交互式问答；后续用等终态观察确认状态，用日志分页与跟随回放过程。
- 执行下发：统一执行外观的下发支持同步、流式跟随、后台立即返回三种形态；后台返回标识后退出，流式逐行打印事件并在终态收尾。
- 执行观察：等终态观察支持单次与跟随，日志支持分页类型过滤与跟随，状态支持存活与持久回退，细节支持变量流转调用栈上下文，层级子树历史仅文本直排。
- 执行生命周期：取消暂停恢复面向运行中执行；删除面向终态记录；运行中循环支持追加与模式与待定转换，工作流嵌套循环支持列出与节点级操作。
- 工作流定义：列表展示图结构创建更新删除克隆校验导出导入版本回滚；版本下属列表展示升级差异变更日志。
- 检查点与审批：状态记录覆盖创建列出展示打标差异恢复删除链路回收；文件分区覆盖创建分区历史改名健康变更差异时间线会话撤销重做工作区文件树冲突解决内容读取恢复清理送审合并；审批覆盖待审批准驳回。
- 实体工具链：技能变量消息任务工具脚本模板触发器均按列表展示与变更动作组织，破坏性动作受统一确认门控。
- 模型配置：档案供应商模板认证代理凭证按列表展示与变更动作组织，口令不落输出。
- 可观测检索：审计事件指标分析统一检索查询按执行标识与过滤组织，分页与聚合参数显式传递。
- 系统远端：健康诊断透传，工作区展示目录归属，展示配置导出导入，远端主机注册列表隧道启停拉包，插件状态批准。

常用组合为前台单次直接运行，离场任务用后台下发加观察与日志接回，管理操作用列表展示定位后执行变更，文件落盘用日志扇出或外部重定向。
