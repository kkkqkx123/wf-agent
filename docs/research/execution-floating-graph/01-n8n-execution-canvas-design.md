# n8n 执行画布设计参考

本文记录 n8n 侧与浮窗式执行查看相关的设计事实，作为当前项目方案的对照。信息来源为 ctx7 文档查询与本地浅克隆副本，所有路径指向 `docs/ref/n8n` 快照。

## 1. 查询来源

- ctx7 文档库 `/n8n-io/n8n-docs`，查询词包括执行预览、画布覆盖层、日志面板。
- ctx7 代码库 `/n8n-io/n8n`，用于确认执行状态枚举。
- 本地副本 `docs/ref/n8n/packages/frontend/editor-ui/src/app/layouts/WorkflowLayout.vue` 与执行视图目录。

## 2. 画布为主，执行为附属面板

n8n 的工作流布局把画布作为主界面，执行信息以插槽形式附着在画布周围，而不是与画布互斥的页面。

- `WorkflowLayout.vue` 把日志面板作为具名底部插槽常驻画布下方，画布始终可见，日志面板可折叠、可调高度。
- 画布-only 模式说明文档明确列出保持可见的三项：工作流画布与其节点、可在屏幕顶部浮动的页签栏、显示单个节点执行日志的日志面板。
- AI 助手制品视图中，日志面板在工作流运行开始时自动打开，成功时折叠，失败时保持打开，并尊重用户在本会话中的手动折叠。

对当前项目的启发：执行进度不需要独占一个 Tab，自动开合策略可以按运行结果区分，手动操作优先于自动策略。

## 3. 执行预览与调试闭环

- 嵌入式画布视图支持发送新的预览消息，在不加载真实节点输出数据的情况下渲染每个节点的执行状态，包括成功、失败与取消，节点输出列可以用轻量模式近似展示。
- 执行预览头部展示标题、投票、状态、执行元信息、数据量、执行编号与工作流版本链接。
- 动作区区分成功与失败：成功时提供复制到编辑器的次要操作，失败时提供在编辑器中调试的主要操作；重跑下拉提供当前工作流与原始工作流两种选项。
- 从执行数据存储中读取脱敏信息，防止钉选数据时泄露。

对当前项目的启发：浮窗至少要回答执行基于哪个定义版本，成功与失败的操作权重不同，重跑需要区分当前定义与原始版本。

## 4. 日志面板的布局与交互

- 日志面板支持上下与左右拖拽调整，布局包含顶部调整条、右侧可调宽的聊天消息面板、主区概览面板与详情面板。
- 键盘映射包括下一条、上一条、清除选中、方向键、展开，以及弹出态下的输入输出切换。
- 概览行使用树形语义，逐级回溯父节点生成缩进连接线；未结算行的时间文本按秒跳动；运行中使用动画 spinner。
- 执行摘要按秒刷新，运行与等待中显示已持续时长，结束后显示总耗时。

对当前项目的启发：浮窗展开后不需要重复完整日志，只需要保留可定位到完整日志的入口；实时跳动的时间适合放在浮窗进度条，不适合放在大图节点上。

## 5. 状态字典

- 全局执行列表为八种状态映射图标与颜色：崩溃与错误为危险色叉圈，等待为沙漏，成功为绿色对勾，新建为虚线圆，运行为 spinner，未知为问号，取消为斜线圆。
- 错误状态控制整行危险背景，停止时间使用本地化计时格式化。
- 通过命令行查询确认执行状态枚举为取消、错误、运行中、成功、等待五种。

对当前项目的启发：状态表达需要图标加文案双通道，颜色不能是唯一区分手段；列表层面的扫视效率来自整行语气，而不仅是徽标。

## 6. 可借鉴与不可照搬

- 可借鉴：画布常驻加底部或浮动执行面板、按结果区分的自动开合、成功与失败不同的调试权重、状态图标字典、树形日志的缩进与实时计时。
- 不可照搬：固定宽度的执行侧栏、双横线令牌命名与历史兼容包袱、三列节点详情视图、任何源码级复制。许可为可持续使用许可，只做本地对照。
