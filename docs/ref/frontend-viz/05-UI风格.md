# 维度五：UI 风格（UI Style）

> 关注点：视觉语言——配色与状态色编码、间距/字号令牌、图标系统、密度与质感。

---

## 1. Dify 的 UI 风格

Dify 采用 **Tailwind 原子类 + 语义化 CSS 变量** 的声明式风格，视觉偏"轻透、现代 SaaS"。

### 1.1 样式实现

- 原子类直接写在 JSX：`system-sm-semibold-uppercase!`、`bg-components-panel-bg`、`border-divider-subtle`、`rounded-b-xl`、`bg-mask-top2bottom-gray-50-to-transparent`（`run/index.tsx:110-144`、`header/index.tsx:28`）。
- 语义 CSS 变量承载主题色：`--color-workflow-link-line-success-handle` / `-error-handle` / `-failure-handle` / `-handle` / `-normal`（`utils/edge.ts:3-20`）。
- 字体刻度用 `system-sm-*` 之类的语义类，而非裸 `text-sm`。

### 1.2 状态色编码（执行/连线）

| 状态 | 变量 |
| --- | --- |
| 成功 | `--color-workflow-link-line-success-handle` |
| 失败 | `--color-workflow-link-line-error-handle` |
| 异常 | `--color-workflow-link-line-failure-handle` |
| 运行中 | `--color-workflow-link-line-handle` |
| 普通 | `--color-workflow-link-line-normal` |

### 1.3 图标与质感

- 图标：Remix Icons（`@remixicon/react`），如 `RiCheckboxCircleFill`（成功）、`RiErrorWarningFill`（错误）、`RiLoader2Line`（运行中，配 `animate-spin`）（`run/node.tsx:15-17,185-226`）。
- 质感：渐隐遮罩（`bg-mask-top2bottom-gray-50-to-transparent`）、半透明选区（`rgba(21,94,239,0.05)`）、圆角面板（`rounded-xl`）、毛玻璃感，整体轻盈通透。

### 1.4 风格小结

- 关键词：**原子类、语义令牌、轻透渐变、圆角、Remix 线性图标**。
- 适合：AI/LLM 类产品那种"简洁、留白、强调内容"的调性。

---

## 2. n8n 的 UI 风格

n8n 采用 **SCSS Module + 设计令牌（CSS 变量）+ 设计系统组件** 的工程化风格，视觉偏"紧凑、专业、信息密度高"。

### 2.1 样式实现

- 每个组件用 `useCssModule()` + `$style` 写局部 SCSS（`CanvasNode.vue:77,466`、`WorkflowExecutionsCard.vue:197`、`MainSidebar.vue:409`）。
- **设计令牌即主题**：颜色、间距、字号、边框、动效全部走 CSS 变量（`_variables.scss` 与各组件 SCSS 引用 `var(--color--*)`、`var(--spacing--*)`、`var(--font-size--*)`）。
- `tailwind.config.js` 实际上**几乎为空**（`theme.extend: {}`），仅声明 `darkMode: ['selector', '[data-theme="dark"]']`——证实 n8n 主力样式是 SCSS Module，而非 Tailwind 原子类。

### 2.2 核心令牌（`_variables.scss` 与组件引用）

| 类别 | 令牌示例 |
| --- | --- |
| 主色/语义色 | `--color--primary`、`--color--success`、`--color--danger`、`--color--warning`、`--color--secondary`、`--color--text` |
| 间距 | `--spacing--2xs`、`--spacing--xs`、`--spacing--md`、`--spacing--4xs` |
| 字号 | `--font-size--xs`、`--font-size--sm` |
| 边框/动效 | `--border`、`--border-style`、`--duration--snappy`、`--easing--ease-out` |
| 侧栏 | `$sidebar-width: 42px`、`$sidebar-expanded-width: 200px`（`:23-24`） |

### 2.3 状态色编码

- **执行卡片左边框色**（`WorkflowExecutionsCard.vue:200-305`）：

  | 状态 | 左边框变量 | 语义色 |
  | --- | --- | --- |
  | running/new | `--execution-card--border-color--running/--waiting` | `--color--warning` |
  | success | `--execution-card--border-color--success` | 成功绿 |
  | error | `--execution-card--border-color--error` | `--color--danger` |
  | waiting | `--execution-card--border-color--waiting` | `--color--secondary` |
  | unknown | `--execution-card--border-color--unknown` | 灰 |

- **画布边**：success→`--color--success`、pinned→`--color--secondary`（`CanvasEdge.vue:110-117`）；非主连接虚线（`CanvasEdge.vue:67-70`）。
- **节点类**：`running`/`waiting` 通过 SCSS 类驱动视觉（`CanvasNode.vue:109-118`）。

### 2.4 图标与质感

- 图标：内联 SVG / `N8nIcon`，如 `redo-2`（重试）、`thumbs-up/down`（标注）、`flask-conical`（manual）、`check-check`（evaluation）（`WorkflowExecutionsCard.vue:154-191`）、`redo-2` 激活态用 `--color--primary`（`:346-348`）。
- 质感：卡片用 `--execution-list-item--color--background` 背景、细边框（`border-bottom: 1px solid --color--foreground--shade-1`，`:360`）、hover 提亮；侧栏 `transition: width var(--duration--snappy) var(--easing--ease-out)`（`MainSidebar.vue:419`），紧凑而精致。
- 密度：折叠侧栏仅 42px 图标条，信息密度高。

### 2.5 风格小结

- 关键词：**设计令牌、SCSS Module、紧凑密度、专业感、N8nIcon 线性图标、左边框状态编码**。
- 适合：自动化/集成平台那种"功能多、信息密、强调可扫读状态"的调性。

## 3. 横向对比

| 对比项 | Dify | n8n |
| --- | --- | --- |
| 样式技术 | Tailwind 原子类 + 语义 CSS 变量 | SCSS Module + 设计令牌（CSS 变量） |
| Tailwind 使用 | 重度（原子类直接写 JSX） | 近乎不用（config 为空，仅深色模式策略） |
| 主题变量 | `--color-workflow-link-line-*` 等 | `--color--*` / `--spacing--*` / `--font-size--*` 全量令牌 |
| 状态编码 | 连线/节点边框着色（success/error/failure/handle/normal） | 卡片左边框色 + 画布边色 + 节点类（warning/success/danger/secondary） |
| 图标系统 | Remix Icons（线性） | N8nIcon（线性 SVG） |
| 视觉密度 | 轻透、留白多、圆角 | 紧凑、信息密、细边框 |
| 质感 | 渐隐遮罩、半透明选区、毛玻璃 | 卡片背景、hover 提亮、精确动效令牌 |
| 深色模式 | 暗色类 + 变量覆盖 | `[data-theme="dark"]` 选择器 |

---

## 4. 设计启示

- **令牌化是共识**：两者都把"语义变量 → 具体色值"作为主题与暗色模式的基础。新项目应尽早建立 `--color--*`、`--spacing--*`、`--font-size--*` 三级令牌，避免散落的硬编码色。
- **原子类 vs SCSS Module 是路线选择**：Dify 的 Tailwind 上手快、迭代快；n8n 的 SCSS Module 在大型设计系统与强类型协作下更可控、作用域更安全。团队规模与一致性要求决定取舍。
- **状态色要"可扫读"**：n8n 用左边框色编码执行状态，比 Dify 单纯连线着色更易在列表中一眼分辨；若要在"列表 + 画布"双场景表达状态，建议双重编码（卡片边框 + 画布着色）。
- **图标风格统一**：两者都用线性图标，保持描边粗细一致；Dify 用 Remix、n8n 用自有 `N8nIcon`，皆未混用多种图标库，保证了视觉统一。
