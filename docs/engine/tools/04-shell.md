# 04-终端工具

> 范围：`predefined/shell/`（十四工具定义）、`shell.rs`（无状态命令处理器）
> 定位：单次命令执行与后台会话复用的统一终端入口，实际进程管理在 `wf-shell`

## 工具一览

仅 `execute_command` 为无状态：经命令安全门后在阻塞池运行，捕获输出、强制超时、可选沙箱策略，解析观察范围目录供检查点侧写。其余十三项全部围绕后台会话引擎：创建后台外壳、查询输出、等待完成、终止、发送输入、调整尺寸、获取或创建会话、在会话中执行、按任务释放会话、任务台账、单会话后台化、全部后台化、后台确认。会话级工具多为有状态工厂，保证同一会话的连续命令复用同一终端。

## 注册与生命周期

注册时由终端配置构造一个共享的后台存储，多工具共用同一存储实例；同时安装会话生命周期转发器，使非工具触发的自然退出也能关闭作用域采样。秒级超时参数在工具边界以秒表达，内部统一转为毫秒。取消信号、输出截断、溢出落盘、PTY 与管道后端选择等进程细节由 `wf-shell` 承担，本 crate 只做参数校验、作用域门与结果整形。

## 任务与后台机制

后台任务注册表按会话记录归属执行、是否转后台与最终状态；转后台后命令解除超时上限，输出经增量游标读取。按任务批量释放供执行结束时的清理路径调用，避免会话泄漏。
