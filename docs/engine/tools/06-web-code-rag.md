# 06-网络代码与检索

> 范围：`predefined/web/`、`predefined/code_context.rs`、`predefined/rag.rs`、`predefined/integration/`
> 定位：只读的外部知识与代码智能入口，不拥有传输与索引实现

## 联网工具

搜索与抓取各一。搜索默认走可配置的 HTML 搜索端点，结果数与超时可调；抓取做响应体上限截断与 HTML 标签剥离加实体解码。两者共享同一配置（端点、超时、体量上限、结果数、UA），处理器为无状态，失败转为失败结果而非抛错。

## 代码上下文工具

六工具覆盖混合语义检索、BM25 关键词检索、符号列表、引用查找、定义跳转、带折叠的文件读取。前五项是集成包传输层的薄封装：只做服务可用性检查、目录前缀的读作用域门、参数规整（工程 id 回落、条数钳制），不触碰线协议细节；数字服务键永不暴露给模型，导航只用文件路径加行号。折叠读取在无服务时静默退化为普通读文件，保证同一工具在两种部署下可用。

## 知识检索与通用 MCP 调用

知识检索为最小静态 schema（问题、条数、分数下限、元数据过滤、命名空间），处理器委托宿主注入的检索后端，本 crate 不选向量后端与嵌入模型。通用 MCP 调用为单一泛型工具（服务名、工具名、参数），将任意已配置服务的调用收敛到一个 schema，实际执行走 MCP 执行器；各服务的具名工具另由 MCP 注册器动态展开（见 MCP 文档）。
