# 终端与 TUI 增强设计（P7）

> 范围：浏览器终端通道与后续增强。本阶段为增量，不阻塞 P4-P6 的独立验收。
>
> 变更：TUI Git 屏（原第 4 节）与无头写批（原第 5 节）随 CLI 放弃 Git 一并取消，理由见 `docs/plan/cli/client-unification-design.md` 第五节；终端界面提供感叹号透传单条命令的轻量形态同样不再适用。本节仅保留浏览器终端。

## 1. 通道分离

事件订阅通道与终端通道分离。前者沿用现有广播式订阅，用于推送仓库变化；后者新建独立端点，一连接绑定一会话，双向流式。终端会话由现有 Shell 会话存储承载，支持创建、输入、尺寸调整、终止、空闲回收。会话工作目录锁定仓库根，环境注入受控覆盖，避免寻呼器与凭据交互卡死。

## 2. 协议与生命周期

协议帧分客户端到服务端与服务端到客户端两向，覆盖建立、输入、尺寸、终止、保活与就绪、增量输出、前台结束、仓库变化、错误等。连接生命周期与页面绑定，折叠不销毁会话，离开路由销毁，关闭前主动终止。终端写入后经指纹比对触发上半部分自动刷新，未变不推。

## 3. 浏览器终端组件

终端组件挂载终端渲染实例，处理输入与尺寸事件。新增运行时依赖只保留终端渲染所需的一项。提供清空、终止当前命令、重启会话三个按钮。输出原生支持着色。动作失败时提示附带在终端中查看的入口。终端做生命周期单测并以手工验证交互式命令，凭据场景不卡死为必验项。

现状：已上线轮询形态，写入经单一输入端点、输出按游标增量拉取，展示为纯文本块，配清空、重启与建立时尺寸上报；命令后按仓库指纹比对驱动上半部分局部刷新。该形态可承载非交互命令，挂起类交互命令会卡死，双向流与终端渲染为后续项。

## 4. TUI Git 屏（已放弃）

CLI 放弃 Git 后本节取消：终端界面内的 Git 屏、单键即触发手感与动作菜单替代右键等形态一并取消。取消理由见 `docs/plan/cli/client-unification-design.md` 第五节；键位输入栏与浏览器终端的工作台形态不受影响。

## 5. 无头写批（已放弃）

CLI 放弃 Git 后本节取消。写操作统一由工作台经 `/git/action` 单一入口提交，动作集、危险级别与确认语义以后端注册表为权威，无头命令不再重复一套 Git 写路径。

## 6. 后续增强

行级暂存、贮藏全套、变基动作集按需跟进。交互式变基、补丁构建、合并冲突解决等重型能力首期不进终端界面，留给浏览器工作台。伪终端依赖与现有 Shell 会话语义的差异需在接入前做最小联调；长命令节流阈值需按实际推送拉取耗时调参。

## 7. 验收

页面内可跑常用命令并正确渲染；终端写入后上半部分按指纹变化刷新；折叠不丢上下文，离开路由被回收；破坏性动作经确认；凭据场景不卡死。

## 8. 风险

伪终端依赖与现有 Shell 会话语义的差异需在接入前做最小联调；长命令节流阈值需按实际推送拉取耗时调参。
