# 05-记忆与上下文

> 范围：`predefined/memory/`（七工具）、`predefined/context/`（两工具）
> 定位：跨轮次的状态记忆与压缩归档的读取能力

## 记忆工具

七工具分两组。会话笔记组（记录笔记、回想笔记、列举分类、会话记录）按执行隔离：同一执行的笔记互可见，分类为其标签集合，会话记录支持创建与列举。长期记忆组（记忆、遗忘、列举）跨执行共享，定位为会话笔记的兼容别名。注册时共享同一个内存存储实例，全部为有状态工厂，保证同一进程内的跨调用连续性；SQLite 特性开启时会话记录走文件数据库，否则回落内存实现。

## 上下文归档工具

压缩归档组为只读两工具：按关键词或主题检索压缩块索引（返回块 id、主题与归档指针，不加载内容），再按归档指针读取归档块内容（支持行区间切片）。两者均为异步处理器，先做参数校验；无会话时报告不可用而非返回空结果，调用方按此区分未配置与无命中。
