# 键位输入栏与写操作设计（P6）

> 范围：工作台的动作触发体系与统一写入口。不含终端伪终端实现。

## 1. 绑定表

绑定表为纯数据模块，是输入栏、控件条、右键菜单的唯一事实源。按上下文分节，每项含标识、中文短名、别名、原键位提示、不可见标记、控件权重、危险级别、参数声明、可用性。危险级别与参数声明以后端注册表为权威，前端表只做离线兜底，启动期比对漂移，发现未知动作告警并置灰。

## 2. 词元解析

语义为动作为主、单字符为别名。解析流程为：空输入显示当前上下文提示；单字符先在当前上下文内别名精确命中，未命中退化为全局前缀搜索；多字符做全局前缀搜索并按上下文优先排序；冒号前缀进入命令模式转发终端；问号列出当前上下文全部动作。提交必须按键确认，不做输入即执行。输入过程中右侧实时预览将被执行的动作全名与危险标记。词元解析做成不依赖框架的纯函数，保证可测。

## 3. 焦点仲裁

焦点仲裁收敛在页面容器。进入页面输入栏自动获焦，点击面板后焦点归还输入栏。输入栏为空时方向与翻页透传列表，候选中移动。弹层打开时输入栏禁用并置灰。另设全局聚焦热键。

## 4. 控件派生与可发现性

不可见键控件条由绑定表自动派生，按权重取前若干项，确认动作渲染为主按钮，返回动作仅在有活动弹层或子视图时出现，无不可见项时自动收起。滚动、导航、选中复制、范围选择等交由浏览器原生行为，不派生控件。可发现性靠常驻提示行轮播高频动作、右键菜单列出上下文全量动作、帮助面板支持按上下文筛选三件套。

## 5. 参数对话框

参数化动作只承担触发，不承担内联参数。提交信息与新分支名走文本对话框，重置模式与贮藏变体走单选，变基目标与比较基准走引用选择器。完整复杂表达交给终端。

## 6. 统一写入口

不按动作开路由，只开一个统一动作入口，载荷含动作标识、参数、选中项。后端维护注册表分发，未知动作返回明确错误。首期覆盖暂存切换、全部暂存、提交、直接提交、修订、放弃、贮藏、忽略、刷新、分支检出与创建删除与合并变基与重命名与快进、提交改写与压缩与修正与丢弃与还原与拣选粘贴与建分支与打标签、贮藏应用与弹出与丢弃与转分支、推送拉取刷新撤销重做聚焦过滤等高频子集。外部差异工具、托管平台、变基编辑器、构建补丁、二分、工作区与子模块写操作首期标记为不可用。

## 7. 危险分级与校验

危险操作分四级：只读直接执行，可恢复走带撤销提示，会丢改动走对话框确认，改写历史或影响远端走二次确认并要求手动输入目标标识。不设全局不再提示开关。动作前置校验在处理侧执行，不满足返回带原因的错误。破坏性级别要求客户端传入确认标识，服务端二次校验后才执行。同一仓库的写操作串行化，避免索引锁冲突。常规命令设较短超时，推送拉取类放宽。

## 8. 回显与撤销

界面动作执行后可回显等价命令到终端，用于教学。可逆操作走带撤销的提示，撤销窗口内可撤销。鉴权与限流沿用现有中间件，用户动作纳入已有审计域。

## 9. 验收

单键可触发暂存提交放弃；危险动作预览带警示；绕过界面直接调用无确认标识被拒；并发写不冲突；撤销窗口内可撤销；绑定表漂移被发现并置灰。

## 10. 测试

绑定表做唯一性与别名冲突单测，词元解析做纯函数分支单测，焦点仲裁做组件级去向单测。统一入口做未知动作、前置失败、无确认标识三类拒绝单测。终端行为以手工验证为主。
