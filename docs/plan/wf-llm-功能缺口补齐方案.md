# wf-llm 功能缺口补齐方案

> 对应问题文档：`docs/issue` 下的 wf-llm 职责划分与功能缺口分析第三章。
> 状态：本次仅定方案暂不执行，按优先级排序，供后续专项逐项立项。

---

## 一、优先级排序

第一档为正确性相关：真实分词、结构化输出本地校验、重试判定硬化。第二档为能力与韧性：鉴权种类、熔断与故障转移、模型目录分页缓存。第三档为效率与观测：缓存预算、统一打点、多模态能力。

## 二、各缺口补齐方向

### 2.1 真实分词

引入按模型家族划分的分词策略接口，默认实现沿用现有启发式，精确实现按需接入。计数模块只认接口不认具体算法，决策轨继续使用本地估算的定位不变。

### 2.2 结构化输出本地校验

在生成参数发射之后、请求构造之前增加一处响应格式校验：声明为 JSON 模式但约束缺失或非法时直接返回配置错误，不再发往服务商。

### 2.3 重试判定硬化

将基于状态码前缀字符串的判定改为结构化判定：状态码分区加可重试错误码表，限流响应尊重重试等待头。熔断与多画像故障转移单独立项，不与本项混合。

### 2.4 鉴权种类补齐

将鉴权类型由自由字符串收敛为枚举加扩展透传：常见机制为一等公民，特殊机制走现有自定义头透传并登记，未知类型在画像注册期即报错。

### 2.5 模型目录增强

补充分页遍历、结果缓存有效期与失败降级：发现失败返回空列表加可观测警告，不阻断画像注册，与现有注释承诺的行为对齐。

### 2.6 缓存预算与可观测性

响应缓存与成本预算合并为一个专项，统一打点为另一个专项：前者定键策略与失效语义，后者定模型画像维度的延迟错误用量指标集。两者都不进入传输热路径的必经分支，无采集器时零开销。

### 2.7 多模态与新能力

嵌入、重排、图像音频等新能力不塞入现有对话接口，按职责新增独立操作与独立编解码方法；现有对话路径不受影响。
