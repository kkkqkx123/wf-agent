六、风险与建议
⚠️ 高风险区域
Checkpoint 版本迁移: 需保证向后兼容
事件系统重写: 订阅模型差异大
MCP 协议: Rust 生态不成熟
✅ 建议策略
渐进式迁移: 先用 napi-rs 实现混合架构
保持 TS API: sdk-kit 层保持 TS，用户无感知
并行运行: Rust 核心 + TS 外壳，逐步替换
充分测试: 每个模块迁移后跑完整 E2E 测试
