# 02-wf-headless 无头二进制

> 范围：`crates/app/cli/wf-headless`（`wf-headless` 二进制）
> 定位：共享逻辑的薄入口，不含任何交互界面，面向脚本与自动化

该 crate 只有一个二进制目标：解析顶层参数并移交共享库的无头专用入口，失败时向标准错误打印错误并按共享错误映射的退出码退出。自身不实现会话、渲染或管理命令，全部行为由共享库提供。

## 与共享库的分工

二进制只做参数解析与进程级错误收敛：成功路径完全委托共享库，错误路径统一转换为人类可读的标准错误行与退出码。这种划分使无头形态的行为与其它形态共用同一实现，新增子命令无需在此追加分发。

无头专用入口与通用入口是同一分发逻辑的两种称谓，保证无头判定与实际分发不会随演进分叉。判定上所有子命令均为无头，管理类子命令在此直接执行，单次会话子命令走无头会话管线，诊断子命令走模式展示，全屏探针在此明确拒绝并指引使用全屏二进制。

## 运行行为

无头形态是非交互的单次语义：一次调用执行一条命令或一轮会话后即退出，不保留跨调用状态。提示词来源支持位置参数与管道输入；交互式问答模式下标准输入转为应答通道，因此要求位置参数提供提示词，避免提示词与答案争用同一输入。

输出延续共享纪律：业务内容走标准输出并支持四档格式，诊断走标准错误，日志文件扇出可选。管道与重定向下颜色自动关闭，机器消费无需额外清洗。

## 适用场景

适用于持续集成、定时任务、管道组合与一次性管理操作。需要多轮记忆、行内建议或全屏检视时，应使用行式会话或全屏形态；需要探查终端能力时，应使用全屏二进制的终端探针。

## 命令清单

无头模式支持全部子命令，按域分组如下。所有命令均为纯客户端，经共享连接句柄访问运行中的服务，输出渲染保留在本地；破坏性操作受统一确认开关约束，非 TTY 下默认免确认。

### 单次会话与诊断

单次会话与诊断形态不属于管理命令，走独立管线而非按域分发。

- 单次会话：位置提示词缺省时，非 TTY 下消费标准输入全文作为提示词；支持智能体与模型选择、可重复批准前缀、超时预算、结构化上下文及其文件来源；智能体转向独占图片、远端图片、附件、细节档位与工作区隔离，工作流转向独占工作流标识与三层输入合并，位置提示词不可与工作流标识同用；交互式应答与全盲批准互斥，应答超时仅限交互式且超时即拒绝审批并取消问答；单次远端覆盖仅作用于本轮。
- 模式诊断：打印当前形态、输出格式与两侧 TTY 状态及日志文件。
- 终端探针：验证终端守卫进入与恢复、外置命令窗口与主题探测，支持切换全屏模式集与指定外置命令；无头构建中明确拒绝并指引使用全屏二进制。

### 执行与工作流

统一执行外观先按智能体后按工作流回退解析，工作流域面向定义与版本，分析臂复用共享分析构造器。

- 执行列表、单执行摘要、单次工作流执行、等终态观察、日志分页与跟随、状态查询、取消与暂停与恢复、状态细节检视、父子层级与子树、分组全量历史、性能与瓶颈与错误与对比与进度分析、迭代时刻状态、执行删除。
- 运行中智能体循环的输入追加、默认追加模式设置、堆积追问转转向；工作流执行下属循环的列出、节点级追加、节点级模式设置、节点级待定转换；已完成循环的按时间清理。
- 工作流定义的列表、展示、图结构与汇总与环路与拓扑与可达与邻居检视、创建、更新、删除、克隆、校验、导出、导入、版本管理、回滚、执行图与路径与慢节点与效率与概率与备选路径分析；版本下属列表、展示、升级、差异、变更日志。

### 检查点与审批

检查点覆盖状态记录、文件分区与智能体循环三类，审批面向文件检查点审批接口；运行时工具调用审批由会话中的交互应答器回答，不走审批命令。

- 状态记录：工作流与智能体循环的创建、按执行列出、展示、打标与去标、两两差异、新分支恢复与预览、删除、链路、回收、最新、批量实体列出、按工作流时间窗列出、实体元数据读写、按实体删除；歧义标识以显式域覆盖区分。
- 文件分区：按归属创建、分区列出、分区提交历史、改名移动、状态文件关联健康、按归属与路径与时间窗的变更列出、与主干差异、单文件版本时间线、编辑会话列出与开始与回滚、撤销与重做、工作区重建集、文件树、冲突列出与全量解决、单文件内容读取、双归属差异、对象存储占用、输入边界撤销预览与执行、从检查点恢复为新写入、对象存储清理、行级提交送审、送审合并到特性分支、多特性顺序合入主干、已合特性追加回滚、源索引重建与健康、导出导入与基线迁移与外部更新提示与对账点与同步默认值。
- 审批：待审批列表、批准、拒绝并附理由。

### 实体与工具链

- 技能：列表、条件查询、展示、启用、禁用、扫描、重载、清缓存。
- 变量：按执行列出、读取、设置、删除，值尽可能按 JSON 解析。
- 消息：按执行与角色列出、关键字检索。
- 任务：列表、展示、统计、跨台账统一计数、取消。
- 工具：列表、展示、参数校验、执行、落盘保存、删除、启用、禁用、关键字检索。
- 脚本：列表、展示、参数校验、执行、落盘保存、删除、启用、禁用、关键字检索。
- 模板与智能体定义：按种类与分类与标签与作者的列表、展示、克隆、文件注册、删除、版本操作、回滚到已存版本；智能体定义版本下属列表与展示。
- 触发器：模板的列表、展示、文件保存、删除，单执行的触发历史，触发台账的列表、单条展示、按触发名统计、按时间清理。

### 大模型配置

- 档案：列表、展示、文件创建、文件更新、删除、文件校验、默认档案读写、模板操作、脱敏导出、文件导入。
- 供应商：列表、展示、模型发现。
- 模板：按种类与分类与标签与作者的列表。
- 认证：登录、登出、状态，登录驱动宿主侧会话状态机，口令不落输出。
- 代理凭证：按路由地址的保存、删除、元数据状态，口令只存凭证库。

### 可观测性与检索

- 审计：摘要、完整报告、时间线、迭代审计、工具调用审计、模型调用审计、节点执行审计。
- 事件：列表、统计、传输健康、执行时间线、跟随流。
- 指标：快照展示、导出，支持结构化与文本两种形态。
- 分析：性能、瓶颈、错误、双执行对比、进度。
- 统一检索：跨资源关键字检索；执行记录的条件过滤分页聚合导出，支持状态与工作流过滤、排序、偏移、高级表达式与聚合导出。

### 系统与远端

- 健康与完整诊断：存储健康透传，完整诊断透传后端原样渲染。
- 工作区：展示本次调用的目录归属、来源、服务端许可与缓存。
- 展示配置备份：仅展示文件的导出与导入，键位与主题文件需手工复制；缺源导出默认值，坏源拒绝导入。
- 远端主机：注册更新、列表、隧道命令打印、服务端启停命令打印、执行包拉取。

## 无头约束

- 全屏开关不可与子命令同用，强制无头开关不可与会话恢复类选项同用。
- 顶层智能体与模型选项仅限交互形态，子命令中的单次会话使用自身的同名选项。
- 会话恢复类选项仅限交互形态，不可出现在子命令中。
- 工作区位置参数仅限交互形态，子命令必须使用显式目录旗标。
- 历史文件路径与禁用互斥，工作流输入类选项要求工作流标识，图片附件与结构化上下文仅限智能体转向。
- 超时必须为正，工作区目录不可为空，工作区隔离名称仅接受纯目录名。
