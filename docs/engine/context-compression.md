# 上下文压缩实现分析

> 范围：`crates/engine/wf-agent/`（发射与回写）、`crates/engine/wf-execution-shared/`（会话、决策、信号分发）、`crates/app/wf-runtime/src/trigger_listener/compression/`（适配与管线）、`crates/app/wf-runtime/src/bootstrap/trigger.rs`（装配）、`crates/engine/wf-resource/`（摘要链模板）、`crates/engine/wf-workflow/src/handler/llm/`（工作流侧发射）
> 定位：跨层链路而非单模块，预算判定在引擎，摘要执行在运行时监听侧，写回在会话，靠版本锚点串起幂等

## 触发点

触发分常规预算与强制安全网两类，工作流侧与智能体侧对称。

### 常规预算触发

智能体侧入口在每轮用量结算后，调用链为迭代协调器结算用量后进入压实决策。需同时满足三个前提：用量跟踪开关打开、模型窗口上下文限额已知、压实窗口已知。任一不满足直接返回，强制安全网负责兜底。

热估算口径为投影视图稳定估算加本轮动态开销，再按实际与估算偏差校准。视图估算在压缩后会缩小，而历史继续增长，因此基于视图而非历史可以避免压缩后立即重触发。动态开销由本次组装请求与稳定估算之差得出，不落账本。

决策函数为纯函数，按热估算与阈值比较：达到硬线走激进压实，达到压实线走常规压实，超过目标值一半以上且存在压缩块时评估交接。单摘要策略跳过块交接分支。调用侧在此之后还有两道投影校验：激进计划释放后仍超硬线直接进交接，空计划在非单摘要模式下直接返回。

### 强制安全网触发

语言模型调用被服务商以上下文超长拒绝时，发射强制压缩信号。特征为强制标记为真、走无状态计划、不查规划建议、无请求级指令。同一版本已发射则跳过，避免与常规信号重复飞行。

工作流侧在语言模型节点的预算检查与流式错误分支中有对等逻辑，预算超限与超长错误分别对应上述两类触发。

### 发射守卫

同版本只发一次，新消息推进数组版本后才重 arm。已有机上飞行则本轮合并等待，飞行超时后自释放，防止丢失完成事件永久阻塞。触发监听侧另有以执行、目标、版本为键的认领表，重复投递直接丢弃，靠版本检查释放。只有分发结果为已接管才锚定飞行，否决清待定计划但不计无接管 streak，无接管保留审计事件且不锚定。

## 业务逻辑

### 发射段

发射器用当前视图快照构造压缩请求，携带目标上下文、用量、限额、消息数、数组版本、强制标记、计划条目与请求级指令。先写压缩前检查点，再同步分发钩子信号，最后发布审计事件。分发语义分三种：观察者否决则在接管前取消；观察者替换则直接以供给摘要落地为完成事件并跳过摘要链；无否决无替换时运行具名接管处理器。智能体侧附带所属循环标识，工作流侧不带。

### 适配段

压缩服务是薄钩子适配器，只做解析、空快照跳过、发布带快照的路由副本三件事。路由副本带路由标记与嵌套深度，只有内建模板能匹配。用户模板禁止携带保留动作与指向该信号，加载期与匹配期双重拦截，因此用户规则永远走不到这条管线。

### 管线段

管线拥有全部执行策略：认领、重试退避、降级回退、写回编排、终态事件、触发器状态与账本审计。快照先按限额裁剪到输入上限并扣除指令开销，零限额不裁剪。再按计划切片，每片头插请求级指令，深度大于零的条目走重压链，未配置重压链时回退主链。空计划为单摘要模式，一片覆盖全快照。

逐片运行摘要子工作流，单片超时、最大尝试次数与指数退避共享整批预算，关闭信号可中止。全部成功后一次聚合写回，版本锚点只推进一次，整批只落一个完成事件。单片失败耗尽重试后按终态结算：过期为放弃，不发失败事件；中止记放弃；失败按摘要工作流资源声明的回退策略处理，降级模式把本地裁剪窗口加显式降级声明写回并记成功，失败模式发失败事件并释放工作流侧飞行锚点。账本中中止与过期记放弃，降级成功记完成。

### 回写段

智能体循环启动时为存活会话拉起 преобразования消费者，循环结束时中止。消费者订阅完成、失败、丢弃与嵌套写回四类事件，只处理本循环标识且目标为会话上下文的事件。完成事件先做版本锚点检查，失配则释锚并发布丢弃事件，命中则按是否带块结果走聚合应用或单摘要应用。压完仍超预算时正常模式转交接请求，停车 streak 达到阈值记错日志等待新消息，否则清 streak。成功后走策略门控的压缩后检查点。失败事件释飞行并清待定计划，发射守卫保留，版本靠新消息重 arm。

### 状态模型

会话历史只追加，压缩只追加摘要消息并切换读投影，撤销压缩是零成本视图切回。活跃视图为分段结构，由摘要段与序号区间段组成。压实状态随会话与检查点持久化，承载模型窗口、推导阈值、块表、待定计划与丢弃、交接请求标记、交接产物与模式。块有原始、已压缩、密封三态与重压计数，丢弃块直接清表不留死重。用量跟踪器另存飞行记录、无接管 streak、仍超预算 streak 与预检警告单次标记，压缩成功后重 arm 预检警告。

阈值由模型窗口按比例推导，须严格递增。块同步只在分层策略下开启，单摘要策略只保留阈值门控不维护块表。超时嵌套由装配期显式校验：等待预算须覆盖最坏声明成本（各次超时加每次失败后退避），违例在启动日志记错并修正到下限，不再只靠注释约束。退避基数与封顶由策略与链运行共用同一常量。飞行、发射守卫、无接管与仍超预算计数收敛为跟踪器同一构件，会话与工作流变量映射共用谓词与阈值；认领表仅为管线内快速丢弃，不再承担正确性。交接以显式三态（正常、已请求、交接中）呈现，存储仍为模式加请求标记，仍超预算到请求的换算集中在一处。强制路径沿用无状态计划不查建议的定位，但补齐待定契约：发射前写入空丢弃的待定计划，否决与无接管时清除，使计划模式强制结果同样可匹配。等待由事件驱动加轮询兜底：版本推进与飞行释放走共享内存即时可见，订阅唤醒失败分支，轮询覆盖滞后订阅与无总线场景，语义与原来一致只是延迟与可靠性改善。

## 扩展点

* 限额配置：压缩策略管尾部保留、重试、单次超时与等待预算，压实限额管阈值比例、重压阈值、原始块下限、重压上限、尾部轮数、计划上限与单次摘要预算、策略名。装配期注入进程全局并解析策略到工作流标识，缺失主链回退内建并记错，重压链缺失仅记调试日志。
* 规划建议：命名策略的纯整形建议，引擎全量校验与钳制，缺失失败空建议回退内建。执行链替换即同名工作流模板替换，主链缺失回退内建。
* 钩子信号：同步观察者可否决或替换，静态定义透传后同样参与门控。替换供给空摘要视为否决，无总线时替换直接取消，避免静默走内建链。
* 终态声明：由摘要工作流的触发子流程配置声明失败或可见降级，缺失配置装配期告警一次，运行时降级为失败。
* 运行时装配：路由配置携带摘要标识、重压标识与策略，管线支持策略、重压链、会话注册表与账本注入。会话直写预留已接线但未切换传输路径，事件契约不变。
* 可观测：请求审计、路由副本、完成、失败、丢弃事件，任务用量警告与超限事件，触发器起止记录与耐久账本，压实指标与调试维度。

## 设计评价

合理的部分：单管线独占执行策略，引擎独占阈值、锚点与写回，决策纯函数可测；历史追加加视图切换保证无损；发射守卫加飞行加管线快速丢弃分层清晰，正确性只依赖版本锚点；接管、否决、无接管三态背压语义清晰；失败要么外部可见暂停，要么可见降级，不静默；超时嵌套、飞行过期、仍超预算阈值、锚点比较各自只有一处实现。

剩余约束：进程级限额与顾问注册仍为默认源，运行时主路径优先使用显式装配值；用户模板仍禁止直达保留动作；审计事件口径与版本号不变。
