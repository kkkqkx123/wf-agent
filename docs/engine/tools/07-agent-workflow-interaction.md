# 07-调度与交互工具

> 范围：`predefined/agent`、`predefined/workflow/`、`predefined/interaction/`、`predefined/knowledge/`、`predefined/utility/`、`predefined/general`、`general.rs`、`general_history.rs`
> 定位：跨执行调度、人机交互与代理分发的内置工具族，执行经回调回到引擎

## 调度工具

智能体调用与工作流执行/查询/取消均为纯定义、无注册函数，执行由内置执行器经引擎回调完成。调用支持同步等待与异步派生两态（默认等待），携带提示词、可用工具名单、轮次与耗时与 token 预算、钩子与初始对话；工作流执行携带工作流 id 与输入，同样支持两态。状态查询与取消按执行 id 操作，调用方根 id 用于鉴权归属。

## 交互与杂项

问答与终结两工具只向智能体循环发信号（暂停等输入、结束任务），同样无注册函数。技能工具的定义常驻注册（内容加载由注入的技能加载器服务），暴露由装配层决定。待办清单工具维护任务列表的增删改查，为无状态处理器。`general` 工具是可发现工具的调用代理：schema 恒定为单个请求字符串（内部为工具名加参数的 JSON），模型侧 schema 永不随可发现集合变化；处理器委托执行上下文中的引擎调用器，使内部调用同样经过可见性、审批、检查点与超时全链路。

## 历史形态归一

`general_history.rs` 处理可见性变化导致的历史形状错位：同一工具在新旧轮次可能分属直接可见与代理调用两种形状。模块提供纯函数在读取出口处双向转换（展开代理调用为直接调用、合并连续直接调用为代理调用），id 推导稳定可逆、顺序保持、不可解析体原样保留、已归一历史幂等；存储的历史永不就地改写，执行语义仍以运行时门控为准。
