# 主会话滚动区可选滚动条设计

范围是完整 TUI 主会话滚动区（`InteractiveController` 的滚动回放区）。只读查看器、详情窗格、设置屏与历史浮层的滚动条已按 `docs/plan/tui-scrollbar.md` 落地，本方案补齐主会话缺口，并与 `docs/plan/long-term/mouse-click-expand-design.md` 的鼠标能力衔接：本方案只做键盘与滚轮驱动下的位置指示，边槽点击与滑块拖拽归长期鼠标方案。

## 现状事实与约束

主会话滚动语义以距尾行数为偏移，零表示尾随，绘制时按视口容量钳制并刷新是否到顶标记。回放分页以前插方式落地并保持视口相对尾部稳定。回尾浮动徽标逐帧覆盖绘制，不进缓存，不具备命中矩形。

绘制分三档分级：全量重建一切，底部专用复用预排只重画页脚与输入行，动画专用只碰记录的动画格。预排缓存以内容宽度与内容版本为键，只克隆可见窗口；流式尾行排除在缓存之外，每帧按当前宽度重新换行；动画格记录流式指示格与状态行 spinner 格，脱离尾部时流式格不记录。重绘快照比较宽度、高度、内容版本、偏移、流式长度与哈希等差异以定级，任一内容与布局差异落全量。

底部布局随作曲器高度生长，滚动区至少保留最小高度。鼠标现状为滚轮复用分页感知的滚动方法，按压与拖拽一律忽略以保留原生选区，捕获默认关闭。配置侧行为开关缺省关闭且修改后需重启生效。

## 目标与非目标

目标：为主会话滚动区提供默认关闭、可选开启的单列位置指示条；开启前后键盘、滚轮、分页、徽标、动画分级语义不变；窄终端自动退化为现有无条形态。

非目标：不引入新的滚动模型，不改变分页与哨兵收敛，不默认开启，不新增主题语义色，不在本方案内做边槽点击与滑块拖拽（归长期鼠标方案），不改动管理列表与历史浮层之外的区域。

## 开关与可见性

沿用主配置行为分组新增会话滚动条显式开关，缺省关闭，与 `ref/opencode` 的主会话默认一致。开关即时生效，无需重启：切换引起内容宽度变化，而宽度变化本来就定级为全量，天然走全量重建。设置屏沿用现有本地键位风格提供切换入口并提示即时生效，不新增全局快捷键。

可见性沿用共享模块的统一规则：内容超出视口、视口高度满足最小值、滚动区全宽满足最小宽度，三者同时成立且开关开启时显示，否则隐藏。隐藏时布局与绘制与现状逐像素一致，保证默认用户零感知。

## 布局与预排

显示时滚动区拆分为左侧文本区与右侧单列边槽，文本区宽度为原滚动区宽度减一。预排、流式尾行换行、快照宽度、布局记忆宽度一律采用文本区宽度，而非原滚动区宽度，保证换行与缓存键一致。隐藏时采用原宽度，两种宽度各自拥有独立缓存键，切换即全量重建，不存在跨宽度的缓存复用。

空会话占位行按现有路径绘制，不画条。降级单条目模式沿用现有缓存路径，位置换算以实际总行数为准。

## 位置换算与绘制

总行数为缓存行数加流式尾行数，容量为文本区高度，起始位置为 surplus 减去距尾偏移并钳制，复用共享模块的尾锚换算。绘制顺序为文本段落后画条，徽标最后画；显示时徽标锚定文本区右下而非滚动区右下，避免压住边槽。底部专用路径同样绘制边槽，位置来自同一换算，保证与全量帧一致。动画专用路径不触碰边槽格，动画格记录排除边槽列。

## 分页与回尾徽标共存

脱离尾部时徽标与滚动条同时可见：徽标回答还差多少行与按键回尾，滚动条回答当前在全文中的比例位置。两者不互斥。窄终端或开关关闭时只有徽标，与现状一致。触顶分页、超顶哨兵收敛、回尾回顶动作均不改动。

## 测试与验收

单测覆盖开关状态与可见性的组合、两种宽度下的快照宽度取值、尾锚换算在流式行存在时的取值、徽标锚定随边槽偏移。渲染测试以测试后端对比开条与关条两帧：文本内容一致（关条帧右侧多一列文本列），开条帧最右列为轨道或滑块符号。现有滚动、分页、重绘分级与无头基线测试全过。弱终端与小高度下自动隐藏，无持续帧率回归。鼠标点击与拖拽的验收归长期鼠标方案，本方案只保证鼠标滚轮行为不变。
