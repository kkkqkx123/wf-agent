# 03-文件系统工具

> 范围：`predefined/filesystem/`（八工具定义）、`filesystem/`（处理器与作用域）、`patch/`（补丁引擎）、`sequence_matcher.rs`、`ignore.rs`
> 定位：受作用域与审批约束的本地文件读写改查能力

## 工具一览

八个工具全部走无状态处理器，按注册顺序为读文件、写文件、编辑文件（批量搜索替换）、应用补丁（代码风格整块补丁）、应用差异（SEARCH/REPLACE 块）、列文件、文本检索、文件名匹配。读侧支持行偏移分页、缺文件标签化错误与取消检查；写侧统一经作用域门、写保护检查与检查点侧写；检索侧支持正则/ glob 语义与忽略规则。

## 处理器结构

`filesystem/` 按职责拆分：配置（工作区根、默认超时、沙箱模式等）、读处理器、写处理器、补丁操作、作用域门、编辑差异内核、变更队列、忽略规则。处理器入口按工具名分发到同名方法，写保护控制器可叠加。路径解析统一为三步：波浪线展开、相对工作区或执行作用域工作目录的拼接、规范化；再经共享的路径裁决（见治理文档）判定越界、外部与符号链接逃逸。同步处理器在读前、读后、写前检查取消信号。

## 补丁引擎与模糊匹配

`patch/` 拥有两种补丁格式的解析与应用：整块格式（新增/删除/更新/移动文件，上下文块）与 SEARCH/REPLACE 块格式（含标记顺序校验）。`sequence_matcher.rs` 提供多遍模糊定位（精确、去尾空、去首尾空、Unicode 归一），使 ASCII 补丁能命中含排版字符的源文件。`edit_diff.rs` 提供编辑差异内核：差异计算、展示差异、只读预览、行尾与 BOM 处理、变更上下文行数常量，供审批流在执行前展示变更。

## 忽略规则

`ignore.rs` 与 `filesystem/ignore.rs` 分别覆盖发现侧与执行侧的忽略：内置目录表（依赖目录、构建产物、版本控制、隐藏目录等）、Git 忽略集成、自定义规则三层叠加，临界目录（版本库、虚拟环境等）永不过度放行。
