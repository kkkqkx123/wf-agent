# Web 前端功能清单

> 以当前后端实际能力为边界：所有后端驱动功能均可在 `crates/app/wf-server` 现有路由中找到对应；借鉴方向见 `docs/plan/web/web-frontend-borrow-analysis.md`，原始实现见 `docs/ref/frontend` 下两份说明。前端特有功能单列于第六节，不依赖后端变更。

## 1. 范围原则

- 后端驱动功能只收录服务端已提供读取或写入通道的域，不为缺失后端的新功能做前端预设。
- 聊天式隐喻只在 Agent 回路域使用；工作流执行域使用执行与节点隐喻，不混用。
- 旧文档 `docs/apps/web-app` 中的 Node 后端与 SDK 假设已失效，涉及部分以本文为准。

## 2. 页面与导航

> 方向更新：本节原定执行工作台为默认落地页，现已翻转为对话优先。默认落地页为对话 IDE，执行工作台退为附加页，详见 `chat-ide-primary-design.md`。下表的一级导航对应后端域划分保持有效，落地顺序按翻转方案执行。

一级导航对应后端域划分：

| 页面 | 后端依据 | 借鉴来源 |
|---|---|---|
| 执行工作台（执行列表加详情三栏） | 执行查询、状态、分析、审计 | zcode 三栏 Shell |
| 工作流（列表、详情、版本、草稿、可视化编辑） | 工作流定义、版本、图、草稿 | zcode 产物面板，deeix 文件库三栏 |
| Agent 回路（列表、详情、消息、变量、图、分析、检查点） | 回路、消息变量、图、错误分析 | zcode 会话窗格，deeix 对话页 |
| 检查点与文件（执行检查点链、文件分区会话与时间线与差异与审批） | 检查点域 | zcode 文件树与预览与 Git 面板 |
| 触发器与钩子（触发记录、钩子试发） | 触发器域 | deeix 管理后台 |
| 模型与工具（模型档案与供应商与生成试算、工具与脚本、技能） | 大模型域、实体技能 | deeix 模型感知输入框 |
| 模板库（节点、触发器、Agent 模板，工作流与 Agent 注册表） | 模板域 | deeix 技能画廊 |
| 查询与审计（即席查询、执行审计报告、错误分析、性能） | 观察域 | deeix 统计图表 |
| 事件与系统（事件流、时间线、依赖影响、存储诊断、指标） | 系统域 | deeix 管理后台 |
| 设置（外观、执行默认、通知） | 偏好读写走服务端，高频项可本地缓存 | deeix 设置分区 |

全局能力：命令面板（跨工作流、执行、模板、文件统一搜索）、执行内查找、最近访问、全局 Toast。

## 3. 后端驱动功能清单

### 3.1 工作流

- 列表：分页浏览、按名称与标签与分类与作者过滤、卡片与表格切换、搜索。列表走统一游标包络（`items`、`limit`、`offset`、`has_more`），无总数，前端按游标翻页。
- 详情：基本信息、图摘要、节点边列表、邻居与可达性、版本历史、生命周期、执行历史入口。
- 版本：版本列表、版本对比查看、递增、回滚。
- 草稿：草稿列表、校验、提升为正式、批量提升。
- 可视化编辑：图渲染、缩放平移、节点选择与详情、路径统计展示；节点创建与连线编辑仅当后端校验通道可用时启用（校验、单节点校验、解析、变换均已存在），保存走更新通道。
- 导入导出：单工作流导出导入、全量导出、批量导入；走 JSON 体通道，无文件下载头，前端自行组装下载。

### 3.2 执行

- 列表：按工作流与状态过滤、游标分页浏览、执行时长展示。批量取消与删除走批量通道；未读徽标暂为前端本地派生（无通知通道）。
- 详情：状态、变量、迁移、上下文、调用栈、内存（含峰值）、变量快照与演化、状态分析。调用栈与内存视图为本项目特有，zcode 与 deeix 均无对应，直接按后端字段渲染。
- 控制：启动（含流式启动）、暂停、恢复、取消；触发器关联查询。
- 分析：路径枚举、决策点、慢节点、效率、替代路径、概率、节点统计、失败节点、迭代、工具链、输入上下文、大模型推理路径。图过大时按需加载节点详情，不一次性展开。
- 审批与交互：审批请求与检查与工具执行、交互列表（按执行与状态）、响应、统计。未读徽标暂为前端本地派生，待服务端通知通道补齐。

### 3.3 Agent 回路

- 列表与摘要统计：游标分页浏览、状态过滤、摘要与统计。星标与标签走服务端收藏通道。
- 详情：摘要、迭代历史（含汇总）、时间线、变量历史、上下文演化、执行路径；运行、暂停、恢复、取消、状态迁移；流式运行走流式通道。
- 消息：列表、搜索、统计、去重、会话视图；分支切换沿用后端会话结构，不自创分支模型。
- 变量：列表、统计、导出、单变量读写；批量写暂走多次单写。
- 图：节点边、路径、关键路径、替代、序列、未探索分支、工具频率、模式、效率、概率。
- 错误分析：错误链、根因、高级统计、恢复建议、相似错误、性能对比。
- 检查点：创建、链查看、恢复与续跑（含分支与原地模式）、删除、统计；清理已完成走批量清理通道。
- 草稿：列表、校验、提升，与工作流草稿同交互。

### 3.4 检查点与文件

- 执行检查点：创建、链查看、恢复与续跑、按实体与时间范围查询、元数据读写。对比预览走文件差异通道复用，不自建比较模型。
- 文件工作区：分区、按 Actor 与路径的变更、重建元数据、差异（双 Actor 与暂存）、时间线、会话创建与回滚、撤销重做、重命名、回收、待审批与批准拒绝。文件内容读写与目录树后端未提供，前端只做变更与差异展示，不做文件编辑器。
- 审批：待审批列表、批准拒绝，接入全局审批入口。

### 3.5 触发器与钩子

- 触发记录：列表、统计、按执行与触发器与工作流过滤、清理。
- 钩子试发：按钩子名发送测试负载并展示结果；幂等键由前端生成。
- 触发器模板的启用停用与定时启停后端未提供，不做对应前端开关，只做记录查看与试发。

### 3.6 模型、工具、脚本、技能

- 模型档案：增删改查、默认设置、导入导出、从模板创建、校验；档案模板查询；供应商列表与模型列表。密钥展示遵循遮罩约定，前端不回显密钥原文。
- 生成试算：单次生成、批量生成、Token 计数、流式生成；用量与成本按分析指标展示，不自算价格。
- 工具：列表、搜索、详情、执行、参数校验、启用停用、注册表增删与统计。工具调用卡片化渲染借鉴 zcode 工具块，但类型全集以后端注册表为准，不预置 zcode 的种类。
- 脚本：列表、搜索、执行、校验、启用停用。
- 技能：列表、查询、启用禁用、扫描重载、缓存清理、提示词查看。安装与版本管理后端未提供，不做对应入口。

### 3.7 模板库

- 节点与触发器模板：增删改查、导入导出；Agent 与 Agent 触发模板：列表、摘要、精选与热门、使用与克隆。
- 工作流与 Agent 注册表：查询、精选热门、使用与克隆。评分评论与发布流后端未提供，不做对应入口。

### 3.8 查询、审计、分析、搜索

- 即席查询：过滤、排序、分页、导出、聚合、分组、去重、求值；结果表格化，大结果集分页拉取。
- 审计：摘要、报告、时间线、迭代、工具调用、大模型调用、节点执行、进度。报告支持只读分享视图（前端路由级只读，不设后端分享令牌，待服务端补齐）。
- 错误与性能：错误分析（含流式）、高级分析、根因、上下文、恢复推荐、相似、性能、摘要、瓶颈、迭代对比。大 dump 通道无分页，前端做分段请求与虚拟化。
- 全局搜索：统一搜索框聚合工作流搜索、工具搜索、脚本搜索、消息搜索，统一通道自带分面与总数；跨源游标仍需前端合并。

### 3.9 事件与系统

- 事件：实时流订阅、按执行与回路与工作流过滤的游标分页列表、统计、搜索、时间线（含回合与工具执行）、监听器统计。删除事件为危险操作，前端须二次确认。
- 依赖：调用方查询、影响分析、审计。
- 运维：健康、信息、存储诊断与健康与统计、系统诊断、事件健康、过期清理、指标快照。备份恢复与配置热加载后端未提供，不做对应入口。

## 4. 流式与实时

- 简单日志与时间线使用 SSE；多执行并行订阅使用 WS。两者按后端现有约定接入，不自创协议。
- POST 流式通道无法用原生事件源直连，前端统一用可取消的流读取器封装，处理认证、限流、重连与断点续拉。
- 套接字支持按执行、回路、工作流三维度订阅，负载仅为元数据；详情按需用 REST 补拉。全局主题与通知通道缺失，仍用多订阅合并模拟。
- 流式渲染必须限速合并，避免逐帧全量重渲染；长列表虚拟化，自动跟随尾部可手动接管。

## 5. 非目标

> 范围决定：登录与计费、订阅类功能不引入，只实现后端已有的功能。本节逐项列出排除项，实施中不再重议。

- zcode 桌面专属：自绘标题栏、托盘徽标、防休眠、原生通知声音。
- deeix 专属外环：密码与 OAuth 登录、多媒体生成模式、PWA 安装、订阅计费、内容审核运营页。
- 需要新后端才能成立的功能：文件内容编辑、触发器定时启停、技能安装、模板评分评论、通知收件箱。本清单均未收录，见服务端补充分析。

## 6. 前端特有功能

> 本节功能仅存在于前端，不需要服务端配合，单独列出以界定前后端边界。

| 功能 | 说明 | 状态存放 |
|---|---|---|
| 应用壳与导航 | 对话优先三区布局（会话侧栏、对话列、边面板），工作台退为中心列模式；侧栏折叠与悬停展开、尺寸记忆、移动端抽屉、面包屑 | 本地持久化 |
| 命令面板与执行内查找 | 全局统一搜索入口、执行内双搜、历史记录 | 本地历史加内存索引 |
| 主题与外观 | 浅色深色跟随系统、多预设、字号档、预注水防闪烁 | 本地偏好 |
| 状态语义色 | 执行状态、变更类型、轨迹类型的独立配色 | 样式 Token |
| 虚拟化与分页兜底 | 大列表虚拟滚动、无总数分页的游标模拟 | 内存 |
| 流式限速与跟随 | 合并渲染、自动跟随尾部、手动接管、回底按钮 | 内存 |
| 加载态体系 | 骨架、流式占位、空态、错误态、重试 | 内存 |
| 本地收藏 | 星标与标签走服务端收藏通道，离线兜底才存本地 | 服务端为主，本地为兜底 |
| 输入草稿 | 各表单与输入框草稿保留、跨页面恢复 | 本地持久化 |
| 快捷键 | 全局与输入框级快捷键、冲突提示 | 本地配置 |
| 附件组装下载 | 即席查询导出可用下载模式，其余导出走消息体由客户端组装下载 | 即时生成 |
| 只读分享视图 | 审计报告的前端只读路由，不设访问令牌 | 路由级只读 |
| 截图导出 | 时间线导出为图，属纯前端渲染能力 | 即时生成 |
| 大纲与位置导轨 | 长时间线的 headings 大纲与滚动小地图 | 内存派生 |
| 无障碍与动效偏好 | 焦点管理、简化动效兜底、触控优化 | 本地偏好 |
