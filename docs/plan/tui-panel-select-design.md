# 面板文本选择（对照 tui-panel-select）设计方案

对照对象为 `~/code/paperboy-tui` 中的 `tui-panel-select` crate，目标是判断当前项目是否需要同类面板级鼠标文本选择能力，给出符合现有分层架构的落地方式，并规划如何用 `ratatui` 演示验证。

## 一、目标

- 让会话滚动区、文件查看器等面板支持限定在面板矩形内的流式鼠标选择，拖拽不受边框与相邻面板干扰，松开即复制。
- 选择在缩放、换行模式切换、滚动后仍指向同一字符，而非同一屏幕格。
- 大文本与超长单行保持响应，只处理可见行。
- 演示以 `ratatui` 官方能力为底座，落点为现有 `wf-cli-demo` 示例体系，可人工审查、可回归。

非目标：替代终端原生选择（关闭鼠标捕获或按住 Shift 时的原生行为保持不变），不引入外部剪贴板守护进程依赖。

## 二、对照对象的做法

`paperboy-tui/crates/tui-panel-select` 按职责拆为若干模块，核心思想是逻辑位置与屏幕位置分离：

- 易用层提供单选面板与多选面板两种形态。单选面板持有单段锚点加游标，调用方在每帧传入文本、宽度、面板矩形与滚动偏移；多选面板在此基础上自持滚动偏移，支持多段、键盘扩展、拖出边界自动滚动、样式化行输入。
- 纯函数层实现流式语义：首行从点击列到行尾，中间整行，末行从行首到释放列。点到逻辑位置的映射先做面板内钳制，再经行列换算；高亮格计算只扫描可见窗口，不全量遍历。
- 换行缓存层按字符数精确换行而非按词，维护每行字符长度与累计行数的前缀和，支持换行与裁剪两种模式、续行标记列、窗口化取行。缓存以文本指针 Identität 加宽度加模式为失效条件，每帧调用开销低。超长行通过跳过加截取的字符窗口处理，避免整行物化。
- 剪贴板层优先尝试本地工具再回退到 OSC 52 转义序列。本地优先的原因是 OSC 52 写入标准输出恒成功，无法感知终端是否执行，回退方向不可判。X11 工具排在 Wayland 工具之前，以避开部分合成器下映射顶层窗口的副作用。另有 tmux 包裹处理与测试禁用开关。
- 终端守卫层集中管理鼠标捕获模式的进入与退出，并在 panic 钩子中恢复，避免用户 shell 残留跟踪序列。
- 滚动条层为面板无关的辅助：轨道点击行到滚动偏移的比例换算，以及按内容总量与视口容量绘制滑块。

其 `ratatui` 依赖面很窄：几何类型与文本行用于渲染，`crossterm` 事件仅用于鼠标，另用部件库绘制滚动条。与工作区 `ratatui 0.30` 同代，无版本冲突。

## 三、当前项目的做法

- 选择模型基于显示行列：`wf-tui` 会话层维护 transcript 选择的锚点与头部显示坐标，绘制时在文本宽度内反白，释放时按显示行截取词或行后复制。缩放或重排后选择不保证指向同一字符。
- 鼠标捕获为显式可选策略，默认关闭以保住原生选择；滚轮、边栏点击、拇指拖拽、徽标回尾已有通路，但内容区拖选只有单段且无自动滚动。
- 剪贴板只有 OSC 52 单路径，经控制面在整帧绘制完成后刷出，能力探测保守，远程与多路复用场景下经常被拒绝。无本地工具路径，无 tmux 包裹。
- 换行与行映射分散在 `tui-markdown` 的纯文本与样式化渲染、`tui-core` 的列映射、`tui-render` 的预排缓存与行源映射中，尚未形成统一的逻辑位置抽象。
- 滚动条已有视图组件，按总量与视口判断可见性，键盘与滚轮驱动，轨道拖拽在会话层处理。无需照搬对照对象的滚动条实现。
- 演示体系成熟：`wf-cli-demo` 按 `tui`、`mini`、`headless` 分组，`ratatui` 交互示例统一用合成数据，有画廊、按键接收、差异录制等既有模式，新增示例只需注册清单与文档。

## 四、差距与借鉴结论

值得引入的是三样东西：逻辑位置抽象、窗口化换行缓存、本地优先的复制回退。面板自持滚动与多段选择按需引入，先满足会话主滚动区单段选择即可。终端守卫思想值得借鉴，但应并入现有 `tui-terminal` 的模式管理，而非新增守卫类型。滚动条不重复建设，复用现有组件。

## 五、落点设计（按现有职责拆分，不建新 crate）

依据架构规则按职责归位，不复制对照对象为独立模块：

- 纯选择语义归 `tui-core`：有序化、点到逻辑位置、按行区间取文、高亮格计算。仅依赖几何与行访问接口，不持有滚动状态，调用方每帧传入面板矩形与滚动偏移。排除装饰字符的复制变体一并归此。
- 换行缓存与面板状态归 `tui-core`：每行字符长度缓存、累计行数前缀和、逻辑位置与行列双向换算、可见窗口取行、换行与裁剪两种模式，以及组合缓存与选区的 `SelectablePanel`。缓存下沉到 `tui-core` 使 `tui-components` 的查看器可以自持选区而不反向依赖 `tui-render`。失效条件沿用文本指针、宽度、模式与续行标记四项。超长行走字符窗口路径。
- 剪贴板后端归 `tui-terminal`：在现有 OSC 52 单路径旁增加本地工具优先、OSC 52 回退的决策链，含按需固定模式的环境变量与进程内开关、tmux 包裹、子进程脱离与后台回收。测试默认禁用，沿用现有消毒与绘制后刷出时序。
- 鼠标接线归 `wf-tui` 壳层：按下开始、拖拽扩展、释放复制的三段调用保持不变，只是把显示坐标换成逻辑位置；拖出边界时按固定节拍推进滚动并扩展游标；面板外点击清除行为沿用现有配置。
- 主题与样式不新增语义色，选中高亮复用现有反白与强调色；续行标记与滚动条样式沿用现有弱化风格。

`wf-mini` 不进入本次范围，其无捕获、无重绘的追加式模型与面板选择互斥。

## 六、用 ratatui 演示的方案

在 `wf-cli-demo` 新增一个 `tui` 分组交互示例，命名沿用 `tui_<surface>_showcase` 规则，内容全部使用合成数据，不接真实服务：

- 布局为左右双面板：左侧为长文本换行面板，右侧为等宽程序输出裁剪面板，底部状态行说明按键与鼠标手势。两面板各有独立选择态，以验证选择限定在面板矩形内、不跨边框。
- 键盘演示换行与裁剪模式切换、续行标记开关、滚动；鼠标演示按下拖拽选择、拖出上下边界自动滚动、轨道点击跳转、松开复制（演示中固定为禁用真实复制，仅展示待复制文本）。
- 同一示例支持两种运行形态：真实终端形态用于人工审查手感，`TestBackend` 形态用于单测与差异录制回归。差异录制复用现有 `diff-record` 特性门控。
- 验收数据覆盖三类：多屏长文本、单行超长文本、含制表符与宽字符的混合文本，分别验证重排稳定性与窗口化开销。
- 注册事项：在示例清单与 `examples/tui/README.md` 中登记运行命令与按键表；在界面对齐设计的人工验收清单中追加选择与复制条目。

## 七、落地顺序与验收

- 先落 `tui-core` 纯选择语义与单测，再扩展 `tui-render` 换行缓存与窗口化取行，接着补 `tui-terminal` 剪贴板后端，最后接 `wf-tui` 鼠标三段调用与示例。
- 单元测试覆盖流式三段语义、逆向拖拽、空行与空白选择、缩放重排后同一字符、超长行窗口开销、剪贴板模式解析与禁用。
- 渲染测试覆盖双面板限定、续行标记列不占字符、滚动条显隐不断言崩溃。
- 全量校验收敛为一次完整编译检查。

## 八、落地状态回填

- `tui-core`：`TextPos`、`PanelGeometry`（含 `Motion`、`clamp_pos`、`move_pos`、`select_all`）、`PanelWrapCache`（由 `tui-render` 下沉）、`SelectablePanel`（单区域 + 冻结区域、`set_plain`/`set_styled`、`set_marker`）与对应单测已完成。
- `tui-terminal`：本地工具优先、OSC 52 回退、模式固定与绘制后刷出保持原状，本次未改动。
- `wf-tui`：transcript 选区改为逻辑坐标；命中与复制复用 `PreparedScrollback` 的行索引与窗口定位；滚动、resize 后选区保持；拖出边界自动滚动时锚点保持逻辑位置；键盘选择（`Shift` 方向/Home/End/PgUp/PgDn、`Ctrl+A`、`Esc`、`Ctrl+Y`）已接入；`Alt+Click` 可冻结当前区域并追加新的不相邻区域，复制时按逻辑位置排序合并。
- `tui-components`：`Modal` 支持鼠标手势与可变绘制，文件查看器、diff 查看器基于 `SelectablePanel` 拖选复制，`Alt+Click` 追加区域，`Esc` 先清选区再关闭。
- 历史分页器：`HistoryOverlay` 持有 `SelectablePanel`，绘制时同步 styled 行并回填内容矩形与顶部行号，拖选复制与键盘扩展选择已接入。
- styled / ANSI 投影：transcript 的几何与复制建立在 `HistoryLine::logical_plain_lines`（渲染后的纯文本投影）上，Markdown 标记不会错位；查看器与历史分页器使用 `SelectablePanel::set_styled` 同时保存 styled 行与纯文本。transcript 本身不解析 ANSI 转义，工具输出中的转义序列按普通字符呈现。
- 续行标记：`SelectablePanel::set_marker` 与 `PanelWrapCache` 的 `reserve_marker` 已提供预留列开关，默认关闭；transcript 与各查看器当前均未启用可见标记字形。
- `wf-cli-demo` 双面板示例保留为底层能力验证，未改为 `SelectablePanel` 调用方。
