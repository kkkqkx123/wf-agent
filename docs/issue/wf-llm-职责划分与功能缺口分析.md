# wf-llm 职责划分与功能缺口分析

> 对象：`crates/infra/wf-llm` 及其在 `wf-types` 中的类型定义。
> 结论前置：核心概念分层清晰，但 crate 内部存在职责混杂；功能覆盖主流对话链路，存在若干明确缺口。

---

## 一、核心概念

### 1.1 三层配置模型

类型定义位于 `wf-types/src/llm`，装配逻辑位于 `wf-llm/src/config`，层次关系为线协议、连接模板、模型绑定三权分立。

- 线协议格式：描述请求如何编码，不含地址、鉴权与模型，内置四种，对应四个编解码器，未知名称归为自定义并经运行时注册表解析。
- 服务商定义：多画像共享的连接默认值，画像引用后在注册期做一次性合并，请求热路径不再访问该注册表。
- 画像：单模型的静态默认值集合，包含格式、模型名、密钥地址、生成参数、工具协议、超时重试等。
- 请求：单次调用的动态覆盖，包含消息、工具、协议锁定与违例策略、流开关与防循环配置。

该分层合理，是本次分析中无需改动的部分。

### 1.2 传输与编解码

- 编解码器 trait 承担请求构造、响应解析、流分块解析、工具声明转换、工具调用提取、计数请求构造与解析六项职责，内置实现各一份，另有插件适配器。
- 客户端 trait 只暴露生成、流式生成、计数三个异步操作；其实现类负责超时、重试、取消与错误分类。
- 网关是唯一门面，负责画像解析、请求合并、客户端缓存、编解码器路由、用量指标记录与测试替身路由。

### 1.3 生成参数与工具协议

- 生成参数分类型化参数与遗留键值两套输入，经四层优先级合并后按格式校验再按格式发射。
- 工具调用协议分原生、XML、两种 JSON 共四种，另有锁定协议与四种违例策略，由网关合并阶段裁决，文本模式解析与提示词渲染为配套模块。

### 1.4 Token 治理与消息会话

- Token 下分估算、计数、追踪、事件、流式计量五个子模块，其中追踪采用决策轨与成本轨双轨制，决策只依赖本地估算。
- 消息下分流式传输、会话状态、历史转换、文本化、边界注入、消息操作、消息构造七个子模块，其中会话状态携带检查点兼容字段，被引擎层多处直接依赖。

## 二、职责划分问题

### 2.1 网关装配序列三处重复

生成、流式生成、计数三个入口各自重复同一装配序列：测试替身分支、画像解析、请求合并、客户端获取。重复的不是单行代码而是一整段装配职责，新增入口或调整装配顺序时极易遗漏其一。

### 2.2 计数执行跨模块掘取传输内部

计数执行函数位于 token 模块，却直接读写客户端实现的传输字段与私有超时构造。传输执行职责因此泄漏到估算模块，客户端字段被迫放宽可见性。正确归属应为：估算归 token 模块，执行归 client 模块。

### 2.3 客户端持有完整画像快照

客户端实现类整体克隆画像，网关按画像编号加模型名缓存实例。画像字段增减会无声波及传输层，且缓存键不能反映连接字段变化，只能依赖注册与删除时的驱逐逻辑隐式保证一致。

### 2.4 编解码器 trait 职责过宽

同一 trait 混合线协议编解码、工具提取与计数端点三类职责。新增能力会持续撑大该接口，自定义编解码实现者被迫关注无关方法，好在计数方法已有默认实现，现状可运行但边界不清。

### 2.5 引擎域逻辑寄居于基础设施层

会话状态、历史转换、消息操作、Token 事件构造均属引擎域的会话与事件契约，却实现在 infra 层，被执行共享层、智能体层、工作流层、运行时层直接依赖。依赖方向名为下层实为同级复用，后续按职责拆分时这些是首要搬移对象，但搬移涉及检查点序列化兼容与多 crate 联动，本次不做跨 crate 搬移，仅在文档与注释中明确归属。

## 三、功能覆盖与缺口

### 3.1 已覆盖

主流对话链路完整：四种线协议、流式传输、超时重试取消、按格式计数优先加本地估算兜底、较丰富的生成参数、文本工具协议与锁定策略、模型发现四种模式、用量计量、死循环检测、残缺 JSON 修复、脚本化测试替身。

### 3.2 缺口

- 能力面窄：仅有对话生成，无嵌入、重排、图像、音频语音类能力；多模态停留在 token 估算启发式层面。
- 鉴权种类少：仅覆盖承载令牌与两种专用头，其余依赖自定义头与自定义体逃生舱补足，说明抽象有洞。
- 韧性不足：重试判定依赖状态码前缀字符串，无重试等待头尊重、无熔断、无多画像故障转移。
- 无缓存与预算：无提示词缓存显式支持、无响应缓存、无成本预算强制，仅做记账。
- 无真实分词器：计数兜底为字符启发式，与各模型真实分词存在系统性偏差。
- 可观测性薄：仅用量计数与重试日志，缺少按模型与画像维度的延迟错误统一打点。
- 模型目录简陋：发现鉴权简化，无分页、无缓存有效期、无失败降级。
- 结构化输出只发不验：响应格式约束只负责发射，不做本地校验，错误推迟到服务商侧。
