# Git 工作台骨架设计（P5）

> 范围：新建 Git 工作台页的只读骨架。不含键位输入栏写操作与终端交互。

## 1. 路由与导航

新增一级路由，与工作流、执行、检查点同级，导航中新增源码分组。地址状态复用已有的面板与标签键，刷新后恢复所在面板。首期不做子路由，提交详情与分支详情一律用主视图承载，避免导航打断输入焦点。无仓库时显示空状态并引导配置，不白屏。

## 2. 页面布局

自上而下四区：顶栏状态条、主体侧栏加主视图、键位输入栏占位、命令行终端占位。P5 只实现前两区与两个占位的折叠形态。顶栏显示仓库名、当前分支、上游、前后计数、中间态徽标与刷新。侧栏分组沿用默认分组，首期激活状态、文件、分支、提交、贮藏，工作区与子模块只读或隐藏。主视图三态切换对应已存与未存差异与提交文件，用分段控件承载。

响应式遵循现有视口判定。宽屏为完整多区，窄屏侧栏收为抽屉，移动端降级为单栏流并隐藏终端占位。

## 3. 组件划分

页面容器负责四区布局、键盘仲裁总入口、仓库订阅。侧栏壳负责分组标签与过滤框，文件、提交、分支、贮藏各一列表组件。主视图壳负责三态切换与工具条，差异窗格复用现有差异组件并附加 hunk 导航。输入栏与终端在 P5 仅保留挂载位置与折叠语义，交互延至后阶段。动作菜单、动作对话框、帮助面板在 P5 可缺席，右键菜单暂不接入。

所有交互元素取自基础组件库，不新增基础组件。触屏上不优化单键输入，以点击候选为主。

## 4. 服务与状态

服务层沿用从客户端取值、拆信封、转领域模型的惯例。只读一组函数各取其一，另有注册表拉取。领域转换在服务层完成，组件不接触原始表示。快照数据、上下文选择、加载分页、执行中的动作与错误四组状态分离。选中按面板分离保存，切换不丢选择。版本指纹变化按范围局部刷新，不整页重载。输入状态与业务状态分离，避免大列表重渲染。

## 5. 实时性

订阅仓库变化并局部刷新。P5 先接通订阅生命周期与指纹比对，动作为空时不推送。折叠不销毁上下文，离开路由销毁。分页游标与已见集合分离，避免重复加载。

## 6. 夹具与预览

预览工程的静态夹具同步补齐新增只读接口，覆盖状态、文件、分支、提交、贮藏五组。漂移纳入同步脚本的覆盖校验。路由、服务、状态的新增文件经同步脚本传播，预览专用的客户端分支与夹具目录不受影响。

## 7. 验收

能看能选能切换；选中文件显示差异；切换不丢选中；刷新后恢复面板；窄屏无溢出；无仓库显示引导；变更后局部刷新而不整页重载。

## 8. 测试

服务层做原始状态到三态的转换单测，差异与状态解析优先补边界单测。绑定表与词元解析不在本阶段测试。终端行为以手工验证为主。
