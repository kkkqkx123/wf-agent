# zcode 前端实现说明

> 对象：`ref/zcode/packages/web`（Web 宿主）+ `packages/ui`（完整产品实现，约 600 文件）+ `packages/desktop`（Electron 壳）+ `packages/shared`（UI 直接消费的类型与协议）。
> 视角：仅关心功能与 UI，不关心 GUI / Web / 语言差异。路由、布局、组件、样式均为功能性描述。

## 1. 概述

zcode 前端是典型的 Agent IDE 工作台：以对话为中心，右侧挂多功能 SidePane，左侧为任务侧栏，底部可展开终端。实际 UI 全部在 `packages/ui` 中实现，`web` 与 `desktop` 只是两种启动壳（Web 用 WebSocket 接服务，桌面用 MessagePort 接本地进程），挂载的是同一套 `Root` 组件。

不使用路由库，路由靠 URL 路径加查询参数加内部 Tab 状态机实现。状态以 Zustand 为主，按工作区键隔离会话状态，配合多个细粒度 store（面板、Tab、MCP、插件、技能、子代理等）。

## 2. 功能清单

### 2.1 启动与 gating

| 功能 | 说明 |
|---|---|
| 启动加载 | 等 OAuth 恢复、模型供应商同步、Tab 持久化恢复、初始工作区就绪后才进入主界面 |
| 欢迎屏 | 支持 OAuth 登录与 API Key 登录，区分多种打开原因 |
| 首次引导 | 职业问卷与新手引导对话框 |
| 设置页 | 以覆盖式 Tab 形式打开，而非独立路由 |
| 目录浏览与远程连接 | 目录选择器、SSH 连接对话框均为全局弹窗 |

### 2.2 对话与会话

| 功能 | 说明 |
|---|---|

| 排队 | 生成过程中可继续追问，队列面板管理待发送消息 |
| 待定交互 | 问答卡自动处理、命令恢复横幅、错误横幅 |
| 配额与上下文 | 配额横幅、上下文用量分解、滚动工具栏标签 |
| 查找与回溯 | 会话内查找、文件回退对话框、文件摘要面板 |
| 分享与复刻 | 选择分享、只读时间线预览、导入提示、复刻高亮 |

### 2.3 工具调用块（约 35 种渲染器）

编辑（内联 diff）、执行与输出、探索与变更分组、计算机操作（含截图与列表详情）、MCP 调用、提问与升级、Workflow 创建与定时创建、执行记录查询、Node REPL（含图片网格）、兜底渲染。配套权限弹窗、询问弹窗、Workflow 权限块、模型轨迹时间线与搜索。

### 2.4 设置（16 分区）

通用（语言、通知、代理、数据目录、终端字体、自动归档、更新）、外观（主题、代码预览、字号）、模型供应商、记忆、子代理、插件（含商店详情与来源）、MCP、技能、命令、自动化（定时、模板、历史、已保存 Workflow 的启动与产物）、Hook、浏览器（内嵌与非安全证书）、计算机操作（仅桌面）、快捷键（录制、搜索、冲突检测）、工作区文件搜索忽略规则、用量统计（应用与个人或团队配额来源、热力图与图表）。

### 2.5 文件浏览与预览

虚拟化文件树（拖拽、置顶文件夹、Git 状态着色、层级引导线、文件监听、外部编辑器打开）、工作区文件搜索（Worker 过滤）、目录浏览器。预览支持文本与代码（高亮、换行开关）、Markdown 预览与源码切换、SVG、图片、音视频、PDF（分片加载）、Office 文档与表格、幻灯片（含文件监听与引用导航）、多文件 Patch 兜底。面包屑带文件图标，支持代码选区评论并加入对话、在编辑器中打开。

### 2.6 终端

基于 xterm 的多标签终端，按工作区键隔离，切换时保活，PTY 退出自动关闭；每任务独立的 SidePane 终端；后台 Bash 输出 SidePane；耗时标签。

### 2.7 Git

变更面板（未暂存、已暂存、 ahead/behind 数据源，虚拟化变更卡，惰性 diff），分支切换器（按路径去重的脏计数），操作菜单，提交图。

### 2.8 浏览器与 Agent 计算机操作

自动化截图表面与人工交互视图分离，响应式视口加缩放与尺寸手柄，调整时变暗，工具栏加网站图标；计算机操作设置与独立权限窗口。

### 2.9 其他面板

目录会话、Actor 会话、工作区产物、Workflow 运行、计划详情、子代理会话与目录、白板（画布笔触可一键加入对话）、代码映射、开发者工具、模型轨迹。

### 2.10 命令、搜索与反馈

Command Center（命令、会话、文件统一搜索，历史记录，直接打开代码查看）、任务查找（会话与 diff 双搜，计数与脉冲高亮）、反馈中心（提交、工单、截图拾取、后台上传、功能请求）。

## 3. UI 布局

### 3.1 三栏 Shell

外层为全视口 Shell，内部分为三列：左侧任务侧栏（约 264px），中间对话列（头部标题栏加对话区加底部终端），右侧多功能 SidePane（代码、Git、浏览器、终端、子代理、Workflow、计划、白板、映射、开发者工具、轨迹等标签页）。自动化主页与插件商店页在中心列替换对话区。全局弹窗（任务查找、命令中心、反馈、Toast）浮于最上。

### 3.2 导航

工作区 Tab（可拖拽排序、展开折叠，按项目与会话分区）、侧栏任务视图（分组、工作区、时间线、归档四种，支持排序与分页）、头部前进后退、命令中心与快捷拾取、设置 Tab。桌面端保留原生交通灯与标题栏安全区，窗口顶部在侧栏隐藏时浮现新建任务按钮。

### 3.3 自适应

窗口宽度阈值自动折叠 SidePane 与侧栏；头部与 SidePane 内部使用容器查询切换网格；设置页在窄屏将侧栏收为图标；移动端输入字号固定避免 iOS 缩放。

### 3.4 尺寸记忆

外层侧栏使用指针捕获自定义拖拽（历史比例从本地存储迁移），内层终端与 SidePane 使用可调面板并记忆展开尺寸，侧栏宽度持久化。

## 5. 样式实现

- **框架**：Tailwind v4，配合 shadcn 变量、动画库、排版插件与滚动条隐藏插件；以 `clsx + tailwind-merge + class-variance-authority` 组织条件类名。
- **主题**：浅色、深色、品牌浅色、品牌深色、跟随系统五种，默认品牌深色；通过根类名切换并同步 `color-scheme` 与 `meta theme-color`，桌面与 Web 在绘制前预置主题避免闪烁。全部语义 token（含背景、侧栏、面板、卡片、浮层、输入、终端、标签、菜单、主色、前景、成功、危险、警告、Git、各类提及 чип、轨迹、Workflow）都有四套覆盖值。
- **字号**：基准 14px，语义阶梯（标题、常规、说明、小字、极小字，极小字仅用于 Workflow 坐标轴）；等宽字体栈覆盖三大桌面平台与中文字体；Markdown 支持公式与图表。
- **图标与动效**：统一细线图标；思考态渐变文字、流式进入、截图呼吸、复刻脉冲、配额重置撒花等自定义关键帧；全局去除默认焦点描边，使用 14px 圆角自定义滚动条（终端与幻灯片内隐藏）。
- **滚动与遮罩**：侧栏上下 32px 渐隐遮罩，面包屑与任务标题跑马灯，滚动经 RAF 节流。

## 6. 状态与数据流

传输层按宿主区分（Web 经 WebSocket，桌面经 MessagePort，远程会话经额外端口），统一收敛为服务访问器（文件、Git、终端、设置、模型选择、Agent 等）。Provider 层叠加服务、平台（桌面与 Web 桩）、广播、Tab、Diff Worker、会话、国际化。

Zustand 为主体：全局界面 store（主题、语言、用户、通知、界面模式、代码预览设置），按工作区键隔离的会话 store（激活任务、草稿、乐观任务列表），Tab store（标签、激活、展开路径，经设置服务持久化），面板分栏 store，任务查询缓存，全局列表索引，以及 MCP、插件、技能、子代理、Hook、白板、代码评论、反馈等 store。流式场景广泛使用浅比较选择器避免重渲染。

数据流为快照加流式事件，经会话数据层与传输层进入 store，再到虚拟化时间线与工具块；输入框经附件上传 store 与草稿传输进入 Agent 服务；SidePane 标签归属当前任务并经记忆桥恢复各任务的浏览器地址与 Git 数据源。

## 7. 特色交互

- 输入框 чип 颜色编码，缺省自动补全，支持粘贴、拖放与跨工作区流转。
- 流式打磨：骨架 shimmer、思考渐变文字、呼吸渐变、简化动效偏好兜底。
- 文本选中唤起侧聊，代码选区可加评论入话，白板笔触可入话，幻灯片元素缺失时提示并导航引用。
- 分享链路：选择 Dock、遮罩、成功 Dock、公开落地页（浅色默认、主题切换、登录门禁预览、深度链接导入）。
- 配额体验：滚动工具栏标签、上下文分解、独立于终端配色的热力图、倒计时自动消解。
- 桌面 fidelity：自绘 Linux 标题栏、mac 交通灯留白、Windows 标题栏覆盖安全区、未读徽标、任务通知（聚焦守卫）、静默发行说明确认、运行时防休眠。
