# 05 端到端覆盖现状分析

> 范围：`e2e/run-e2e.sh`、`e2e/lib/common.sh`、`e2e/fixtures`、`e2e/outputs/actual` 实际落盘结果，对照无头命令全集与服务端路由装配得出的覆盖盘点
> 与清单的关系：`04` 是按命令面整理的全量待验清单，本篇只回答当前脚本实际跑了什么、没跑什么、为什么算缺口

## 分析方法

以验证脚本实际执行的无头调用为唯一口径：一次 `run_headless` 或其变体对应一个被覆盖叶命令，判定方式看脚本内的成功与否定断言分支。输入口径看固件目录的版本化文件，输出口径看实际输出目录落盘的命名输出对。命令全集口径取共享参数定义中的顶层命令与各子命令枚举，服务端侧以路由装配中合并的领域路由为交叉印证。凡仅在帮助文本或路由中存在、从未被脚本调用的叶命令，一律计为未覆盖。

## 已覆盖功能

### 健康与诊断层

脚本以健康探针开场并以此作为服务端就绪门限，随后覆盖服务信息透传的列表形态、模式诊断、指标快照、完整诊断透传、存储健康透传、统一检索与条件查询基础形态。判定均为成功退出加业务包络可解析，其中健康类用例额外要求就绪标记为真，检索与查询类用例允许空结果，只要求结构可解析。该层无状态且总是可运行，是后续用例的前置门限。

### 工作流定义基础生命周期

覆盖最小起止流程的校验、创建、展示、图结构检视、列表可见、删除与删后清理，以及两条否定路径：展示不存在的定义、以内置的执行输入对象冒充定义文件做校验。判定为各步退出码符合预期，展示与检视包络可解析出目标标识，否定路径要求非零退出。输入仅用最小起止流程一种定义，刻意不与脚本注册表耦合。

### 执行体读路径与否定路径

覆盖空态列表、查询不存在的执行体、观察不存在的执行体到达终态。判定为空态列表成功且结果为空，不存在目标返回非零退出并给出可识别的未找到信息。该组验证的是执行读视图的错误映射，不触及真实执行。

### 注册表只读透传

覆盖工具列表、技能列表、模板列表三个只读端点。判定仅为成功退出且包络可解析，不对条目数量做精确断言，避免与本机插件状态耦合。工具与技能与模板的展示、检索、启停、注册等写路径均未覆盖。

### 本地执行闭环

覆盖脚本注册、脚本流程创建、后台触发执行、单次观察终态、执行摘要读取，以及工作流与脚本的条件清理。该层是默认门禁中唯一的真实执行闭环，依赖本地脚本执行能力。环境不支持时脚本明确跳过并报告原因，不记为通过。另有一个非门禁的一致性探针，对比观察视图与展示视图的终态是否收敛，只累积证据不决定成败。

## 覆盖特征

当前覆盖集中在无外部依赖的健康、只读与最小写路径，约为命令全集的一成多。有状态用例只用两个具名标识，运行顺序固定串行，用例结束即删工作流定义，执行记录随内存服务端退出而消失。固件遵循最小可用原则，管理链路只用最小流程，执行层单独使用脚本流程。黄金目录尚为空，脚本只做退出码加包络存在性断言，未做归一化后的黄金比对。破坏性操作依赖非终端下的免确认默认行为，无需额外确认标志。

## 未覆盖功能

### 工作流定义进阶

更新、克隆、导出导入往返、版本列表展示升级差异、版本回滚、执行图检视均未覆盖。列表的条件过滤与分页、图检视的聚合摘要与环检测与拓扑与可达性等选项分支也未覆盖。重复创建同标识的唯一性约束在设计文档中有要求，但当前脚本未显式执行第二次创建，实际处于缺失状态。

### 执行体进阶

除触发、单次观察与摘要外的全部执行面均未覆盖：日志与状态、暂停恢复取消、状态细节检视、层级与子树、性能与错误分析、执行删除与清理、运行中输入追加与转向、代理循环查询、嵌套追加族、批量清理均无用例。列表的状态与工作流与统一合并等过滤分支、展示的附带时间线与变量等选项分支、触发的输入内联与变量赋值等形态分支也未覆盖。

### 检查点与审批

状态记录与文件分区两大族共数十个叶命令完全未覆盖，包括创建列出展示、打标去标与差异、新分支恢复与删除、链路回收与实体查询、文件提交历史与树读取、撤销重做与冲突处理、送审合并与回滚、待审批列出与批准拒绝。审批域当前无任何用例。

### 实体与工具链

工具与脚本的展示检索、参数校验与执行、启停与落盘删除，技能的条件查询展示与启停扫描重载，模板的展示克隆注册与版本回滚，变量的读写删除，消息的列出检索，任务的列表展示统计取消，触发器模板管理与历史台账清理，均未覆盖。脚本的保存与删除仅作为本地执行的附带前置出现，不验证其自身的展示与检索语义。

### 大模型配置

档案的列表展示校验与文件创建更新删除、默认档案读写与脱敏导出、供应商列表与模型发现、模板按类查询均未覆盖。登录登出与代理凭证因依赖外部凭证与网络，保持手工是合理的，但档案与供应商的只读面本可进入默认门禁，目前仍缺失。

### 可观测与检索进阶

统一检索与基础查询仅覆盖空结果可解析形态，条件查询的分页聚合导出、审计摘要报告时间线、事件列表统计跟随、执行时间线、进度对比分析均未覆盖。指标仅覆盖快照展示，导出形态未覆盖。

### 会话与系统远端

智能体单次会话、预批准前缀与全盲批准、交互式应答、结构化上下文与附件、工作区隔离均未覆盖，其中依赖真模型的保持手工是合理的，但工作区展示、目录隔离语义、配置备份导出导入、远端主机注册列表、隧道与启停命令打印等无模型依赖的系统面也未覆盖。执行包拉取依赖远端执行记录，可列为手工或受控前置用例。

### 横切能力

目录作用域隔离、多目录串扰、鉴权失败映射、输出形态切换、超时预算、并发与串行语义、幂等重试均无用例。否定与连接类仅覆盖不存在标识与非法定义文件，缺失输入文件、未知工作流触发、不可达服务端的启动指引等可操作性用例尚未接入。

## 结构性缺口

固件只有最小流程、脚本流程、执行输入对象、脚本注册元数据与手工提示词五种，缺少更新与克隆与导入导出所需的第二定义、触发器模板、工具定义、变量与消息断言所需的执行上下文。黄金目录为空，归一化脚本虽已存在但无人调用，回归只能靠退出码，无法捕捉字段级漂移。断言只看成功标记与退出码，不校验标识回显、列表包含关系、删后不可见等读写一致性。清理仅覆盖工作流与脚本，执行记录、检查点、触发台账、变量等残留无清理约定。环境跳过语义只在本地执行层实现，其他依赖本地能力的用例尚无统一的跳过与报告约定。

## 风险判断

高风险缺口为执行生命周期控制与检查点文件域：暂停恢复取消、删除清理、恢复分支、合并回滚等语义一旦漂移，现有门禁完全无感知。中风险缺口为工作流更新克隆导入导出与版本回滚、工具脚本模板的写路径、变量消息任务触发器的读写一致性：管理面回归只能在联调阶段暴露。低风险但高价值的是只读与文件型用例的批量补齐：成本低且能快速抬高命令面覆盖率。手工层保持现状，不扩大默认门禁的外部依赖。
