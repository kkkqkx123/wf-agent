# Web 前端总览

> 范围：`apps/web-app`（Modular Agent Framework 的 Web 前端，npm workspace 成员）
> 状态：基于当前代码的静态分析

`apps/web-app` 是框架唯一的人机交互面：全高终端页承载 TUI 程序（含 lazygit），IDE 页承载轻量文件树、编辑器与内嵌终端，Git 页承载仓库工作台。终端一律经由 PTY 持久会话走透明字节管道，前端只做渲染与键位归属，不接管应用自身的模式设置。

## 终端键位总则

浏览器保留键是唯一的硬顶：页面要么收不到事件，要么拦截无效，只能由用户侧键位重映射绕开。其余按键一律归终端所有，应用内快捷键在终端聚焦时主动豁免，不与终端争键。
