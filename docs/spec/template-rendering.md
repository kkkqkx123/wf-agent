# 模板渲染全局规范

本文定义项目内所有占位符语法的归属阶段、适用范围与语义边界。凡涉及渲染、校验、文档、报错文案之处，均以本文为准。

## 1. 分层模型

渲染按五个阶段依次发生，后一阶段只能看到前一阶段的产物，不得回头重新解释前一阶段的语法：

* 文件加载期：读取原始文件文本，只处理环境变量插值。
* 配置装配期：合并默认配置与应用配置，只处理参数替换。
* 工作流执行期：节点运行时解析变量引用与条件表达式，产物进入上下文或命令。
* 提示词展示期：把已声明模板渲染为发往模型的文本，未命中时保留原文或按选项拒绝。
* 后渲染注入期：把展示文本中的单括号锚点替换为技能与工具元数据块。

跨层引用一律无效。例如执行期变量不得在加载期提前展开，展示期占位符不得在装配期被消费。

## 2. 语法总览

| 写法举例 | 归属阶段 | 含义 | 未命中时的行为 |
|---|---|---|---|
| 美元单括号全大写形式 | 文件加载期 | 引用操作系统环境变量，可带默认值 | 留原文，显式检查时报错 |
| 双括号 parameters 前缀形式 | 配置装配期 | 引用装配参数表中的字符串参数 | 默认留原文，密钥类材料走严格模式报错 |
| 美元单括号小写点路径形式 | 工作流执行期 | 引用工作流变量存储中的值 | 留原文 |
| 美元裸名与美元单括号形式 | 脚本参数动态插值 | 在脚本声明参数值内部引用上下文 | 留原文，显式查询可发现 |
| 双括号路径形式 | 执行或展示 | 引用上下文或模板变量，是否报错取决于引擎 | 执行引擎报错，展示引擎留原文或按选项拒绝 |
| 单括号全大写锚点形式 | 后渲染注入期 | 预留的技能与工具元数据插入位置 | 轻量路径剥离并告警，Agent 回路注入正文 |
| 双括号 fragments 伪变量形式 | 资源模板引擎 | 按模板声明的片段列表组装正文 | 缺片段则整次渲染失败 |
| 双括号 input 特殊变量形式 | 用户交互节点 | 引用用户本轮输入 | 仅该节点有效，其他位置视为普通未声明变量 |

同一对双括号在不同引擎下含义不同，选引擎先看产物去向：产物会被执行的用严格引擎，产物仅展示的用宽松引擎。

## 3. 文件加载期规范

* 仅识别全大写字母、下划线、数字组成的变量名，小写表达式一律视为业务文本，不得触碰。
* 支持默认值形式，无默认值且环境未设置时保留原文，不得静默变为空字符串。
* 密钥与文件内容在启动时应显式调用未解析查询，缺失直接拒绝启动；可选占位允许预览时保留原文。
* 环境覆盖的 typed 映射属于装配逻辑，不在此阶段做类型推断之外的校验。

## 4. 配置装配期规范

* 仅识别 parameters 前缀的双括号占位，参数表为字符串映射，不做点路径语义拆分之外的类型解释。
* 默认保持宽松以支持预览与局部覆盖；涉及密钥、地址、口令的装配必须使用严格入口，渲染后复查仍有残留即报错。
* 参数名提取与渲染必须共用同一扫描规则，新增语法必须同步更新提取器与渲染器。
* 装配期不得消费运行时变量，不得处理单括号锚点与 fragments 伪变量。

## 5. 工作流执行期规范

* 变量存储解析只认美元单括号形式。整串恰好为单个引用时保留原值的完整类型；嵌入在长文本中时一律转为展示文本。
* 以 variables 前缀开头的路径表示作用域剥离，即读取扁平变量名，而非字面嵌套键。该前缀不得出现在存储键名中。
* 条件求值同时接受美元单括号与双括号引用，但求值前未命中的引用留原文进入表达式求值，不得提前报错；求值器的字面量规则独立于展示文本，字符串自动加引号，空值按空字面量处理。
* 节点注册期必须校验内嵌引用中的路径形状与括号闭合情况，裸字面量无引用时直接放行。

## 6. 脚本命令规范

* 命令模板只认双括号路径，路径形状复用全局校验器，非法路径视为未解析。
* 参数值内部的美元引用在模板渲染之前完成，默认同时处理裸名与单括号形式；面向 shell 的执行路径只处理单括号形式，裸美元一律留给 shell 原生变量。
* 双美元转义为单个美元，全程不得重扫已代入的值，避免二次展开。
* 任何未解析的双括号占位都必须导致命令拒绝执行，不得带着占位符原文去执行。
* 文件类型参数在解析后必须做工作目录内存在性约束检查，与模板渲染成功与否无关。

## 7. 钩子负载规范

* 负载模板只认双括号路径，査找表为直接上下文，不经过脚本参数声明与文件约束。
* 未闭合、路径非法、上下文缺失一律视为渲染失败，钩子不得以半替换负载触发。
* 渲染结果若恰好构成合法结构化文本，允许回写为结构化值，否则保持字符串；该回写不得改变渲染失败的判定。

## 8. 提示词展示期规范

* 资源模板为唯一的提示词渲染入口，调用方只传模板编号，不得感知数据来源。
* 普通双括号占位从字符串变量表精确匹配，匹配时忽略括号内侧空白，值代入后不再重扫。
* fragments 伪变量由引擎按声明列表组装，各片段先分别应用变量表再拼接；声明了片段但未注册的直接渲染失败；模板正文不含该伪变量时片段列表不起作用。
* 已删除的历史伪变量一律视为普通未声明变量，保留原文，不得恢复旧语义。
* 必填变量在默认值填充后仍缺失的，直接渲染失败；可选变量缺失时保留原文并记录可观测事件。
* 展示文本的值胁迫规则全局统一：字符串透传，空值转为空字符串，其余按结构化文本形式转写。
* 发往模型的路径默认拒绝残留占位，预览路径允许保留原文。当前默认宽松属于历史行为，新接入的模型绑定路径必须显式开启拒绝模式。
* 内联正文优先于模板引用，两者同时出现时记录告警并采用内联正文。
* 轻量模型节点不得使用后渲染锚点，命中时告警并在最终文本中剥离；需要技能与工具曝光的节点必须使用 Agent 回路节点。

## 9. 后渲染注入期规范

* 单括号锚点与双括号模板正交，模板变量声明、必填检查、占位提取一律忽略单括号锚点。
* 新增锚点必须同步扩展全局锚点清单，未登记的单括号大写文本一律视为普通文本，不得注入。
* 锚点拼写全局唯一，大小写敏感，调用方不得自创别名或缩写。

## 10. 类型规范

* 模板变量声明包含名称、形状、是否必填、说明与默认值五要素，形状限于字符串、数字、布尔、数组、对象五种。
* 声明的默认值必须与声明形状一致，否则在配置校验期拒绝。
* 调用方传入的结构化值必须在转字符串之前先做形状匹配，失配直接渲染失败，不得先转字符串再比较。
* 值胁迫区分三种用途：展示转文本、条件转字面量、整串透传保留类型。三种用途不得复用同一函数名义，文档与报错必须写明当前用途。
* 空字符串默认值视为有效值参与填充，不得按缺失处理；是否允许空文本由模板作者通过必填与否表达。

## 11. 路径规范

* 路径由点号分隔，每段为标识符或纯数字数组下标，首尾不得有点，中间不得有空段，首字符不得为数字（纯数字段除外）。
* 点路径解析在对象上按鍵查找，在数组上按数字下标查找，标量上继续下钻一律视为缺失。
* 扁平变量表只做精确键匹配，不做点路径拆分。需要点路径能力的展示场景必须先走结构化变量入口，不得依赖调用方手工拼扁平键。
* 单括号、双括号、美元单括号三种括号下的路径形状规则为同一套实现，不得各自为政。

## 12. 优先级与回退规范

* 系统提示词：内联正文大于模板引用，模板引用大于无配置；模板编号未知时返回空缺而非空字符串。
* 资源模板：已配置模板大于内置默认文本，内置默认大于未知编号；使用内置默认时必须记录回退事件。
* 可见性公告：有注册表时走模板渲染，渲染失败回退调用方传入的兜底文案；无注册表时直接使用兜底文案。
* 配置合并：应用层非空覆盖默认层，变量表按名称合并，片段列表按序去重合并，编号不一致直接拒绝合并。

## 13. 可观测性规范

* 每次渲染记录耗时与成功与否；未知模板、缺必填变量、缺片段、类型失配、残留占位、内置回退分别记为不同错误原因。
* 宽松渲染产生残留占位时必须记录告警，严格渲染拒绝时必须指明首个缺失变量或非法路径及原因。
* 占位提取器即渲染尝试集合，两者扫描规则必须一致；未闭合括号不计入占位提取，但严格引擎仍需独立报错。

## 14. 禁止事项

* 禁止在展示模板中依赖点路径自动拆分（在结构化入口落地前）。
* 禁止在执行产物中使用宽松渲染，禁止带着残留占位执行命令或触发钩子。
* 禁止把调用方传入值二次扫描展开，禁止把锚点拼写混入双括号变量。
* 禁止新增与现有括号语法仅差空白或大小写的近义写法；新语法必须使用此前未使用的括号组合或显式前缀。
* 禁止在注释中引用本文档的章节编号，注释只描述代码意图。
