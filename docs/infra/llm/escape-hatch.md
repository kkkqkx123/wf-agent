# 透传逃生舱与模型补充手册

本篇说明如何不改编解码代码解决长尾兼容问题，以及如何补充内置模型。
原则：影响编解码分支的少数热字段保持类型化，其余一律走非类型化透传。

## 透传优先级

请求头（从低到高）：画像默认头、`headers`、`custom_headers`、每次请求的
`extra_headers`；抓取钩子最后执行，可做签名与重写。

请求体（从低到高）：类型化生成映射、按思考级别的采样覆写、
profile 与请求参数合并、自定义体。自定义体做深度合并且胜出，
受总开关控制。请求参数胜过 profile 参数。

查询串与端点：查询参数追加，基址可携带完整部署端点，
地址拼接时合并基础与路径查询串。

保留键永不上线：`stream` 由调用方控制，`request_limits` 由网关准入消费，
类型化生成键走生成解析器。透传非类型化键原样进包。

## 常见配方

- 路由偏好与会话亲和：经由请求头或自定义体透传对应厂商字段，
  会话路由这类动态值走每次请求的附加头。
- 提示缓存键：经由请求参数透传缓存键字段。
- 思考方言：优先使用思考值映射；级别置空加原生参数直传是过渡用法，
  新方言应收敛到映射表。
- 结构性协议差异：注册自定义编解码，网关按 profile 的格式名解析。

## 思考值映射

思考配置支持两个通用容器，均按规范小写级别名
（`none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`）键控：

- 值映射：某级别的 JSON 值替代编解码内置；显式空表示该级别不支持，
  编解码省略思考字段，端点回落模型默认。映射可绕过内置级别成员校验，
  新级别无需改代码。
- 按级别采样覆写：生效级别的对象在类型化生成映射后深度合并进包，
  profile 与请求参数仍在其后生效。非对象值在运行时告警忽略。

未知键在 profile 注册期失败。请求级思考配置整体替换 profile 级，
映射随其所属配置原子生效。

## 请求限制

保留键 `request_limits` 置于 profile 或请求参数内，网关在编码前准入：

- `max_request_bytes`：消息加工具声明序列化字节上限，超限失败。
- `max_images_per_message`：单消息图片块上限，超限失败。
- `max_images_per_request`：全请求图片块上限，超限失败。

请求级整体替换 profile 级。超尺寸图片直接拒绝，不做静默缩放，
调用方在发送前自行缩放。未知字段与类型错误在注册期与准入期均失败。

## 模型补充

- 新兼容厂商：新增连接模板（基址加线协议加鉴权类型），文件层后注册的
  按标识胜出，无需新注册表。
- 新协议：运行时注册自定义编解码，网关按格式名解析。
- 价格：存储自定义规则优先于嵌入式公开表，命名空间映射解决本地标识
  与上游命名空间不一致；补价格只需写存储规则并刷新镜像。
- 模型行无需预置：profile 手写绑定，在线发现负责列出远端模型，
  上下文窗口与输出上限走显式值加目录回填；线协议永不从目录回填。

## 密钥插值

文件内容解析前展开 `${VAR}` 与 `${VAR:default}` 两种占位，
仅大写名匹配，缺失无默认值时保留原文。裸 `$NAME` 形式有意不支持，
避免正常文本被误展开。感叹号开头的密钥与头值在校验期直接失败，
命令执行语义不被实现；动态密钥走插件鉴权。
