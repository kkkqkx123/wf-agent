## 1. 目标

为用户仓库补上与检查点裸仓完全隔离的版本控制体验。首期做到只读可用、写操作收敛、可审计；终端与 TUI 为增量增强，不阻塞主链路。

## 2. 约束

双域隔离不松动。用户仓一律调用 `git` 二进制并以参数数组发起，不复用检查点对象库读写用户分支，不把检查点提交图当用户历史展示。新增传输代码只做路由、模型、校验与标注，解析与执行收敛在领域层。前端契约经开放接口快照与类型生成消费，流式通道类型手写。界面元素取自基础组件库，不新增基础组件。每阶段结束为可用中间状态，文档随代码同步更新。

## 3. 里程碑

| 里程碑 | 主题 | 交付物 | 可独立验收 |
|---|---|---|---|
| P4 | 用户 Git 只读域 | 只读查询加注册表骨架、无头只读命令 | 是 |
| P5 | 工作台骨架 | 新路由、四区布局、只读服务、局部刷新 | 是 |
| P6 | 输入栏与写操作 | 绑定表、解析函数、统一动作入口、危险分级 | 是 |
| P7 | 终端与增强 | 终端通道、浏览器终端、TUI Git 屏、回显 | 否，增量 |

各里程碑的任务与验收见分篇，跨阶段约束为契约先行、唯一写入口、前后端同守。

## 4. 不做事项

首期不做多仓库切换、托管平台集成、多人并发写锁、完整编辑器嵌入、补丁构建完整形态、交互式变基编辑器形态。工作区与子模块写操作标记为不可用，只读或隐藏。
