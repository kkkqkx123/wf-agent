# 聊天 IDE 为主界面、工作台为附加页的设计方案

> 目标：把 `apps/web-app` 从运维工作台优先翻转为对话优先的 Agent IDE。对话列成为默认落地页，执行工作台退为附加页面。只描述长什么样、怎么摆、用什么拼，不粘贴完整代码实现。

## 1. 现状复盘

当前为工作台优先形态，结论来自逐文件核验：

- 根路由恒定重定向到执行工作台（`apps/web-app/src/routes/+page.ts` 重定向到 `/executions`）。
- 应用壳为两栏（`lib/components/layout/AppShell.svelte`）：左侧一级导航侧栏加顶部顶栏加主内容区。
- 列表页统一范式为列表加检查器（`lib/components/layout/SplitView.svelte`）：左列表右只读详情，宽屏停靠窄屏转抽屉。
- Agent 回路详情（`routes/agent-loops/[id]/+page.svelte`）是记录回放页：消息、变量、图、分析、检查点做成顶部内分段切换，没有输入组合器；`domain/MessageBubble.svelte` 只渲染纯文本。
- 样式基座已就绪（`src/app.css` 的 HSL 通道 Token、浅深两套语义色、统一缓动、细滚动条、受限毛玻璃、无障碍降级），翻转时直接复用，不重建。

结论：缺的不是样式，而是一个以对话为中心的三区 IDE 壳，以及可交互的会话组件。工作台页面本身可用，只是不应再占据默认落地页和一级导航首位。

## 2. 目标形态

翻转后的默认界面为三区 IDE，工作台退为中心列的一个可切换模式：

```text
┌──────────────┬──────────────────────────────────┬──────────────────┐
│ 会话侧栏      │ 对话列                            │ 功能边面板        │
│ 264px        │ 1fr（居中最大宽度消息区加底输入框） │ 360px（多标签页） │
│ 可折叠记忆    │ 工作台模式时替换为执行列表        │ 可停靠可浮层      │
└──────────────┴──────────────────────────────────┴──────────────────┘
```

- 默认落地为对话列：有会话进最近会话，无会话进新建会话空态。
- 工作台不再是首页，而是对话列顶部可切换的第二模式，或侧栏底部的一个附加入口。
- 右侧边面板承载原来分散在各详情页分段里的内容：图、迭代、变量、检查点、工具调用、时间线、分析。

## 3. 路由与导航

### 3.1 路由调整

- 根重定向目标改为对话（修改原 `routes/+page.ts`，不保留旧落地页兼容）。
- 对话主路由收敛到一组：会话列表与会话详情共用同一 IDE 壳，详情承载消息流与输入框。
- 执行工作台从 `/executions` 保留但降级：作为 IDE 中心列的一个模式和一个可直达的附加路由存在，不再是默认页。
- 原 `agent-loops` 列表与详情页合并进对话路由，冗余页面删除，不做双轨兼容。
- 工作流、检查点、触发器、资源、模板、洞察、事件、设置等二级页面保留路由，但一级导航不再平铺全部，常用项进边面板标签页，冷门项只留命令面板入口。

### 3.2 导航分组

侧栏按会话优先重组：

- 顶部操作区：新建对话、全局搜索、命令面板入口。
- 会话分组：星标、最近、草稿、归档，支持过滤与排序。
- 附加区：工作台、工作流、检查点等人入口收拢为一组，不再与会话平级抢首屏。
- 底部：连接态、用量徽标、主题与检查器开关。

## 4. 布局设计

### 4.1 三区职责

- 会话侧栏：只管会话寻址（新建、切换、星标、归档、搜索），不管业务详情。折叠策略沿用现有偏好存储（折叠态、宽度持久化），在其原模块内直接改造，不另起侧栏组件。
- 对话列：默认渲染消息时间线加底部输入框；切换到工作台模式时渲染执行列表。两种模式共享同一页头位置，页头内容随模式切换（会话标题与模型选择器，或工作台筛选器）。
- 功能边面板：多标签容器，标签归属当前会话（图、迭代、变量、检查点、工具、时间线、分析）。宽屏停靠，窄屏转浮层抽屉，沿用现有检查器停靠与宽度记忆机制，在原 `SplitView` 模块内扩展为标签页模式。

### 4.2 响应式断点

沿用现有四档，只改各档行为：

- 宽屏三区全开；中等宽度边面板转浮层；窄屏侧栏折叠为图标轨；移动端单栏，会话侧栏与边面板均为浮层，输入框底部固定。
- 对话列消息区保持居中最大宽度，两侧预留细导轨位置（位置小地图与回答大纲后续增量再加）。

### 4.3 空态

- 无会话空态：问候语加推荐提示加新建会话入口。
- 会话无消息空态：模型选择与快捷输入建议。
- 工作台模式空态沿用现有空态组件。

## 5. 组件演进

原则：改造原模块，只在出现新职责时新增模块，不建替代型重复模块。

- 会话侧栏：在原侧栏模块内改造，会话项支持置顶、星标、时间线、归档四种视图。
- 对话页头：标题支持内联重命名，附带星标、标签、分享、导出、模型选择器、边面板开关。
- 消息时间线：在原消息气泡模块上扩展，职责仍为消息展示：增加 Markdown 与代码渲染、工具调用内联卡片、引用与文件徽标、重试与继续与反馈入口；虚拟化与自动跟随尾部、回底按钮随数据量增长再加。
- 输入组合器：新增模块（新职责：输入、队列、提及、附件）。支持生成中继续追问的多消息队列、停止语义、@ 提及文件与模型与工具与技能、斜杠命令、拖放与粘贴上传、草稿会话与正式任务分离。
- 工具调用卡：扩展种类渲染（执行输出、文件变更、审批询问、MCP 调用），配套完整结果弹窗；颜色沿用现有语义 Token，不新增色板。
- 工作流图：沿用现有占位渲染先满足选择与详情联动，平移缩放与执行态高亮作为后续增量。
- 命令面板：在原模块内扩展数据源与动作，统一搜索导航、会话、文件、工作流，并支持直接执行常用命令。
- 设置页：改为左导航加右卡片行布局，补齐外观字号档与对话字体切换入口（消费现有字号缩放 Token）。

## 6. 样式复用说明

- 色板、圆角、阴影、字体栈、细滚动条、受限毛玻璃、统一缓动、无障碍降级全部沿用现有 Token，不新增。
- 新增动效只限三处：面板入场淡入上移、卡片逐项延迟入场、流式思考态；其余沿用现有动画工具类。
- 深浅色与跟随系统逻辑不变，主题切换过渡只加在背景与边框色上。

## 7. 状态与数据流

- 会话状态按会话键隔离：激活会话、草稿、乐观会话列表、队列、流式缓冲各自独立，避免一个全局存储包揽一切。
- 执行逻辑留在服务端，前端只负责展示与下发用户消息：流式消息经 WebSocket 或 SSE 进入存储，再到时间线；输入框经附件上传与草稿通道进入服务端。
- 简单日志与时间线用 SSE，多会话并行订阅用 WebSocket；文件处理与用量用轮询加无限滚动哨兵。
- 沿用现有信封拆包、错误归一、鉴权头注入与地址栏状态回写约定。

## 8. 借鉴来源对照

- 向 deeix 借对话页 chrome（标题栏操作群、居中消息列、输入框队列与提及、轨迹手风琴、星标标签分享导出）与侧栏信息架构（主导航加项目加星标加最近）。
- 向 zcode 借三区编排（会话侧栏加对话列加多标签边面板）、草稿与正式任务分离、排队追问、虚拟化时间线、文件预览与 Diff 与 Git 面板组合、命令中心统一搜索。
- 向 live-agent 借风格节制（中性主轴、毛玻璃收敛、统一缓动、字号缩放、主题跟随），该部分基座已落地，本方案只消费不重建。

## 9. 落地顺序

- 先翻转壳：根重定向改对话、侧栏改会话分组、中心列出对话时间线占位、边面板改多标签容器。
- 再做可交互会话：输入组合器、队列与停止、多消息流式渲染、工具调用内联卡。
- 再迁移工作台：执行列表退为中心列模式与附加路由，原详情分段并入边面板标签。
- 最后补外环：命令面板统一搜索、分享导出、设置页重组、空态与推荐、骨架波次。

## 10. 验收标准

- 根地址进入对话 IDE，无会话时为空态而非工作台列表。
- 会话切换、边面板标签切换、宽度与停靠记忆在刷新后恢复。
- 类型检查、lint、格式、构建四项通过；组件内无硬编码颜色；未知状态值有中性兜底。
- 真实数据下消息流可逐帧消费，错误与关闭有处理；移动端断点可用。
