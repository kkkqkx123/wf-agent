# 终端与 TUI 增强设计（P7）

> 范围：浏览器终端通道、TUI Git 屏、无头写批与后续增强。本阶段为增量，不阻塞 P4-P6 的独立验收。

## 1. 通道分离

事件订阅通道与终端通道分离。前者沿用现有广播式订阅，用于推送仓库变化；后者新建独立端点，一连接绑定一会话，双向流式。终端会话由现有 Shell 会话存储承载，支持创建、输入、尺寸调整、终止、空闲回收。会话工作目录锁定仓库根，环境注入受控覆盖，避免寻呼器与凭据交互卡死。

## 2. 协议与生命周期

协议帧分客户端到服务端与服务端到客户端两向，覆盖建立、输入、尺寸、终止、保活与就绪、增量输出、前台结束、仓库变化、错误等。连接生命周期与页面绑定，折叠不销毁会话，离开路由销毁，关闭前主动终止。终端写入后经指纹比对触发上半部分自动刷新，未变不推。

## 3. 浏览器终端组件

终端组件挂载终端渲染实例，处理输入与尺寸事件。新增运行时依赖只保留终端渲染所需的一项。提供清空、终止当前命令、重启会话三个按钮。输出原生支持着色。动作失败时提示附带在终端中查看的入口。终端做生命周期单测并以手工验证交互式命令，凭据场景不卡死为必验项。

## 4. TUI Git 屏

新增一个 Git 屏，与检查点屏并列，不合并。侧栏分组沿用默认五分组，首期激活状态、文件、分支、提交、贮藏。主视图复用差异查看器，支持已存与未存切换。列表导航沿用现有上下移动与确认进入，面板间用数字键与标签键切换，与现有导航习惯一致。

键位取高频子集并按焦点消歧：空格切换暂存或检出，提交键在文件面板为提交变更，放弃键在文件面板为放弃变更、在分支面板为删除分支，贮藏键在文件面板为贮藏全部，刷新键全局刷新，撤销重做走全局，问号唤出当前上下文全量表。破坏性动作一律走确认框，强制类操作要求输入目标标识。只读动作先行，写动作随后端统一入口就绪后接入。状态刷新靠版本指纹变化驱动，无仓库时显示空状态并引导配置。

终端界面内不内嵌伪终端，不引入新的终端依赖。需要完整 Shell 的场景由用户本地终端或浏览器终端页承载，终端界面提供感叹号透传单条命令的轻量形态即可。命令面板与键位输入栏的 Web 形态不搬到终端界面，终端界面保留单键即触发的手感，右键菜单以动作菜单替代。

## 5. 无头写批

写操作后置，形态为显式动作加确认。暂存切换、提交、贮藏等进入第二批，每个动作声明危险级别，破坏性动作要求传入确认标识。远端交互命令以显式确认加长超时单独开放。命令日志保留完整输出供回溯。轻量交互不承载 Git，由无头命令覆盖。

## 6. 后续增强

行级暂存、贮藏全套、变基动作集按需跟进。交互式变基、补丁构建、合并冲突解决等重型能力首期不进终端界面，留给浏览器工作台与无头命令。

## 7. 验收

页面内可跑常用命令并正确渲染；交互式暂存可完成一次；终端写入后上半部分自动刷新；折叠不丢上下文，离开路由被回收；TUI 屏标题帮助与行为一致，破坏性动作经确认；凭据场景不卡死。

## 8. 风险

伪终端依赖与现有 Shell 会话语义的差异需在接入前做最小联调；长命令节流阈值需按实际推送拉取耗时调参；TUI 新增屏的数字键重排需同步帮助文案，避免单键歧义。
