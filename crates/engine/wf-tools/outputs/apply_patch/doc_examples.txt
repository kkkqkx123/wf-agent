# apply_patch (filesystem)
Apply a Codex-style patch to the filesystem. The patch is a sequence of Add File, Delete File and Update File operations delimited by '*** Begin Patch' and '*** End Patch'.

tips:
- Use Update File with @@ context markers for reliable matches

examples:
- apply_patch("*** Begin Patch\n*** Add File: new.txt\n+hello\n*** End Patch")
