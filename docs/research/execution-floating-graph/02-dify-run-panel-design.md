# Dify 运行面板设计参考

本文记录 Dify 侧与浮窗式执行查看相关的设计事实，作为当前项目方案的对照。信息来源为 ctx7 文档查询与本地浅克隆副本，所有路径指向 `docs/ref/dify` 快照。

## 1. 查询来源

- ctx7 文档库 `/langgenius/dify-docs`，查询词包括工作流运行追踪、运行状态、日志查看。
- ctx7 代码库 `/langgenius/dify`，查询词包括运行追踪面板、节点执行、运行状态。
- 本地副本 `docs/ref/dify/web/app/components/workflow` 下的运行面板、追踪面板与节点卡。

## 2. 右侧浮动运行面板

- 运行面板由三页签组成：结果、详情、追踪，页签使用大写文案与底部细分隔线，监听态会自动切换到详情页签。
- 请求生命周期对象对详情与追踪请求做竞态防护，旧请求返回后直接丢弃；结果区高度按容器高度减去内边距与边框计算。
- 工作流面板整体绝对定位在画布右上，右侧面板为纵向浮层，选中节点时展示节点面板，环境变量与版本历史面板与其共享同一浮层容器。
- 日志页本身是表格加分页加右侧抽屉，表格行点击后滑出抽屉，关闭后回到表格；运行详情复用同一运行组件。

对当前项目的启发：浮窗适合做成画布或详情页上的绝对浮层，而不是新的路由；详情与追踪应该在浮层内可切换，而不是只能二选一；监听态需要明确的自动切页规则。

## 3. 状态面板

- 状态面板展示状态、耗时、令牌数、错误、异常数、监听态与追踪入口，区分计划、成功、部分成功、失败、停止、暂停、运行中七种文案与语义色。
- 成功与部分成功使用绿色，失败使用红色，停止与暂停使用警告色，计划使用次要色，运行中使用蓝色。
- 暂停态会查询暂停详情，区分人工输入节点，给出原因文案与后台输入链接。
- 部分成功带有异常数提示，可点击跳转到追踪页签。

对当前项目的启发：浮窗进度条需要同时回答状态、耗时、令牌与异常数；部分成功与暂停是独立语气，不能合并为成功或失败；每个异常都需要可跳转的追踪入口。

## 4. 追踪面板与节点卡

- 追踪面板先建树再递归定位，并行首节点渲染并行标识与展开控制，悬停时图标在展开与菜单间切换，节点间用渐变分隔线与左侧竖线表达层级。
- 迭代、循环、重试、智能体节点按类型决定是否渲染专属日志触发器，工作流工具调用支持下钻到子节点。
- 节点卡默认折叠，头部包含折叠箭头、节点图标、标题、令牌数与耗时、状态图标；耗时小于一秒显示毫秒，大于六十秒显示分秒，均保留三位小数；令牌数按千与百万缩写。
- 卡片使用大圆角、细边框、小阴影，悬停时阴影加深；标题截断，状态文案同时提供无障碍朗读。

对当前项目的启发：浮窗迷你图不需要展示全部节点 IO，节点卡的折叠、缩写与悬停策略更适合小尺寸；耗时与令牌缩写规则可以直接复用。

## 5. 日志筛选与分页

- 日志页顶部为标题加筛选加保留期提示，筛选行使用状态 Chip 与时间 Chip 加搜索框，查询参数做防抖。
- 时间周期覆盖今日、近七日、近四周、近三月、近一年、月初至今、季初至今、年初至今与全部。
- 列表为表格，分页仅在总数超过页大小时显示，页大小支持十、二十五、五十三档。

对当前项目的启发：浮窗不需要重复筛选能力，筛选仍属于列表页；但状态 Chip 的低理解成本值得浮窗图例借鉴。

## 6. 可借鉴与不可照搬

- 可借鉴：右侧浮层承载运行面板、结果与追踪在同一容器内切换、状态圆点加语义色加文案、节点卡默认折叠与缩写规则、暂停原因与后台链接、异常数跳转追踪。
- 不可照搬：大量任意值样式类、固定最小画布宽度、页码分页照搬到当前项目的游标分页。许可为 Dify 开源许可，只做本地对照。
