# 维度三：页面布局（Page Layout）

> 关注点：编辑器/执行视图的整体骨架——头部、侧边栏、画布主区、详情/执行面板的位置关系与响应式策略。

---

## 1. Dify 的页面布局

Dify 的编辑器布局是**"画布为主、悬浮覆盖、抽屉为辅"**的轻量叠层结构，没有固定的多栏栅格。

### 1.1 画布即主体

- `web/app/components/workflow/index.tsx` 渲染 React Flow 画布，占满工作区；`reactflow/dist/style.css` + 自定义 `style.css` 提供基础布局与选区样式。
- 协作光标、评论、候选节点、辅助线等均为**画布上的叠加层**（`:59-76`）。

### 1.2 顶部悬浮工具栏

- `header/index.tsx:28` 头部以 `absolute top-7 left-0 z-10` 覆盖在画布顶部，背景为自上而下渐隐遮罩 `bg-mask-top2bottom-gray-50-to-transparent`，左右分布 normal/restoring/history 三种模式控件。
- 这种"浮在画布上"的做法不挤压画布空间，但功能入口相对收敛。

### 1.3 运行/追踪面板（抽屉式覆盖）

- `run/index.tsx` 的 `RunPanel` 作为**覆盖面板**（常置于画布右侧或底部），内含 RESULT/DETAIL/TRACING 三 Tab（`:104-140`）；TRACING 面板底色 `bg-background-section-burn`（`:182`）。
- 节点配置走右侧抽屉式面板（NDV 思路），由共享组件承载。

### 1.4 布局特征小结

| 区域 | 实现方式 |
| --- | --- |
| 主区 | 全屏 React Flow 画布 |
| 头栏 | 绝对定位悬浮工具条（不占栅格） |
| 运行/追踪 | 叠加式面板（三 Tab） |
| 协作/评论 | 画布内叠加层 |

## 2. n8n 的页面布局

n8n 的布局是**"具名插槽的结构化骨架 + 可缩放侧栏 + 专用执行分栏"**，层次清晰、可扩展。

### 2.1 结构化布局骨架（BaseLayout 插槽）

`WorkflowLayout.vue:85-108` 以 `BaseLayout` 为根，使用具名插槽：

```vue
<BaseLayout>
  <template #header>   <AppHeader />            </template>
  <template #sidebar>  <AppSidebar />           </template>  <!-- canvasOnly 时隐藏 -->
  <LoadingView v-if="isLoading …" />
  <RouterView v-else />
  <template #footer>   <LogsPanel />            </template>  <!-- logs 为真时 -->
  <template #overlays>
    <AskAssistantFloatingButton />
    <CanvasChatOverlay />
  </template>
</BaseLayout>
```

——头部、侧边栏、内容区、底部日志、浮层分区明确，画布（NodeView）位于内容区。

### 2.2 主编辑器（NodeView）

`NodeView.vue` 是工作流编辑器主体，渲染：

- `WorkflowCanvas`（画布）；
- `FocusSidebar`（节点详情视图 NDV，懒加载 `LazyNodeDetailsView`）；
- 画布按钮：`CanvasRunWorkflowButton`、`CanvasStopCurrentExecutionButton`、`CanvasStopWaitingForWebhookButton`、`CanvasChatButton`（`:16-20,139-140`）；
- 懒加载 `LazyNodeCreation`（节点创建器）、`LazySetupWorkflowCredentialsButton`（`:167-178`）。

### 2.3 可缩放侧边栏

`MainSidebar.vue`：

- `N8nResizeWrapper id="side-menu"`，`supported-directions="['right']"`，`min/max-width=MIN/MAX_SIDEBAR_WIDTH`，`grid-size=8`（`:363-379`）。
- 宽度变量在 `_variables.scss:23-24`：`$sidebar-width: 42px`（折叠）、`$sidebar-expanded-width: 200px`（展开），可拖拽调整。
- 内部结构：`MainSidebarHeader`（含折叠/命令栏）+ `N8nScrollArea` 包裹 `ProjectNavigation` + `BottomMenu` + `MainSidebarSourceControl`（`:380-406`）。

### 2.4 执行视图分栏布局

- `WorkflowExecutionsView.vue:331-348` → `WorkflowExecutionsList`：左 `WorkflowExecutionsSidebar`（列表）+ 右 `RouterView name="executionPreview"`（详情）。
- `WorkflowExecutionsList.vue:84-107` 为 `flex` 容器；`sm-and-down` 断点下转为纵向列（`SCSS :123-131`），体现响应式。
- 全局执行视图 `ExecutionsView.vue:137-182` 用 `PageViewLayout` + `GlobalExecutionsList`，含 `ProjectHeader` 与 `InsightsSummary`。

### 2.5 布局特征小结

| 区域 | 实现方式 |
| --- | --- |
| 主区 | `RouterView` → `NodeView`（WorkflowCanvas） |
| 头栏 | `BaseLayout #header`（常驻 AppHeader） |
| 侧栏 | `N8nResizeWrapper` 可缩放（42↔200px），含项目导航/菜单 |
| 详情 | `FocusSidebar`（NDV，右侧抽屉） |
| 底部 | `LogsPanel`（#footer，可选） |
| 浮层 | 助手悬浮按钮、画布聊天叠层（#overlays） |
| 执行 | 独立分栏视图（左列表+右预览，响应式列化） |

## 3. 横向对比

| 对比项 | Dify | n8n |
| --- | --- | --- |
| 整体骨架 | 画布为主 + 悬浮覆盖 | `BaseLayout` 具名插槽（header/sidebar/footer/overlays） |
| 头部 | 绝对定位浮层（不占栅格） | 常驻 `AppHeader`（插槽） |
| 侧边栏 | 无独立侧栏（配置走抽屉） | 可缩放 `N8nResizeWrapper`（42↔200px），含导航/菜单 |
| 节点详情 | 右侧抽屉式面板 | `FocusSidebar` / NDV（懒加载） |
| 运行/执行 | 叠加式三 Tab 面板 | 专用分栏视图（列表+预览），响应式 |
| 日志 | 内嵌于运行面板 | 画布底部 `LogsPanel`（独立 footer） |
| AI 入口 | 隐含于运行解释 | 悬浮助手按钮 + 画布聊天叠层（浮层区） |
| 响应式 | 画布自适应 | 侧栏/执行视图有显式断点（sm-and-down 转列） |

---

## 4. 设计启示

- **是否需要常驻侧栏**：n8n 面向"多工作流 + 项目导航 + 设置"的平台场景，常驻可缩放侧栏收益高；Dify 以单工作流编辑为中心，悬浮工具条更省空间。选择取决于信息密度。
- **执行视图独立成页**：n8n 把 Executions 做成一级分栏视图（列表+预览+响应式），比"叠加面板"更利于审计与检索；若产品重视历史回溯，应独立成页。
- **插槽化布局**：n8n 的 `BaseLayout` 插槽模式让 header/sidebar/footer/overlays 可被不同宿主（独立编辑器、嵌入 iframe）选择性启用（如 `isCanvasOnly` 隐藏侧栏），可复用性强。
